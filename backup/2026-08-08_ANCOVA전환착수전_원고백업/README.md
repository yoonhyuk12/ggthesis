**백업 시점:** 2026-08-08
**백업 사유:** 주 분석을 ANCOVA(두 집단 비교 설계)로 전환하는 목차 수준 개편에 착수하기 전, 현행 원고 일체를 보존한다. 사용자 지시에 따른 백업이다.

## 이 백업이 담고 있는 설계

- **연구모형:** 조절된 매개(moderated mediation). X1~X4 → M(경보 피로도) → Y(안전관리 실효성), W(안전관리 예산 제약성)가 M→Y 경로를 조절. 가설 14개, jamovi(lavaan) SEM, 사용 후 설문 1회 측정.

- 비교 구조: AI 알림 수신 현장 약 30개소 vs 미수신 현장 약 30개소, 사후 1회 설문 (횡단 두 집단 비교)
