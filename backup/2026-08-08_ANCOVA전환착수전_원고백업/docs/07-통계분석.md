# 07. 통계분석 방법

> 제5장 실증분석 결과 작성 시 분석 절차 참고용으로 로드하세요.
>
> ⚠️ 아래 절차는 학회논문 단계의 SPSS/PROCESS macro 기준이다. 현행 학위논문의 분석 설계는 `논문구조/04_연구설계.md` 제5절(jamovi·lavaan 기반 SEM, 부트스트랩 간접효과 검정)이며, 충돌 시 원고가 우선한다.

- 빈도분석 (인구통계학적 특성)
- 타당도(주성분분석) + 신뢰도(Cronbach's α: 0.6~0.9)
- 기술통계(평균, 표준편차, 왜도, 첨도) + 상관관계(±0.3 < r < ±0.9)
- 다중회귀분석 (X→Y 인과관계)
- 매개효과 검정 (Baron & Kenny 또는 PROCESS macro)
- 조절효과 검정 (위계적 회귀분석, 상호작용항)
