# 백업 — 조절된 매개 설계 원고 (ANCOVA 전환 이전)

**백업 시점:** 2026-07-29
**백업 사유:** 지도교수(박종용 교수님) 지시로 주 분석을 ANCOVA(공분산분석)로 **전면 전환**하기로 결정. 전환 이전의 원고 일체를 보존한다.

## 이 백업이 담고 있는 설계

- **논문 제목:** 중소규모 건설현장을 위한 YOLO-LLM 안전관제 시스템 실증 연구: 경보 피로도의 매개효과와 안전관리 예산 제약성의 조절효과를 중심으로
- **연구모형:** 조절된 매개(moderated mediation). X1~X4 → M(경보 피로도) → Y(안전관리 실효성), W(안전관리 예산 제약성)가 M→Y 경로를 조절
- **변수 형태:** X·M·W·Y 전부 연속형 리커트 5점 척도 (32문항 + 인구통계 6문항)
- **가설:** 14개 (H1-1~H1-4, H2-1~H2-4, H3, H4-1~H4-4, H5)
- **분석:** jamovi(lavaan) 기반 SEM. CFA → 경로계수 → 부트스트랩(5,000회) 간접효과 → 상호작용항·단순기울기
- **데이터 상태:** 설문 미수집. 제5장은 전체가 `[DATA PENDING]` 골격

## 포함 파일

논문 원고 전체(`00_목차.md` ~ `07_참조번호목록.md`), 부록 2종, 설문 작업이력, `model.md`, hwpx 작성본, 그리고 이 설계에 종속된 `docs/02-연구모형.md`·`docs/07-통계분석.md`.

## 주의

이 디렉토리는 **아카이브**다. 여기의 파일을 수정하지 않는다. 활성 원고는 항상 `논문구조/`에 있다.
