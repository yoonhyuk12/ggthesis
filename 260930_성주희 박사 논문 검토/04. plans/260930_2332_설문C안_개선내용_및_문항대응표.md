# 설문 C안 개선내용 및 문항 대응표

작성일: 2026년 9월 30일 · 개선검토용 v0.1 · 성주희 박사학위논문 대상

## 1. 이번 산출물의 범위

[설문 C안 81문항](<../01. md변환/03. 설문C안(md)/04_설문지_C안_81문항_개선검토용_20260930.md>)은 A안 100개 본문항 가운데 19개를 예비보류하고, 81개 대응 자리에 수정·재개발 후보를 작성한 것이다. **기존 19개 하위요인의 후보 78개와 재정의한 Y5의 새 후보 3개**로 구성된다. A안의 단순 단축판이나 검증된 척도가 아니며, 원문 문항과 점수의 동등성을 가정하지 않는다.

[앞선 축약 검토서](<260930_2246_설문문항_축약가능성_검토서.md>)의 보류 번호를 따르되, M5는 후속 프로젝트 대신 같은 현장 내 환류로 정했다. Y5는 사고지표·관리체계·안전분위기를 섞는 기존 정의를 폐기하고 ‘전반적 안전관리성과 평가’라는 주관적 총괄 평가 후보로 다시 작성했다. 원래 Y5와의 관계는 문항 자리의 추적 관계이며 내용 유지 관계가 아니다.

이 작업은 새 설문과 이 대응표만 만든다. 기존 A·B안, 검토서, 제2·3장 및 저장소 루트의 학위논문은 수정하지 않는다. **배포 전에 나머지 19개 하위요인의 수정과 재정의한 Y5를 포함하여 제2·3장의 정의·가설·측정계획 반영 승인을 받아야 한다.**

## 2. 요인별 문항 수와 번호

## 3. 응답 단위·선별·부담의 실제 구성

응답 기준은 **하나의 국내 도심지 주상복합아파트 신축현장**이다. 다른 건축물 현장을 대신 고르는 A안 안내를 제거했다. [제3장 연구방법](<../01. md변환/00. 논문(md)/03_제3장_연구방법.md>) 제5절의 다섯 조건을 G1(현장 경험), G2(국내 종합건설업체), G9(50억 원 이상), S2(스마트 안전장비 도입), S1(해당 현장 안전관리 업무 수행)로 확인한다. 직종명만으로 안전관리 업무 수행을 추정하지 않는다. 모름 응답은 적격 확인 완료로 취급하지 않는다.

G1의 ‘2021년 이후’ 제한은 C에서 제거했다. A안에만 제시된 이 제한은 제3장 다섯 조건과 일치하지 않으므로, 근무 경험의 기준연도는 연구자가 별도로 결정할 사항이다. 본 C안의 선택은 모집 기간 제한을 확정한 것이 아니며, 배포 전 제3장과 일치시켜야 한다. S2는 현장 도입 사실을, G10은 R1 기간의 기술별 이용 상태를 묻기 때문에 질문 목적이 다르다. BIM·4D 보유만으로 스마트 안전장비 도입을 충족했다고 보지 않도록 안내했다. 기타 장비의 적격 판정 범위는 연구자가 사전에 정의해야 한다.

R1은 응답자가 직접 관찰하거나 업무자료로 확인 가능한 시작·종료 연월이다. 임의의 최소 관찰기간을 적격 기준으로 추가하지 않았다. X는 그 현장의 초기 설계·착공 전 자료에 관한 회고이며, M·W·Y는 R1 기간의 경험이다. M의 초기 공정 검토가 R1 밖에 있었다면 해당 기간에 실제 수행된 것으로 답하게 하지 않는다. 관련 검토 기회가 없었던 경우와 정보를 모르는 경우를 분리한다. 기간 길이와 공정 차이, 회고 편향은 여전히 남으므로 기간 정보를 분석 설계에서 어떻게 다룰지 결정해야 한다.

일반사항 10개는 원래 번호 G1~G10을 유지하되 선별에 필요한 G1·G2·G9를 앞에 두었다. G10의 개인 기술 사용 경험은 현장 기술 프로필로 교체했다. G3·G4에 응답 거부 선택지를 두고 G4에 20대 미만을 추가했으며, 나머지는 현장 기준과 표현을 정리했다.

| 구분 | 번호가 붙은 질문 수 | 실제 기본 응답 단위 | 설명 |
|---|---:|---:|---|

G7·G8의 기타 설명, G10 T7 종류 설명은 해당 시 각각 추가되는 선택적 서술 입력이므로 최대 3개가 더해진다. 실제 최대 입력 단위를 고정값으로 광고하지 않는다. R1 연월의 연·월은 각각 따로 된 문항이 아닌 날짜 입력의 구성요소로 센다. R4 T번호와 ‘판단 가능한 기술 없음’은 택일하여 1개이다. 조기 종료자는 이 합계보다 적게 답한다. **81은 본문항 수이지 총 응답 질문 수가 아니며, ‘총 91문항’이라고 표기하지 않는다.** 응답시간은 예비조사에서 측정하며 예상 분량만으로 소요시간을 단정하지 않는다.

## 4. 주요 내용 변경과 남는 한계

### X: 초기 위험조건을 묻되 혼합 개념 문제는 남는다

X1·X2의 공간·침하·하중 조건은 구체 위험에 초점을 맞추었다. C3은 자재 적치공간으로 좁혀 장비 배치공간이 빠졌으며, C19도 작업시간 제약으로 좁혀 공법 제약을 직접 묻지 않는다. 이 범위 축소가 허용되는지 전문가가 판단해야 한다. C8은 현장에 적용되는 가설시스템의 단계별 작업절차로 바꾸어 특정 클라이밍 장비를 필수로 전제하지 않았다.

C12(A X3-4)는 안전한 고소작업 접근 통로의 부재로 바꿨다. X3-5를 보류하면서 사라질 수 있는 고소·추락 동선 내용을 일부 보완한 것이며, 신호·줄걸이 작업자의 실제 추락노출을 온전히 대체한다고 볼 수 없다. C11은 실제 상하 동시작업 대신 계획 배치상의 분리 제약, C15는 착공 전 설계도서 불일치를 묻는다. X5는 실제 민원·변경 횟수에서 당시 예상 제약과 시간 여유로 옮겼다. 특히 C18의 인허가 불확실성은 단순 어휘 수정이 아닌 내용 변경이다.

물리적 위험노출과 계획·검토 부족을 X 안에 함께 두는 문제는 해결되지 않았다. 잔여 위험인지 초기 고유 위험인지도 정의가 더 필요하다. 문장을 같은 시점으로 썼다는 이유로 단일차원성이나 M과의 판별타당성이 생기는 것은 아니다. 위험조건과 계획 결함을 나눌지, 합성 지표로 정의할지 제2·3장에서 결정해야 한다.

### M: 설계정보의 환류 과정으로 경계 정리

M1은 DfS의 발견·평가·대책 선정·도서 반영·위험작업 제거를 구분했다. C25는 위험작업 자체의 제거로 범위를 좁혔으므로 대체까지 포함하는 원래 정의의 범위를 충분히 대표하는지 확인해야 한다. M2는 안전 관련 설계·시공 협의로 한정했고, M3는 DfS 저감대책 예산의 편성·우선배분·최신 계획 집행·재조정으로 맞췄다. M4는 계획 반영·전달·실제 적용·이행 확인을 나눴다.

M5 다섯 문항은 모두 해당 현장의 실제 경험에서 시작한다. C38 검토 요청, C39 개선안 확정, C40 수정 설계도서 반영, C41 사고·아차사고 교훈의 해당 현장 검토 기준 반영, C42 같은 현장 후속 작업구간 설계 검토 적용이다. 특히 C41·42는 조직 기준 및 다음 프로젝트 학습에서 같은 현장의 검토 기준과 후속 구간으로 바뀐 **내용 재개발**이다. 사고나 후속 구간이 없으면 낮은 역량이 아니라 관련 기회 없음으로 기록한다.

이 범위 변경은 조직 전체의 장기 학습역량을 측정하지 않는다. 동일 현장으로 맞춰도 횡단 응답에서 X→M→Y의 시간적 선후와 인과성이 확보되지 않는다. M5와 성과의 발생시점이 겹치는 문제를 추가로 검토해야 한다.

### W: 현장 이용 가능 역량과 사용자 관찰

W1·W2는 내·외부 전문자원을 포함하여, 도구·인력·모델을 한꺼번에 각각 평정하는 문제를 줄였다. W3는 적용 중인 모니터링 시스템을 기준으로 쓰고, C53은 R3의 주요 위험을 작업 중 상시 감시하는지 묻는다. 구조물과 작업환경을 동시에 만족해야 하는 문항을 피했지만 서로 다른 위험 유형의 점수가 같은 역량을 뜻하는지는 검증이 필요하다. W4는 단일 제품 보유가 아닌 정보 연계·판단 활용·검색·접근 기능을 묻는다.

W5의 C59~61은 R4에 선택한 동일 기술에 관한 **단일 응답자의 현장 사용자 관찰 대리지표**이다. 조작적 정의 후보는 ‘응답자가 직접 접한 현장 사용자의 유용성 발언, 지속적 활용, 기본 작업 수행의 용이성’이다. 구성원의 내면이나 조직 전체의 수용도를 응답자가 안다고 전제하지 않는다. C59는 유용성 인식 자체보다 그 인식이 표현된 발언을 접한 정도에 영향받을 수 있다. 선택 기술과 관찰 접촉 빈도의 차이도 남는다.

이 응답을 조직 수준 측정치라고 조용히 바꾸어 부를 수 없다. 관찰 가능한 사용자 범위, 복수 응답자 필요성, 동일 현장 응답의 집계 근거와 단일 정보제공자 편향을 검토해야 한다. 이론적으로 개인 수용을 측정하려면 문항과 분석단위를 다시 정해야 한다. W5의 조직 표준화·교육 지원은 이번 정의에 포함하지 않았다. 현장 W의 측정시점을 안내했어도 조직의 사전 역량이나 조절효과의 인과적 선행성을 입증한 것은 아니다.

### Y: 구체 성과와 새 총괄 평가를 구분

Y1은 오류·누락에 따른 설계변경과 재시공으로 범위를 제한하고, 일정을 지키기 위해 안전조치를 생략한 경우를 높은 성과로 읽지 않도록 했다. C66(A Y2-1)은 추락·낙하 ‘중점위험 관리’라는 추상 문구를 **낙하물 위험구역 출입통제**로 재개발했다. 추락 방호에 편중된 Y2를 보완하지만, 낙하물 방지망·고정 등 다른 통제수단까지 대표하는지는 내용 검토가 필요하다. Y3는 지시보다 실제 통제 시행과 시정 후 위험 통제 확인을 묻는다. Y4는 관찰 가능한 준수·보호구·신고·제안을 남겼다.

Y5의 C79~81은 각각 전반적 재해 노출 예방 달성, 주요 위험 통제 성공, 안전관리 결과의 도달 수준을 묻는 **새 주관적 총괄 평가 문항**이다. 사고율·사고건수, 관리체계 보유, 안전 분위기, 기록·공유 절차를 함께 묻지 않는다. 따라서 ‘정량적·정성적 통합성과’라는 원래 명칭·정의·근거를 그대로 사용할 수 없다. 사고율의 객관적 측정치로도 해석하지 않는다.

세 문항이 유사한 전체 평가라 서로 중복될 수 있고, Y1~Y4를 다시 요약한 상위 평가일 수도 있다. **Y5를 Y1~Y4와 동등한 별개의 차원으로 확정하거나, 다섯 요인을 모아 2차 요인이 성립한다고 보장하지 않는다.** 중복이 크거나 구별되는 내용이 없다면 Y5를 별도 외부 준거로 분리하는 대안을 검토한다. 이 경우 Y의 측정모형과 가설을 바꾸어야 하므로 81개 구성을 고정하지 않는다. 문항 수 유지를 위해 통계적으로 독립된 요인인 척해서는 안 된다.

## 6. 점수 방향과 결측·비해당 처리 초안

X는 높은 값일수록 위험노출 또는 계획 결함이 큰 방향이고, M·W·Y는 높은 값일수록 해당 환류·기술 적용·성과가 높은 방향이다. X를 자동으로 역채점하여 다른 변수와 합치지 않는다. **81개 전체 합계점수와 W 전체 주점수는 아직 산출 기준이 확정되지 않았다.**

응답 원자료에서 1~5의 평가값과 상태 필드를 분리한다. 모름은 `DK`, 해당없음은 `NA`, 비해당 사유는 기술미도입·공정/기회없음·사건없음·기타로 별도 보존한다. 숫자 6·7을 척도값으로 부여하지 않으며, 0·1·3으로 자동 대체하지 않는다. 빈칸은 모름·해당없음과 구분하여 무응답으로 남긴다. 예산이나 설계 자료에 접근하지 못하면 수행 부족이 아닌 모름이다.

G10의 기술 상태와 R5의 비해당 사유를 대조한다. 미도입 현장의 W를 기계적으로 0점 처리하지 않고, 서로 다른 기술 조합에서 관측된 문항만 평균 내어 동일한 전체 역량 점수로 간주하지 않는다. 기술은 있으나 해당 공정이나 사건이 없었던 경우, 할 수 있었지만 실제로 하지 않은 경우, 상황을 모르는 경우를 구분한다. 필요한 작업과 수행 기회가 있었으나 실제로 수행하지 않은 경우는 수행문항에서 낮은 평가가 될 수 있다. 관련 공정·사건이 없으면 비해당으로, 정보를 모르면 DK로 기록한다. G10은 조사기간의 상태이고 S2는 현장 도입 사실이므로 두 답변의 차이를 무조건 모순이라고 판정하지 않는다.

IoT만 사용한 현장 등에서는 W1·W2·W4 전체가 비해당이 될 수 있다. 따라서 다섯 하위요인으로 공통 W 점수를 바로 계산할 수 없다. **기술 적용 범위에 따른 채점·표본설계가 확정되기 전에는 본조사용으로 배포하지 않는다.**

하위요인 최소 유효 응답 수, 결측 처리법, 기술별 분석 대상, 비해당 과다 문항의 처리 기준은 내용 검토와 예비조사를 바탕으로 자료 수집 전에 정한다. 현재 초안에서 임의의 평균 대체·총점·합격점을 제시하지 않는다. 같은 응답을 연속 선택했다는 이유만으로 불성실 응답으로 배제하지 않는다.

## 7. 배포 전에 남은 결정

1. 제2·3장의 X 범위, M5 현장 내 환류, W의 현장 수준·관찰 대리지표 정의, 새 Y5의 위치를 승인하고 문항별 출처·수정·자체 개발 근거를 갱신한다. 앞선 문헌의 개념적 근거를 새 문장 검증으로 대체하지 않는다.
2. 기존 19개 하위요인에서도 축약으로 빠진 고유 내용과 반영형·형성형 또는 합성 측정 여부를 검토한다. Y5를 동등한 하위차원으로 둘지 외부 준거로 분리할지 정한다.
3. 수정된 모든 후보에 전문가 내용 검토를 실시한다. CVR을 사용할 경우 실제 평가자 수와 적용 기준을 명시하고, 특히 X3·M5·W5·Y2·Y5의 재개발 내용을 별도로 검토한다.
4. 인지면담으로 응답자가 떠올리는 현장·기간·자료, 기술미도입과 해당없음 구분, W5 관찰 가능성, Y5 세 문항의 중복을 확인한다. M1의 DfS 검토가 R1보다 앞서 완료되어 관련 기회 없음이 집중되는지도 점검하고, 필요하면 측정기간과 설계를 함께 조정한다. 예비조사는 실제 완료시간·피로·모름·비해당 빈도와 화면 동작을 확인하는 단계로 둔다.
5. 최종 척도에 맞추어 문항 수준 측정모형과 하위요인 평균 활용 분석을 구분하고, W 하위요인별 조절가설과 검증 경로를 일치시킨다. 표본 계획은 최종 모형·결측·상호작용 등에 근거해 재검토한다. 문항 수가 줄었다고 신뢰도나 필요한 표본 수가 확보되었다고 주장하지 않는다.
6. 조사대상 기준연도, 스마트 안전장비 적격 범위, 관찰기간 처리, 개인정보 안내와 실제 문의 이메일을 배포 전에 확정한다. 보존기간·윤리심의 승인·연락처를 확인 없이 만들어 넣지 않았다.

## 8. 파일 검증 기록

두 새 파일만 대상으로 본문 번호, A 안정 코드, 후보 영역별 개수, 상대 링크, UTF-8 및 문자 위생을 점검한다. 검증은 통계적 타당도 검증을 뜻하지 않는다. 실제 실행 결과는 아래에 기록한다.

- Python의 정규식·집합·개수 검증: 설문 번호 1~81 연속, 후보 영역 20개, X20·M22·W19·Y20을 확인했다.
- A안 행 추출 및 대응 검증: A 안정 코드 100개가 모두 고유하며 C1~C81 각각 한 번과 예비보류 19개로 정확히 연결되었다. X·M·W·Y의 보류 번호 집합이 지정된 목록과 일치했다.
- 입력·서식 검증: G 10개, S 2개, R 5개, 기술 행 7개를 확인했다. 조건부 사유란을 포함한 질문 표식은 98개이며 기본 입력 단위는 104개이다. 두 파일의 상대 링크 5개가 모두 실제 파일을 가리키고, 각 표의 열 수가 일정했다.
- 보존·인코딩 검증: 읽기 원본을 포함한 기존 Markdown 13개의 작업 전후 SHA-256이 일치했다. 새 두 파일의 UTF-8 디코딩이 통과했고 예기치 않은 포맷 문자(Cf)와 대체문자 U+FFFD가 없었다.
- 문자 검사 명령: `python -X utf8 .claude/skills/clean-user-facing-text/scripts/inspect_text.py --stylometry --json <파일>`을 두 초안에 실행했다. 검사 시점의 점수는 설문 0.0325, 대응표 0.1225로 둘 다 `density_tier: low`, 도구 표시 `confidence_level: CLEAN`이었다. 이 표시는 저자 판별이나 타당도 증거가 아니며, 점수 때문에 문장을 강제로 다시 쓰지 않았다.
- 결정적 정리 명령: `python -X utf8 .claude/skills/clean-user-facing-text/scripts/clean_text.py <파일> -o <임시출력> --stats --no-normalize-spaces`를 실행했다. 두 파일 모두 삭제 0개·치환 0개이며 임시출력과 입력 바이트가 같았다. 코드·표·문항번호·A 원문은 보존했다.

위 검증은 문서 구조와 파일 보존에 대한 증거이다. 신뢰도·요인구조·내용타당도 또는 실제 응답시간을 검증한 결과가 아니다.
