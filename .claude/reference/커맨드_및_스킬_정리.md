# 커맨드 및 스킬 정리 (논문 프로젝트 기준)

본 문서는 경기대 석사논문 프로젝트에서 활용 가능한 모든 스킬·슬래시 커맨드를 **논문 작업 관점**에서 재정리한다. 기존 `슬래시_커맨드_가이드.md`는 superpowers/gstack 두 시스템에 한정되어 있어, 본 문서는 ① 프로젝트 전용 스킬, ② 빌트인 커맨드, ③ 보조 스킬까지 포함하여 한 곳에 정리한다.

## 1. 프로젝트 전용 스킬 (가장 중요)

### 1.1 `write-academic-report` — 논문 자동 작성 스킬
**경로:** `.claude/skills/write-academic-report/SKILL.md`
**호출:** "write-academic-report 스킬 써서 …" 또는 SKILL.md를 직접 참조

#### 핵심 기능
- 40~100+페이지 학위논문을 **병렬 서브에이전트**로 작성 (8~12시간 → 2~4시간)
- 출력: Markdown(.md) → pandoc으로 HWP/DOCX/PDF 변환

#### 3-Wave 파이프라인
| Wave | 작업 | 병렬도 |
|------|------|--------|
| Wave 0 | 데이터 준비 (코드 분석, 통계 추출, 그림 생성) | 5~6 에이전트 동시 |
| Wave 1 | 챕터 작성 (각 장을 동시 집필) | 3~4 에이전트 동시 |
| Wave 2 | 조립 (병합, 교차참조 감사, 품질 검토) | 1~2 순차 |

#### 보조 스크립트
| 스크립트 | 용도 |
|----------|------|
| `scripts/citation_checker.py` | **인용 환각 방지** — CrossRef(140M DOI) → Semantic Scholar(200M) → OpenAlex(240M) 3단계 검증. verified / suspicious / not found 분류 |
| `scripts/cross_ref_audit.py` | 그림·표·식 번호 교차참조 누락·중복 감사 |

#### 절대 규칙
> **NEVER generate citation entries from memory.** 인용은 반드시 DB에서 가져오거나 `[CITATION NEEDED]`로 표시. 환각 인용은 학사 부정행위로 처리되는 추세 (NeurIPS 2025 100+건, 법정 제재 206건).

#### 본 논문 활용 시점
- **2026.6~7** 3장 완료 후 4장 통계분석 결과 자동 정리
- **2026.8~9** 4장 본문 자동 초안 생성
- 인용 작성 시 `citation_checker.py`로 사전 검증 (박종학·이준호 등 저자명 환각 방지)

## 5. 논문 작업 단계별 추천 조합 ★

각 항목은 **호출법 또는 명령어 → (줄바꿈) → 기능** 순으로 정리한다. 명령어 옆 (자동)은 사용자가 호출하지 않아도 Claude가 의도를 인식해 자동 발동되는 superpowers 스킬을, `/명령` 형태는 직접 호출이 필요한 gstack 슬래시 커맨드를 의미한다.

### 5.0 초기 환경 세팅 (한 번만, 2026.4 초)

`/init` (Claude Code 빌트인)
프로젝트 루트를 스캔해 CLAUDE.md를 자동 생성한다. 본 프로젝트는 이미 생성되어 있으며, 변경 시 `claude-md-management:claude-md-improver`로 품질을 감사한다.

`update-config` 스킬 — "settings.json 편집해줘" 또는 "hook 추가해줘"
settings.json에 hooks·권한·환경변수를 등록한다. "X 할 때마다 Y 자동 실행" 형태의 자동화는 메모리가 아닌 hooks로만 가능하다. 논문구조/ 외 편집 차단 hook, 인용 추가 시 citation_checker.py 자동 실행 hook을 등록한다.

`fewer-permission-prompts` 스킬 — "권한 프롬프트 줄여줘"
세션 transcript를 분석해 자주 쓰는 read-only 명령(ls, cat, grep 류)을 .claude/settings.json 화이트리스트에 자동 추가한다. 권한 프롬프트 노이즈를 제거해 집필 흐름이 끊기지 않게 한다.

`keybindings-help` 스킬 — "단축키 등록해줘"
~/.claude/keybindings.json을 편집해 자주 쓰는 슬래시 커맨드를 단축키 chord로 등록한다. `/context-save`·`/make-pdf` 등을 단축키화한다.

### 5.1 자료 수집·검증 (현재 단계, 2026.4~5)

`/connect-chrome` 또는 `/setup-browser-cookies`
사용자의 실제 Chrome 쿠키를 헤드리스 세션에 import해 RISS·DBpia·국회도서관 로그인 상태를 그대로 이전한다.

`/browse`
Chromium 영속 세션으로 페이지 탐색·요소 클릭·스크린샷·다이얼로그 처리를 명령당 약 100ms 수준에서 수행한다. 학위논문 PDF 자동 수집, 인용 페이지 실제 캡처에 활용한다.

`dispatching-parallel-agents` (자동)
공유 상태 없는 독립 작업 2개 이상을 병렬 서브에이전트로 동시 실행한다. 5개 키워드(YOLO·LLM·alarm fatigue·frugal innovation·TAM)를 5개 DB에서 한 번에 검색해 자료 수집 시간을 압축한다.

`superpowers:brainstorming` (자동)
구현 전 요구사항·의도·설계 옵션을 탐색한다. 2장 절별 논지 트리와 장(章)별 메시지 라인을 잡는 데 쓴다.

`mcp__plugin_context7_context7__query-docs` — "Context7으로 X 라이브러리 문서 가져와줘"
Context7 MCP로 라이브러리·프레임워크 최신 공식 문서를 fetch한다. 학습 데이터 cutoff(2026.1) 이후 변경을 보완하므로, YOLO·OpenCV·Ultralytics 최신 버전 사양 인용 시 정확도를 보장한다.

`/investigate`
Iron Law(근본원인 없이는 fix 금지) 4단계(investigate→analyze→hypothesize→implement)로 작동한다. 인용 환각(예: 박종학 ↔ 문유미 혼동)의 root cause를 추적한다.

`python scripts/citation_checker.py <인용목록>`
CrossRef(140M DOI) → Semantic Scholar(200M) → OpenAlex(240M) 3단계 fallback으로 verified/suspicious/not_found 분류. 의심 인용은 본문에 [CITATION NEEDED]로 마킹한다.

### 5.2 설문 설계·FGI (2026.4~5 병행)

`superpowers:brainstorming` (자동)
측정 문항의 구성타당도·내용타당도 옵션을 탐색한다. 20문항(X1~X4 8 + M 2 + W 2 + Y 8) 도출에 사용한다.

`/plan-eng-review`
아키텍처·데이터 흐름·엣지케이스·리스크를 인터랙티브하게 압박한다. 본래 코드 검토용이지만 측정모형의 다중공선성·횡단편향 사전 점검에도 그대로 적용된다.

`/codex` (challenge 모드)
OpenAI Codex CLI로 "이 가설은 어떻게 깨질 수 있나"를 적대적으로 묻는 2차 의견. 가설 4-1·4-2 조절 방향성(예산 제약↑ → 효과↑)의 반례 점검에 쓴다.

### 5.3 장(章) 집필 계획 (각 장 시작 시)

`superpowers:writing-plans` (자동)
코드 변경 전 마크다운 계획서를 강제한다. 단계·체크포인트·검증 절차를 명시하므로, 각 장 절 단위 집필 plan.md(선행연구 인용 매핑 포함)를 만든다.

`/plan-ceo-review`
4모드(SCOPE EXPANSION / SELECTIVE / HOLD / REDUCTION)로 "10배 더 의미있는 버전"을 강제 탐색한다. 2장 절 구성 재검증, "Frugal Innovation을 어디까지 끌어올릴 것인가" 결정에 쓴다.

`/plan-eng-review`
논리 구조·엣지케이스·다이어그램·테스트 커버리지를 인터랙티브 점검한다. 3장 가설 1-1~4-2와 통계검정 매핑 누락을 색출한다.

`/plan-tune`
누적 질문 패턴을 학습해 "이 질문은 항상 묻기/절대 묻지 않기"식 톤을 조절한다. 박종용 가이드 톤(능동형 서술·두괄식)에 맞춘 질문 빈도를 튜닝한다.

`/autoplan`
CEO → Design → Eng review를 6개 결정 원칙으로 자동 일괄 처리하고 taste 결정만 최종 게이트에 노출한다. 장 통합 리뷰 1회 일괄 실행에 사용한다.

### 5.4 본격 집필 (2026.6~9)

`/freeze 논문구조`
편집 영역을 단일 디렉토리에 잠가 외부 편집을 차단한다. 다른 디렉토리에 초안이 흘러가는 사고를 원천 차단한다(CLAUDE.md 작성 규칙 준수).

`write-academic-report` 스킬 — "write-academic-report 스킬로 X장 작성해줘"
3-Wave 파이프라인. Wave 0(데이터·그림 5~6 병렬) → Wave 1(챕터 3~4 병렬) → Wave 2(조립·교차참조·QA 1~2 순차). 4장 통계 결과·그림 자동 정리, 절 단위 markdown 초안 생성에 활용한다.

`superpowers:subagent-driven-development` (자동)
독립 작업을 서브에이전트에 위임하면서 메인 컨텍스트를 보호한다. 1·2·3장 동시 집필, 각 절을 독립 에이전트가 작성하는 구조다.

`superpowers:test-driven-development` (자동, 코드 한정)
통계분석 스크립트 작성 시 테스트 우선 작성을 강제한다. 매개효과 검정(PROCESS macro 모델 4) 단위 테스트를 먼저 정의한 뒤 구현한다.

`mcp__ide__executeCode` — Jupyter 셀 실행 요청 시 자동 활용
Jupyter 커널에서 즉시 실행, 변수 상태가 세션 동안 영속. SPSS/Python으로 빈도분석·Cronbach α·다중회귀를 즉시 계산해 결과를 본문에 바로 삽입한다.

`frontend-design:frontend-design` 스킬 — "연구모형도 만들어줘"
생성 AI 슬롭(slop) 패턴을 회피한 고품질 컴포넌트 생성. 4장 그림(연구모형도, 매개·조절 효과 도식)을 고품질 SVG로 만든다.

`python scripts/citation_checker.py`
본문에 새로 추가되는 인용을 사전 검증해 환각 인용을 차단한다(NeurIPS 2025 학사 부정 100+건 사례 회피).

`python scripts/cross_ref_audit.py`
그림·표·식 번호의 누락·중복·끊긴 참조를 자동 감사한다. "그림 3-1" 본문 언급과 실제 삽입의 정합성을 보장한다.

### 5.5 초안 검토·교정 (각 장 완성 후)

`/review`
base branch 대비 diff에서 SQL 안전·LLM 신뢰경계·조건부 부작용 등 구조적 결함을 탐지한다. 논문 diff 검토로 전용해 신규 추가 절의 약한 인과 주장과 미인용 문장을 색출한다.

`superpowers:requesting-code-review` (자동)
작업 완료 후 요구사항 충족 검증을 강제한다. 가설번호 ↔ 본문 검정결과 매핑 누락을 검증한다.

`/codex` (review/consult 모드)
독립적 2차 의견, session continuity로 follow-up 가능. "Frugal Innovation 인용이 RBV와 충돌하지 않는가" 같은 핵심 논지를 cross-model로 검증한다.

`/investigate`
발견된 문제의 근본원인을 추적하고 표면 수정을 금지한다. 환각 인용이 발견되면 어느 단계에서 주입됐는지 거슬러 올라간다.

`superpowers:verification-before-completion` (자동)
"완료/통과" 주장 전 검증 명령 실행 + 출력 확인을 강제한다. "인용 검증 완료" 보고 전 citation_checker 결과 첨부를 강제한다.

`simplify` 스킬 — "이 절 단순화해줘"
변경 부분의 재사용성·중복·품질을 검토해 정리한다. 박종용 가이드의 "동일 표현 반복 자제" 원칙에 부합한다.

`superpowers:receiving-code-review` (자동)
받은 리뷰를 무비판 수용하지 않고 기술적 엄밀성으로 재검토한다. 지도교수 코멘트 수용 vs 근거 기반 재반박을 판단한다.

### 5.6 세션 관리·학습 누적 (상시)

`/context-save`
작업 중 git 상태·결정 사항·남은 작업을 단일 파일에 저장한다. 장 전환 시 워크스페이스 핸드오프에 사용한다.

`/context-restore`
가장 최근 저장 상태를 브랜치 무관하게 복원한다. 다음 세션에서 즉시 이어쓰기가 가능하다.

`/learn`
세션 간 학습 패턴(자주 묻는 질문, 반복 실수)을 .gstack/learn에 누적한다. 박종용 가이드·인용 형식·저자명 환각 사례를 누적 학습시킨다.

`claude-md-management:revise-claude-md` 스킬 — "이번 세션 학습을 CLAUDE.md에 반영해줘"
세션 종료 시점 학습을 CLAUDE.md에 반영한다. "박종학·문유미 혼동 패턴" 같은 새 발견을 추가한다.

`claude-md-management:claude-md-improver` 스킬 — "CLAUDE.md 감사해줘"
CLAUDE.md 품질 감사·템플릿 비교·개선 제안. 분기별 정합성 점검에 쓴다.

`/health`
코드 품질 대시보드(타입체커·린터·테스트·dead code)를 가중 점수로 산출한다. 통계분석 코드 품질 트렌드를 추적한다.

`/retro`
커밋 이력·작업 패턴·품질 메트릭 기반 주간 회고. 장(章) 완성 후 작업 시간·집필량을 회고한다.

### 5.7 발표·심사 준비 (2026.10~11)

`/make-pdf`
마크다운 → 출판 품질 PDF 변환. 1인치 마진, 페이지 번호, 표지, 러닝헤더, 곡선 따옴표, em dash, 클릭 가능 TOC, DRAFT 워터마크 자동 적용. 심사 제출본 PDF 초안(DRAFT 워터마크 단계)을 만든다.

`pandoc -f markdown -t docx` (write-academic-report 보조)
Markdown → DOCX/HWP 변환. 경기대 석사 양식 HWP 최종본을 산출한다.

`superpowers:brainstorming` (자동)
발표 슬라이드 메시지 라인, 예상 질문, 반론을 시뮬레이션한다. 공개발표 Q&A 대비에 사용한다.

`/codex` (challenge 모드)
적대적 모드로 발표 논지 깨기 시도. 디펜스 핵심 방어 논리(CLAUDE.md 8섹션)를 사전 검증한다.

`/office-hours`
YC식 6개 강제 질문(수요·현상·구체성·웨지·관찰·미래적합성). 연구 기여도 최종 자체 점검에 사용한다.
