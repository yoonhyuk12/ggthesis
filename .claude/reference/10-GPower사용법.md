## 2. 화면 용어 번역표

| 화면의 영어 | 뜻 | 넣을 값 | 왜 이 값인가 |
|:---|:---|:---|:---|
| Test family | 검정 계열 | **F tests** | ANCOVA는 F라는 값으로 판정하는 분석이다. 여기서 F를 골라야 다음 칸에 ANCOVA가 나타난다. |
| Statistical test | 통계 검정 방법 | **ANCOVA: Fixed effects, main effects and interactions** | 우리 분석이 바로 이것이다. 이름이 길지만 두 집단을 비교하면서 공변량을 통제하는 분석이 이 항목이다. |
| Type of power analysis | 분석 유형 | **A priori: Compute required sample size** | 조사 전에 "몇 명 받아야 하나"를 구하는 것이므로 사전(A priori)이다. Post hoc은 조사를 마친 뒤에 쓰는 것이라 지금은 아니다. |
| Effect size f | 효과크기 | **0.40** | 두 집단의 차이가 클 것으로 보기 때문이다. 제3장에서 오경보 98.44% 감소를 실측했고 선행연구도 도입 효과를 크게 보고한다. 값을 정하는 방법은 3절 참조. |
| α err prob | 유의수준 | **0.05** | 사회과학 논문의 관례다. 실제로는 차이가 없는데 있다고 잘못 말할 위험을 5%까지만 허용하겠다는 뜻이다. |
| Power (1−β err prob) | 검정력 | **0.80** | 이것도 관례다. 차이가 실제로 있을 때 그것을 놓치지 않고 잡아낼 확률을 80%로 잡겠다는 뜻이다. |
| Numerator df | 분자 자유도 | **1** | 비교하는 집단 수에서 1을 뺀 값이다. 두 집단이므로 2 − 1 = 1이다. |
| Number of groups | 집단 수 | **2** | 도입 현장과 미도입 현장, 두 집단을 비교하기 때문이다. |
| Number of covariates | 공변량 개수 | **6** | 통제할 항목이 소속·성별·연령·경력·직위·공사금액 규모로 6개이기 때문이다. [확정 필요: 공변량 축소 시 이 숫자도 함께 바꾼다] |
| Calculate | 계산 실행 | 마지막에 누르는 버튼 | 값을 다 넣은 뒤 눌러야 결과가 나온다. |
| **Total sample size** | **필요한 전체 표본 수** | **← 이것이 결과다** | 두 집단을 합한 인원이다. 집단당 인원은 이 값을 2로 나눈다. |
| Actual power | 실제 확보되는 검정력 | .80 이상이면 정상 | 넣은 값대로 계산이 잘 됐는지 확인하는 칸이다. 0.80보다 낮으면 어딘가 잘못 넣은 것이다. |
| Determine => | 효과크기 보조 계산기 | 지금은 쓰지 않아도 된다 | 효과크기를 직접 정하기 어려울 때, 선행연구의 평균과 표준편차를 넣어 역산하는 보조 도구다. |
| Protocol of power analyses | 분석 기록 탭 | 결과 저장용 (7절 참조) | 계산에 쓴 조건과 결과가 글로 남는 곳이다. 심사 증빙으로 저장해 둔다. |

## 3. ⚠ 가장 흔한 실수 — f와 d는 다른 값이다

**ANCOVA 화면은 효과크기를 `d`가 아니라 `f`로 받는다.** 논문이나 교과서에서 본 d 값을 그대로 넣으면 표본 수가 네 배로 잘못 나온다. 두 집단 비교에서는 다음 관계가 성립한다.

> **f = d ÷ 2**

| Cohen(1988) 기준 | d (t-검정에서 쓰는 값) | **f (ANCOVA 화면에 넣는 값)** |
|:---|:---:|:---:|
| 작은 효과 | 0.20 | **0.10** |
| 중간 효과 | 0.50 | **0.25** |
| 큰 효과 | 0.80 | **0.40** |

이 논문은 제3장에서 오경보 98.44% 감소를 실측했고 선행연구도 도입 효과를 뚜렷하게 보고하므로 **큰 효과(f = 0.40)** 를 1차 기준으로 삼는다. 다만 보수적 검토를 위해 **중간 효과(f = 0.25)** 도 함께 계산하여 두 값을 비교해 둔다.

## 4. 단계별 조작 순서

1. 프로그램을 실행한다.
2. 맨 위 **Test family**에서 `F tests`를 고른다.
3. **Statistical test**에서 `ANCOVA: Fixed effects, main effects and interactions`를 고른다.
4. **Type of power analysis**에서 `A priori: Compute required sample size`를 고른다.
5. 왼쪽 아래 입력란에 2절 표의 값을 차례로 넣는다.
6. 오른쪽 아래 **Calculate** 버튼을 누른다.
7. 오른쪽 출력란의 **Total sample size** 숫자를 읽는다.
8. `Effect size f`만 0.25로 바꾸고 다시 Calculate를 눌러 두 번째 값도 기록한다.

## 5. 결과 해석

계산이 끝나면 다음을 확인한다.

- **Total sample size** — 두 집단을 합한 전체 필요 인원이다. 집단당 인원은 이 값을 2로 나눈다.
- **Actual power** — 실제로 확보되는 검정력이다. 0.80 이상이면 정상이다.
- **Noncentrality parameter λ**, **Critical F**, **Denominator df** — 논문에 함께 보고하면 근거가 두터워진다.

산출값은 실행 후 이 문서에 기록한다.

| 조건 | Total sample size | 집단당 | Actual power |
|:---|:---:|:---:|:---:|
| f = 0.40 (큰 효과) | [DATA PENDING: 실행 후 기입] | | |
| f = 0.25 (중간 효과) | [DATA PENDING: 실행 후 기입] | | |

> **⚠ 함께 확인할 것:** Green(1991) 규칙을 적용하면 예측변수가 7개(집단 1 + 공변량 6)이므로 N ≥ 50 + (8 × 7) = 106명이 필요하다. G*Power 산출값이 이보다 작게 나오더라도, 공변량 6개를 유지한다면 **둘 중 큰 값**을 목표 표본으로 삼아야 방어가 된다. 공변량을 3개로 줄이면 이 기준이 82명으로 내려간다. [확정 필요: 공변량 축소 여부]
