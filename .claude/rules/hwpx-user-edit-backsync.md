# Rule: hwpx 사용자 직접 편집분의 MD 역동기화

## Principle

**사용자가 한글에서 hwpx를 직접 고치면, 바뀐 부분을 찾아 MD에도 같은 내용으로 반영한다(2026-11-05 사용자 지시).** MD는 단일 원본이고 hwpx는 MD를 따라가는 사본이다. 그런데 사용자가 한글에서 고친 내용이 MD에 없으면, 다음 반입이나 재조립 때 그 수정이 지워지거나 두 원고가 어긋난다. 그래서 따로 시키지 않아도 역동기화한다.

## 기준 스냅샷

- Claude가 `00. hwpx/`에 산출물을 저장할 때마다 **같은 파일명으로 `tools/hwpx_transfer/staging/hwpx_snapshots/`에 복사본을 남긴다**(gitignore 대상). 이 복사본이 "Claude가 마지막으로 넘긴 상태"이다.
- 역동기화 뒤에는 그 시점의 사용자 저장본으로 스냅샷을 갱신한다. 그래야 다음 대조에서 새 편집만 나온다.
- 스냅샷이 없으면 git HEAD 판(`git show HEAD:"00. hwpx/<파일>"`)을 기준으로 쓴다. 그것도 없으면 직전 접두사 파일을 쓰되, Claude가 그 사이에 바꾼 부분이 섞이므로 MD와 일일이 대조해 사용자 편집만 가려낸다.

## 언제 시작하나

- 사용자가 "한글에서 직접 고치고 있다"·"한글에서 수정했다"고 말할 때. 편집 중이면 `00. hwpx/`의 수정 시각을 감시하는 백그라운드 명령을 띄우고, 저장이 감지될 때마다 아래 절차를 돈다.
- 세션 시작 훅(`session_brief.py`)이 **"사용자 편집 감지"**를 알릴 때. 접두사 최신본의 SHA256이 스냅샷과 다르다는 뜻이다.
- `log.md`에 Claude가 하지 않은 `00. hwpx/… 수정` 기록이 있을 때.

## 절차

1. **대조:** `python tools/hwpx_transfer/hwpx_text_diff.py <스냅샷> <사용자 저장본>`. 파일이 한글에 열려 잠겨 있어도 읽기 복사는 되므로 스크래치에 복사해서 쓴다. hwpx MCP 읽기 도구는 쓰지 않는다(2.5MB 본문에서 멈춘다).
2. **분류:** 바뀐 문단마다 아래 중 하나로 판정한다.
   - **내용 변경**(문장·수치·용어·표 셀 글자·캡션·제목): MD의 해당 위치를 찾아 **사용자 문구 그대로** 반영한다. 다듬거나 되돌리지 않는다.
   - **표 셀 안 문단 나눔**(글자는 같고 한 셀 문단이 여러 문단으로 나뉘거나 합쳐진 것): MD 표는 셀 안 줄 나눔을 `<br>`로 적으므로 같은 위치에 `<br>`를 넣거나 뺀다. 반영하지 않으면 재조립·반입 때 나눔이 사라진다(2026-11-05, <표 4-4> 종속변수 근거 셀 첫 사례).
   - **목차 쪽수·조판 전용**(점선 목차 쪽 번호, 빈 문단, 본문 문단의 줄바꿈 위치만 바뀐 것): MD는 바꾸지 않는다.
   - **마커 해소**(`[확정 필요`·`[CITE_TODO` 등을 지우고 본문을 채운 것): MD에서도 같은 마커를 지우고 채운 문장을 넣는다.
   - **MD 위치를 특정할 수 없는 변경**(한글 문서에만 있는 표지·감사의 글 등): MD에 대응 위치가 없으면 바꾸지 않고 보고에 적는다.
3. **파급:** 바뀐 수치·용어·번호는 [장 간 일관성 규칙](cross-chapter-consistency.md)에 따라 `01.docs/` 전체를 grep한다. 기계적 정합(같은 수치·용어의 다른 출현)은 같은 턴에 함께 맞춘다. 다른 장 문단을 다시 써야 할 정도면 보고 후 승인을 받는다.
4. **hwpx는 건드리지 않는다.** 역동기화는 MD 쪽 작업이다. 파급 때문에 hwpx의 다른 곳도 바꿔야 하면 사용자에게 알리고 지시를 기다린다. 사용자가 편집 중인 파일에 쓰면 저장 충돌이 난다.
5. **스냅샷 갱신**과 함께 보고한다: 바뀐 문단별로 "hwpx 변경 → MD 반영 위치(파일:줄)", 반영하지 않은 것과 그 이유.

## Anti-Patterns

- **Don't** 사용자 편집이 MD와 다르다고 hwpx를 MD 기준으로 되돌리기. 사용자 편집이 우선이다.
- **Don't** 사용자 문구를 반영하면서 "더 낫게" 고치기. 고칠 점이 보이면 반영은 그대로 하고 보고에서 따로 제안한다.
- **Don't** 서식만 바뀐 변경(글꼴·열폭·쪽 나눔)을 MD에 옮기기. MD는 서식 정보를 갖지 않는다.
