# dumbify — 쉬운 말로 고치기

## 원칙

**내용과 주장은 한 글자도 바꾸지 않고, 낱말과 문장 모양만 쉽게 바꾼다.** 읽는 사람이 중학생이라고 생각하고 고친다.

## 입력

- `/dumbify <글>` → 그 글을 고친다.
- `/dumbify <파일 경로나 장·절>` → 그 부분을 읽어 고친 결과를 대화에 보여준다. **파일은 사용자가 "반영해"라고 할 때만 고친다.** 반영할 때는 `01.docs/` MD만 고치고 hwpx는 따로 지시를 기다린다.
- 대상이 없으면 무엇을 고칠지 한 줄로 묻는다.

## 고치는 규칙

1. **단어만 쉬운 말로.** 사실·수치·주장의 세기(단정/추정)·논리 순서는 그대로 둔다.
2. **한자어·영어 전문용어 → 중학생이 아는 말.** 꼭 써야 하는 용어(변수명, 분석 방법, 법령 용어 등)는 남기고 같은 문장 안에서 풀어 쓴다.
   - 예: "공분산분석(ANCOVA)" → "공분산분석(ANCOVA, 다른 조건의 영향을 빼고 두 집단 평균을 비교하는 방법)"
3. **번역투 → 일상 말투.** `~에 있어서` → `~에서`/`~할 때`, `~를 통해` → `~로`/`~해서`, `~에 대한` → `~의`/풀어 쓰기, `~되어진다` → `~된다`, `~할 수 있을 것이다` → `~할 수 있다`(추정의 세기는 유지).
4. **한 문장에 생각 하나.** 생각이 둘 이상이면 나눈다.
5. **40자 넘으면 둘로.** 공백 포함 40자를 넘는 문장은 나눈다. 나눈 뒤 이어 주는 말(그래서, 그런데, 이때)을 넣어 흐름을 살린다.
   - 문장 끝 괄호 속 통계값·인용(`(p=.005)`, `(95% CI [0.17, 0.91])`, `(김철수, 2024)`)은 40자 셈에서 뺀다. 그 주장 문장에 그대로 붙여 두고 따로 떼어 내지 않는다.
   - 용어 풀이를 같은 문장에 넣으면 40자를 넘을 때는 **바로 다음 문장**에서 푼다("공분산분석은 ~하는 방법이다").

## 그대로 둘 것

- 숫자·통계값(`p = .003`, `73명`), 표·그림·장·절 번호(`<표 4-13>`, `제2장`)
- 인용 표기(`(김철수, 2024)`, `[38, 41]`)와 고유명사(YOLO, LLM, jamovi)
- 미완성 표시 `[CITE_TODO …]`·`[확정 필요 …]`·`[DATA PENDING …]`·`[UNVERIFIED …]`·`실험전` — 글자 그대로
- 논문에서 정한 용어: `현장소장(관리감독자)`, `안전관리 실효성` 등 변수 이름

## 출력 형식

1. **고친 글** — 원문과 같은 문단 구분으로.
2. **바뀐 단어** — 짧은 표 하나. 같은 바꿈은 한 번만 적는다.

| 원문 | 바꾼 말 |
| --- | --- |
| 실효성 제고에 있어서 | 실제 효과를 높이는 데 |

문장을 나눈 곳은 표에 넣지 않고, 표 아래에 "문장 나눔 N곳"으로 한 줄만 적는다.

## 흔한 실수

| 실수 | 바로잡기 |
| --- | --- |
| 쉬운 말로 바꾸다 주장을 세게 만든다 ("차이가 있었다" → "좋아졌다") | 세기와 방향을 그대로. 이 논문은 횡단 비교라 시간·인과 표현("향상", "개선시켰다")은 특히 쓰지 않는다 |
| 쉽게 하려고 문장이나 근거를 뺀다 | 빼지 않는다. 길면 나눈다 |
| 변수 이름·분석 방법 이름까지 바꾼다 | 이름은 남기고 옆에서 풀어 쓴다 |
| 인용 괄호가 문장을 나눈 뒤 엉뚱한 문장에 붙는다 | 인용은 그 내용을 담은 문장 끝에 남긴다 |
| 바뀐 단어 표가 고친 글만큼 길어진다 | 대표 바꿈만, 겹치는 것은 한 번 |
