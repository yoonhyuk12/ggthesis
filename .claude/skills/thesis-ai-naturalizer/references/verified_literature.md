# Verified Literature Grounding

Use this reference as a citation-safety workflow, not as a fixed bibliography. Each user or public fork should replace this file with a checked source pool for the target topic.

## Source Pool Template

For each verified source, record:

- full citation
- DOI, stable URL, ISBN, or database record
- topic keywords
- methods or data type
- what claim the source can support
- what claim the source cannot support
- useful quotation or page number, if legally and practically available

## LIS Search Targets

For Library and Information Science work, useful search areas include:

- library service quality
- information-seeking behavior
- electronic resource use
- digital library systems
- information literacy education
- academic database access
- metadata, classification, and indexing
- discovery systems and user experience
- institutional repositories
- research data management

Use field databases and indexes appropriate to the task, such as LISTA, LISA, ERIC, Web of Science, Scopus, KCI, RISS, KISS, DBpia, and Google Scholar.

## Use Rules

- Do not add a source unless it has been checked from a reliable record or full text.
- Do not claim a study analyzed a specific university, dataset, platform, or country unless it actually did.
- Do not claim statistical significance, sample size, methods, or findings unless verified.
- Do not use a citation only because its title sounds relevant.
- If a source is only partially verified, label it as partial and avoid making strong claims from it.

## Literature-To-Paragraph Pattern

Convert literature into thesis prose with this structure:

1. define the local problem or concept
2. cite the source for a specific point
3. explain how the source relates to the user's data or topic
4. state the limitation or gap
5. connect to the next variable, research question, or chapter

This prevents author-list summaries and makes the paragraph feel like research reasoning rather than generated prose.
