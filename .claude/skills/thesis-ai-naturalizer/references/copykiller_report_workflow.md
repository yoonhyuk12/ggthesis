# CopyKiller Report-Guided Workflow

Use this workflow for legitimate academic revision after the user provides a CopyKiller AI detail report. The goal is to identify mechanical writing risks and improve the thesis with real evidence, local context, and academic reasoning.

## 1. Extract The Report

Use text extraction first. If extraction fails, render pages or inspect screenshots visually.

Look for:

- total AI-generation risk score
- marked high-risk paragraphs or sentences
- nearby section headings
- repeated risk zones across chapters
- report text that may come from an older draft

## 2. Map Report Text To The Draft

Do not rewrite blindly. Build a paragraph index from the current draft and map each report marker to:

- exact current paragraph, if it still exists
- structurally similar paragraph, if the report used an older draft
- chapter-level risk zone, if the report only gives partial context

Prioritize marked paragraphs and repeated structural problems.

## 3. Diagnose Failure Mode

Classify the problem before editing:

1. wrong section job
2. claim without evidence
3. evidence without a clear claim
4. broad definition with no local context
5. author-list literature review
6. symmetrical or template-like sentence rhythm
7. generic conclusion or contribution claim

Only polish sentences after the paragraph logic is fixed.

## 4. Revise The Paragraph

For each marked paragraph:

- preserve correct data and citations
- replace broad definitions with thesis-specific scenes
- turn model exposition into a reason for the thesis variables
- turn literature lists into a gap map
- add the author's interpretation
- vary sentence length and structure
- remove generic connectors and template endings

Useful LIS anchors include library systems, electronic resources, search behavior, authentication, database access, discovery tools, user education, service quality, and information literacy.

## 5. Preserve Academic Integrity

Never:

- fabricate references
- alter survey or interview data without evidence
- invent significance results
- promise a detector score
- make the thesis casual or nonacademic just to look less mechanical

## 6. Final Check

Check for:

- unmapped report markers
- invented-looking citations
- unsupported claims
- repeated generic transitions
- missing section headings
- accidental changes to numbers, citations, tables, or figures

Report the revised sections, evidence used, and remaining verification gaps.
