## 2. 장·절·항 ���목 체계

### 2.1 번호 표기 규칙

```
제 N 장  장 제목        ← 장(Chapter): 숫자 양쪽 공백, 제목도 자간 넓힘
 제 N 절  절 제목       ← 절(Section): 동일 공백 규칙
  제 N 항  항 제목      ← 항(Subsection): 동일
   1. 소제목             ← 세부항목: 아라비아 숫자 + 점
    (1) 세세항목         ← 괄호 숫자
     ① 최소 단위        ← 원문자 또는 가. 나. 다.
```

**핵심 규칙:**
- `제`와 숫자 사이, 숫자와 `장/절/항` 사이 **모두 한 칸 공백**: `제 1 장`, `제 2 절`, `제 3 항`
- 장 제목에서 한글 제목도 자간 넓힘: `서 론`, `이론적 배경`
- 장 제목은 **가운데 정렬 또는 좌측 정렬** (논문에 따라 다름, 좌측 정렬이 다수)
- 절·항 제목은 **좌측 정렬, 굵게(Bold)**
- 각 장(Chapter)은 **새 페이지에서 시작**

### 2.2 목차 점선 형식

```
제 1 장  서 론 ·························· 1
  제 1 절  연구 배경 및 필요성 ············ 1
    제 1 항  전업종 산업재해 현황 ·········· 5
```

- 점선(`·····`)으로 제목과 페이지 번호 연결
- 장: 좌측 정렬, 절: 약간 들여쓰기, 항: 더 들여쓰기

## 3. 표(Table) 양식

### 3.1 표 번호 체계

```
<표 장번호-일련번호> 표 제목
```

- **꺾쇠괄호 `< >`** 사용 (10편 모두 일관)
- 장이 바뀌면 일련번호 **초기화** (예: 2장의 표 = `<�� 2-1>`, `<표 2-2>`..., 4장 = `<표 4-1>`...)
- 표 번호와 제목 사이 **공백 1칸**

### 3.2 표 제목 위치

> **표 제목은 항상 표 위(상단)에 가운데 정렬** (10편 모두 일관)

```
              <표 4-1> 빈도분석(Typical characteristics of respondents)

┌───────┬──────────┬────────┬──────────┬─────────────┐
│ 구분  │  항목    │ 빈도   │ 비율(%)  │ 누적비율(%) │
├───────┼──────────┼────────┼──────────┼─────────────┤
│       │ 남성     │  221   │  89.8    │    89.8     │
│ 성별  ├──────────┼────────┼──────────┼─────────────┤
│       │ 여성     │   25   │  10.2    │   100.0     │
└───────┴──────────┴────────┴──────────┴─────────────┘
```

### 3.3 표 제목 영문 병기

통계 결과표에서는 **영문 부제목을 괄호 안에 병기**하는 것이 일반적:

```
<표 4-1> 빈도분석(Typical characteristics of respondents)
<표 4-5> 신뢰도 분석 Item Reliability Statistics
<표 4-8> Omnibus ANOVA Test - 회귀모형에 대한 분산분석(N=232)
<표 4-9> Model Coefficients - 독립변수가 종속변수에 미치는 영향(N=232)
```

### 3.4 표 내부 디자인 — 2가지 유형

**유형 A: 통계 결과표 (3선 스타일)**
- 맨 위: 굵은 실선
- 헤더 아래: 단 실선
- 맨 아래: 단 실선
- 내부 세로선: 없음 (깔끔한 학술 스타일)
- 적용: 회귀분석, 상관관계, 기술통계 등 JAMOVI 출력 기반 표

**유형 B: 내용 정리표 (격자 스타일)**
- 헤더 행: **회색 음영(shading)** 처리
- 모든 셀에 실선 테두리 (격자 구조)
- 구분 열의 대분류는 **셀 병합(rowspan)** 사용
- 적용: 선행연구 요약, 조작적 정의, 설문지 구성, 법령 비교 등

### 3.5 출처 표기 방식

| 방식 | 형식 | 사용 빈도 |
|------|------|----------|
| 각주 번호 연결 | `<표 2-1> 5년간 업종별 사망사고 현황⁸⁾` | **가장 많음** |
| 표 하단 직접 표기 | `※ 출처 안전보건공단의 산업재해현황분석` | 일부 사용 |
| 표 내부 출처 열 | 설문 출처를 표 안 별도 열로 기재 | 설문지 구성표에 사용 |
| 출처 미표기 | 자체 조사/분석 데이터 | 4장 통계표 전반 |

### 3.6 단위 표기

표 제목 아래 오른쪽 정렬로 별도 행에 표기:
```
<표 2-4> 공사종류 및 규모별 산업안전보건관리비 계상기준표
                                              (단위: 원)
```

### 3.7 유의수준 표기 (통계표 하단)

```
*p<.05  **p<.01  ***p<.001
```
또는
```
Note. * p < .05, ** p < .01, *** p < .001
```

- 표 하단 **좌측 정렬**
- 상관관계표, 회귀분석표에 반드시 포함

### 3.8 모형 적합도 표기 (회귀분석표 하단)

```
Model Fit Measures R²=0.509, Adjusted R²=0.503, F=83.7(p<0.001), DW Statistic=1.39
```

## 4. 그림(Figure) 양식

### 4.1 그림 번호 체계

```
<그림 장번호-일련번호> 그림 제목
```

- 표와 동일하게 **꺾쇠괄호 `< >`** 사용
- 장이 바뀌면 일련번호 초기화

### 4.2 그림 제목 위치

> **그림 제목은 항상 그림 아래(하단)에 가운데 정렬** (10편 모두 일관, 표와 반대)

```
    [연구모형 박스+화살표 다이어그램]

        <그림 3-1> 연구모형
```

### 4.3 출처 표기

| 방식 | 형식 | 예시 |
|------|------|------|
| 제목 내 괄호 | `<그림 2-5> 영국 BCIS 모델(BCIS, 2006)` | 외부 자료 직접 인용 |
| 각주 번호 | `<그림 2-1> 재해 규모별 비율¹⁾` | 가장 일반적 |
| 연구자 재구성 명시 | 각주에 "연구자가 재구성한 프레임워크임" | 이론 도식 재구성 시 |

### 4.4 연구모형 그림 형식 (`<그림 3-1>`)

모든 논문에서 공통적으로 사용하는 연구모형 표현 방식:

- **사각형 박스 + 화살표** 다이어그램
- 독립변수(X): 좌측 배치, 하위 변수를 묶음 박스 내 나열
- 종속변수(Y): 우측 배치
- 매개변수(M): 중앙 상단 또는 독립↔종속 사이
- 조절변수(W): 하단 또는 별도 위치, 화살표가 경로에 교차
- 변수 기호 병기: `(xa)`, `(xb)`, `(ya)`, `(w)` 등
- 일부 논문은 변수별 **색상 구분** 사용 (독립=파랑, 종속=노랑, 조절=녹색)

## 5. 각주 형식

### 5.1 각주 번호 체계

> **10편 모두 논문 전체에서 연속 번호를 사용** (장별 초기화 없음)

- 번호 형식: 아라비아 숫자 + 닫는 괄호 `1)`, `2)`, `3)` ...
- 본문 내 위치: 위첨자로 해당 문장 끝 또는 저자명 뒤에 삽입
- 페이지 하단에 가로 구분선 후 각주 텍스트 기재

> **참고:** CLAUDE.md에는 "장(Chapter)별로 번호 초기화"로 기재되어 있으나, 실제 제출된 10편 모두 전체 연속번호를 사용함. 지도교수님께 확인 필요.

### 5.2 각주 마커 위치 패턴

```
패턴 A: 문장 끝 마침표 뒤
  → "...산업재해가 발생하고 있다.³⁾"

패턴 B: 저자명(연도) 뒤
  → "김성훈(2017)¹⁴⁾은 건설현장에서..."

패턴 C: 표·그림 제목 뒤
  → "<표 2-1> 5년간 업종별 사망사고 현황⁸⁾"

패턴 D: 괄호 인용 뒤
  → "...지적하였다(이준호, 2024).³⁾"
```

### 5.3 각주 서지 형식 — 핵심 원칙

> **각주에는 반드시 인용한 페이지(p.XX)를 명시한다.** 이것이 참고문헌 목록과 각주의 결정적 차이이다.
> 참고문헌은 문헌 전체의 서지정보만 기재하지만, 각주는 **"이 문장의 근거가 해당 문헌의 몇 페이지에 있는지"**를 특정해야 한다.

### 5.4 각주 서지 형식 (유형별)

**국내 학위논문:**
```
저자명, 연도, 논문제목, 학교명 석사(박사)학위논문, p.XX
```
예: `이상구, 2024, 건설현장에서 안전관리비의 산정 및 집행 효율화와 위험지수의 관계, 경기대학교 박사학위논문, p8`

**국내 학술지:**
```
저자명(연도), 「논문제목」, 『학술지명』, 제N권 제N호, p.XX
```
예: `안홍섭(2011), 「CDM에 내재된 발주자 주도의 안전관리 메카니즘」, 『대한건축학회연합논문집』, 23(4), p.298`

**정부·공공기관 보고서:**
```
기관명(연도), 보고서명, 기관명, p.XX
```
예: `한국산업안전보건연구원(2022), 산업안전보건교육에 대한 국내외 사업장의 이행실태 조사, 연구보고서, p16`

**외국 학술지:**
```
Author(s)(Year), "Title," Journal Name, Vol. X, No. Y, p.XX
```
예: `Hallowell, M. R. & Hansen, D.(2016), Measuring and improving designer hazard recognition skill, Safety Science, Volume 82, p.255`

**단행본:**
```
저자(연도), 도서명, 출판사, p.XX
```
예: `정진우(2023), 안전문화 이론과 실천(3판), 교문사, p297`

**재인용:**
```
원저자(원년도), 재인용저자(재인용연도), 재인용문헌제목, 기관명, p.XX에서 재인용
```
예: `Heinrich(1959), 박찬임 외(2018), 산업재해의 경제적 손실비용 관련 연구, 한국노동연구원, p5에서 재인용`

**법령:**
```
법령명 [법률 제XXXXX호, 시행일 XXXX.XX.XX.]
또는
법령명 제X조(제목) 조문 내용
```
예: `산업안전보건법 [법률 제19591호, 시행일 2024.05.17.]`

**웹사이트/기사:**
```
"기사 제목", 언론사명, 날짜
또는
URL 직접 기재
```

### 5.4 각주 형식 편차 주의

## 6. 본문 인용(내주) 방식

### 6.1 인용 방식 개요

### 6.2 본문 인용 패턴 (실제 예시)

**패턴 A: 저자명(연도) + 각주번호 (가장 일반적)**
```
김성훈(2017)��⁴⁾은 건설현장에서 시행되고 있는 위험성 평가의 실효성을 분석하였다.
```

**패턴 B: 저자명(연도)은 ~하였다 (서술형)**
```
민병길(2022)은 BIM을 활용한 현장의 위험 요소를 효과적으로 파악하고 안전관리
효율성을 높이는 것을 목표로 하였다.
```

**패턴 C: 괄호 내주 (문장 끝)**
```
...이러한 구조적 연계성은 확인된다(Hollnagel, 2014).
```

## 8. 어조·서술체

### 8.1 기본 원칙

- **능동형 서술어 사용** (피동형 지양)
- **3인칭 서술** (`본 연구는`, `본 논문은`)
- **격식체 평서문** (`~이다`, `~한다`, `~하였다`)

### 8.2 문장 종결어미 — 상황별

| 상황 | 종결어미 | 예시 |
|------|---------|------|
| 사실/정의 기술 | ~이다, ~한다, ~있다 | "건설업은 고위험 산업이다." |
| 과거 연구 인용 | ~하였다, ~밝혔다, ~강조하였다, ~주장하였다 | "김영남(2023)은 ~를 지적하였다." |
| 분석 결과 | ~나타났다, ~분석되었다, ~확인되었다 | "유의한 정(+)적 영향이 나타났다." |
| 가설 판정 | ~채택되었다, ~기각되었다 | "연구가설은 채택되었다." |
| 판단/전망 | ~판단된다, ~기대된다, ~것으로 보인다 | "실효성 향상이 기대된다." |
| 연구자 의도 | ~하고자 한다, ~제시하고자 한다 | "본 연구는 ~를 분석하고자 한다." |

### 8.3 피해야 할 표현

| 피해야 할 표현 | 올바른 표현 |
|--------------|-----------|
| ~되어졌다 (이중 피동) | ~되었다 또는 ~하였다 |
| ~것으로 사료된다 | ~것으로 판단된다 |
| ~할 수 있을 것으로 보여진다 | ~할 수 있다 |

### 8.4 실제 문장 예시 (상황별)

**서론 도입:**
> 건설산업은 국가 경제를 지탱하는 핵심 산업과 동시에 다양한 위험 요인이 공존하는 대표적인 고위험 산업 분야이다.

**이론 설명:**
> 버드는 하인리히의 고전적 도미노 이론을 계승·확장하여, 조직적·관리적 요인을 중점적으로 반영한 '신도미노 이론'을 제안하였다.

**선행연구 서술:**
> 이규득 외(2024)는 경영진의 안전리더십이 직접적으로 위험수준을 낮추기보다는, 관리감독자의 안전보건 역할을 매개로 하여 효과를 발휘한다고 밝혔다.

**연구방법 서술:**
> 본 연구에서는 서울·경기·인천지역의 건설현장 안전관리자를 대상으로 설문조사를 실시하였다. 수집된 자료는 JAMOVI 통계프로그램을 활용하여 분석하였다.

**결과 서술:**
> 분석 결과, 독립변수인 '위험성평가 교육 인식'은 종속변수와 유의한 정(+)적 상관관계를 나타냈다(r = .859, p < .001).

**가설 검증 서술 (정형 패턴):**
> 〈연구가설 1-1〉 '독립변수X는 종속변수Y에 정(+)의 영향을 미칠 것이다.'에 대한 분석결과, t값은 5.40이며, p<.001로 0.05의 유의수준에서 통계적으로 유의하다. 이에 연구가설은 **채택**되었다.

**결론 마무리:**
> 결론적으로, 본 연구는 ~가 건설 현장의 안전관리 효율성을 높이는 데 중요한 도구임을 입증하였다.

**핵심 구조:**
- 하나의 표 안에 **독립변수별 소단위 구분** (소제목: `[X — M — Y]`)
- 각 소단위는 **Indirect / Direct / Total** 3행 고정
- 열: Effect / Estimate / SE / Z / p (일부 논문은 % Mediation 추가)
- **완전매개**: Direct의 p > .05 (직접효과 비유의)
- **부분매개**: Direct의 p < .05 (직접효과도 유의)

### 10.9 조절효과 표 (Moderation Estimates)

```
<표 4-14> Moderation Estimates - 조절변수(W)의 조절효과

| 구분              | Estimate | SE    | Z     | p     |
|-------------------|----------|-------|-------|-------|
| 독립변수(xa)      | 0.161    | 0.028 | 5.85  | <.001 |
| 조절변수(w)       | 0.192    | 0.033 | 5.88  | <.001 |
| (xa)*(w) ← 상호작용항 | 0.183 | 0.038 | 4.78  | <.001 |
```

**핵심 구조:**
- **3행 묶음**: 독립변수 → 조절변수 → 상호작용항 순서
- 상호작용항 표기: `(xa)*(w)` (괄호+별표 곱셈)
- **Z값** 사용 (t값 대신 — JAMOVI 출력 기반)
