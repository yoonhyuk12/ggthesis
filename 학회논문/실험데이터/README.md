## 라벨링 규약

M열 `맞음여부`에 LLM 판정이 맞는지 입력 (드롭다운 지원):

| 입력 | 의미 |
|------|------|
| **O** | LLM 판정이 맞다 |
| **X** | LLM 판정이 틀리다 |
| **?** | 이미지로 판단 곤란 |

LLM 정탐 행 52건은 노란색으로 강조됨.
