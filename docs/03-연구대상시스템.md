# 03. 연구 대상 시스템: AI CCTV Viewer

> 시스템 아키텍처, 기술 명세, 변수(X1~X4)의 운영적 정의 작업 시 로드하세요.

연구자가 직접 개발한 Windows 데스크톱 애플리케이션. 핵심 아키텍처:

- **1차 감지(YOLO26m):** 11클래스 객체 감지 + 이중 모델 낙상 감지(Bbox분류+포즈추정 IoU 융합)
- **2차 검증(LLM):** OpenAI/Gemini/Claude/Grok/Qwen 5개 프로바이더 지원, 문맥 기반 오탐 필터링
- **알림:** 텔레그램 즉시 전송 (자연어 요약 + 감지 이미지)
- **인프라:** 일반 PC 기반, ONVIF 호환 IP 카메라, NVIDIA/AMD/CPU 4단계 폴백
- **오탐 억제 3단계:** 경고 확인 필터 → LLM 2차 검증 → 쿨다운(경고음 300초, 텔레그램 600초)
- **High-Recall 아키텍처:** YOLO Confidence Threshold 0.3 (선행연구 0.4~0.5 대비 의도적 하향) → 미탐 최소화 + LLM이 급증 오탐 필터링. 낙상 감지는 Dual-Asymmetric 설계: Bbox 0.7(정상 동작 배제) + 포즈 키포인트 0.3(Occlusion 보완) → IoU 융합
- **동적 위험구역:** HDBSCAN 기반 안전콘/전신주 클러스터링 → 볼록껍질/MST 접선 버퍼로 자동 폴리곤 생성
- **원근 적응형 근접 판정:** 감지 객체 크기 기반 동적 위험 거리 산출 (캘리브레이션 불필요)

상세 기술 명세는 `프로그램 기술분석서.md` 참조.
