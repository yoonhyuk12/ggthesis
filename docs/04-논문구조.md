## 논문 구조 (현행 **6장 구조**)

절 제목의 단일 원본은 `논문구조/00_목차.md`다. 아래 표와 어긋나면 목차 파일이 우선한다.

**설계(구상) 순서:** 연구설계(제4장) → 이론적 배경(제2장) → 서론(제1장) → 실증분석 결과(제5장) → 결론(제6장)
> 연구설계를 먼저 확정해야 이론적 배경의 방향과 서론의 논지가 정해진다. 교수님 요령의 "3장(연구방법) 먼저" 원칙은 5장 구조 기준이며, 본 논문에서는 **제4장 연구설계**가 그 자리다. 제3장(시스템 개발)은 연구대상 그 자체이므로 `프로그램 기술분석서.md`와 학회논문 검증 결과를 근거로 별도 작성한다. 서론은 뒷장을 쓰면서 계속 수정한다.

## 논문 작성 규칙

- 경기대학교 석사학위 양식 사용
- 선행연구는 경기대 석사졸업논문과 아시아태평양학회 논문 우선 인용
- 능동형 서술어 사용 (피동형 지양)
- 두괄식 문단 설계: 하나의 주제어 = 하나의 문단
- 문장 간결성: 3~4줄 이내, 동일 표현 반복 자제
- 인용문장 5줄 이하, 핵심어구 발췌 후 새롭게 기술
- 장 끝에 다음 장과의 연결 문장 기술
- 출처 표기: 내주(저자명, 연도) 방식 통일

## 인용 및 각주 표기 규칙

**본문 인용 (내주 방식):** `(저자성, 연도)` 또는 `저자성(연도)`
- 저자 2인: (홍길동·이순신, 2024)
- 저자 3인 이상: (홍길동 외, 2024)
- 외국 문헌: (Cvach, 2012)
- 페이지 병기: (홍길동, 2024, p.30)

**각주 번호:** 본문에 `[^N]` 마커 삽입, 장(Chapter)별로 번호 초기화
- 마커 위치: 문장 부호 앞 또는 인용 닫는 괄호 `)`·`,` 직후
- 예: `어렵다(이준호, 2024).[^3]`

**각주 서지 형식 (유형별):**

| 유형 | 형식 |
|------|------|
| 국내 학위논문 | 저자, 「논문제목」, 학교명 학과 석사(박사)학위논문, 지도교수 OOO, 연도. |
| 정부·공공기관 보고서 | 기관명, 『보고서명』, 기관명, 연도, p.XX. |
