# 04. 논문 구조 · 작성 규칙 · 인용 규칙 (박종용 교수님 가이드 기준)

> 본문 집필, 인용 표기, 각주 작성 시 로드하세요.

## 논문 구조

**설계(구상) 순서:** 3장 → 2장 → 1장 → 4장 → 5장
> 연구방법(3장)을 먼저 설계해야 이론적 배경(2장)의 방향과 서론(1장)의 논지가 정해진다. 단, 텍스트 집필 일정은 일정표 참조.

**실제 집필 일정:** 1장+2장(4~5월) → 3장 완료(6~7월) → 4장(8~9월) → 5장(10월)

| 장 | 내용 | 비고 |
|---|------|------|
| I. 서론 | 1절 배경 및 필요성, 2절 목적, 3절 범위 및 방법 | 2~5장 작성하며 지속 수정 |
| II. 이론적 배경 | 1절 이론적 근거(연구모형 근거), 2절 연구대상과 종속변수 현황, 3절 연구대상과 종속변수 관계, 4절 매개변수-종속변수 관계, 5절 조절변수-종속변수 관계, 6절 선행연구(X↔Y), 7절 소결 | 변수별 개념+정의+선행연구 인용 |
| III. 연구방법 | 1절 연구모형, 2절 연구문제 및 가설, 3절 조작적 정의·측정도구, 4절 설문조사, 5절 자료수집·분석방법 | modle.md에 초안 완성됨 |
| IV. 연구결과 | 1절 인구통계학적 특성, 2절 타당도·신뢰도, 3절 기술통계·상관관계, 4절 가설검증, 5절 소결 | 다중회귀분석, 매개·조절효과 검정 |
| V. 결론 | 요약, 논의(선행연구 비교), 시사점(실무적/학술적/정책적), 한계 및 방향 | 1~2p |

## 논문 작성 규칙

- 경기대학교 석사학위 양식 사용
- 선행연구는 경기대 석사졸업논문과 아시아태평양학회 논문 우선 인용
- 능동형 서술어 사용 (피동형 지양)
- 두괄식 문단 설계: 하나의 주제어 = 하나의 문단
- 문장 간결성: 3~4줄 이내, 동일 표현 반복 자제
- 인용문장 5줄 이하, 핵심어구 발췌 후 새롭게 기술
- 장 끝에 다음 장과의 연결 문장 기술
- 출처 표기: 내주(저자명, 연도) 방식 통일

## 인용 및 각주 표기 규칙

**본문 인용 (내주 방식):** `(저자성, 연도)` 또는 `저자성(연도)`
- 저자 2인: (홍길동·이순신, 2024)
- 저자 3인 이상: (홍길동 외, 2024)
- 외국 문헌: (Cvach, 2012)
- 페이지 병기: (홍길동, 2024, p.30)

**각주 번호:** 본문에 `[^N]` 마커 삽입, 장(Chapter)별로 번호 초기화
- 마커 위치: 문장 부호 앞 또는 인용 닫는 괄호 `)`·`,` 직후
- 예: `어렵다(이준호, 2024).[^3]`

**각주 서지 형식 (유형별):**

| 유형 | 형식 |
|------|------|
| 국내 학위논문 | 저자, 「논문제목」, 학교명 학과 석사(박사)학위논문, 지도교수 OOO, 연도. |
| 정부·공공기관 보고서 | 기관명, 『보고서명』, 기관명, 연도, p.XX. |
| 국내 학술지 | 저자, 「논문제목」, 『학술지명』, 제N권 제N호, 연도, pp.시작-끝. |
| 외국 학술지 | Author(s), "Title," *Journal Name*, Vol. X, No. Y, pp. start–end, Year. |
| 단행본 | 저자, 『도서명』, 출판사, 연도, p.XX. |

**자주 쓰는 저자명 오류 주의:**
- `YOLO 모델별 건설 현장 위험 상태 및 객체 인식 성능 비교` → 저자: **박종학**, 지도교수: 문유미 (2024, 경기대). 문유미로 인용하지 말 것.
