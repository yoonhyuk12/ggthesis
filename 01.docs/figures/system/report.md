## 원고 기준과 수정 사항

최종 도식은 `01.docs/03_시스템개발.md`에 기술된 연구 구성을 설명한다. 외부 프로그램의 최신 작업본을 연구 당시 구현으로 간주하지 않으며, 외부 구현의 확장을 도식에 포함하지 않는다. 세 그림 모두 ‘연구에서 기술한 구성’으로 범위를 명시했다. CLAUDE.md 및 지도교수 논문작성요령 전문을 앞선 작업에서 읽었으며 이번 수정에도 동일한 범위를 적용했다.

- 그림 3-1: 제3절의 네 단계, 표 3-2, 제4절 임계값 0.3 및 제6절 다중 수신자 전파. 전송 분기를 SEND/BLOCK으로 수정했다.
- 그림 3-2: 제5절 제1–2항 및 그림 3-2 삽입 지시. 입력 세 종류와 result/reason 두 필드만 표시하고 confidence·cutline·사용자 임계값을 제거했다. SEND는 알림 전파, BLOCK은 저장·교정으로 연결한다. API 장애 시 검증 실패 표시와 1차 결과 발송은 원고에 따라 하단 주석으로 표시했다.
- 그림 3-3: 제5절 제3항 및 그림 3-3 삽입 지시. 알림 이력 우클릭으로 등록한 사유 10–80자·이미지를 맥락별로 저장하고, 새 알림과 같은 맥락의 교정만 최대 3건 검색하여 주입한다. 해당 교정이 없으면 미주입한다. 외부 코드의 5W1H 태그·임베딩·순위 점수·기본값 설명은 제거했다.

## 외부 구현 불일치 — 해결하지 않음

1. **출력 필드와 분기:** 외부 작업본은 confidence와 사용자 임계값으로 최종 전송 여부를 재결정한다. 연구 원고의 두 필드·SEND/BLOCK 구성과 다르다. 이번 최종 그림은 원고 구성만 표현하며 외부 확장을 반영하지 않는다.
2. **같은 맥락만 검색:** 외부 `select`는 맥락 점수 0인 후보를 제외하지 않아 경고 키 후보가 있으면 다른 맥락도 반환할 수 있다. ‘같은 맥락이 없으면 미주입’이라는 원고 설명과의 버전 정합은 확인되지 않았다. 그림은 요청대로 원고의 연구 구성을 설명한다.
3. **최대 3건:** 외부 설정에서는 기본 3건, 허용 범위 1–5건이다. 그림에는 원고의 최대 3건만 표시했다.
4. **쿨다운 순서:** 외부 AlertHandler는 LLM 호출 전 쿨다운을 갱신하지만 원고는 LLM 검증 뒤 3단계 필터로 설명한다. 본 도식은 쿨다운 세부 구현 순서를 다루지 않는다.
5. **사유 80자:** 외부 코드에서는 프롬프트 지시이며 응답 파서의 강제 절단은 확인되지 않았다. 그림은 연구 원고의 ‘80자 이하’를 표시한다.
6. **연구 버전:** 외부 작업본과 실제 연구 당시 버전의 동일성, 설정 및 실험 수치는 이번 수정에서 검증하지 않았다. 위 차이들은 모두 미해결로 유지한다.

## 최종 수정본 검증 증거

- 생성 명령 `python 01.docs/figures/system/generate_system_figures.py` 실행 성공. 세 PNG 모두 300 dpi(메타데이터 299.9994 dpi, PNG 정수 단위 환산 반올림), 흰 배경 확인.
- SVG 세 파일을 XML로 읽고 각각 21/23/23개의 편집 가능한 text 요소를 확인했다. confidence 및 임베딩 문구가 SVG 텍스트에 없음을 확인했다.
- **SVG 자체 렌더링:** PyQt6 QSvgRenderer에서 세 SVG 모두 유효 판정. 검사 환경이 시스템 글꼴을 자동 로드하지 않아 처음에는 대체 사각형이 나타났으나, `C:/Windows/Fonts/malgun.ttf`와 `malgunbd.ttf`를 QFontDatabase에 명시 등록한 뒤 세 SVG 모두 한글이 정상 렌더링됨을 확인했다. 이는 검사 도구의 글꼴 로딩 문제이며 SVG 텍스트나 자산을 경로화하지 않았다.
- **시각 검증:** `render_verification.png`의 위 행은 실제 SVG의 QtSvg 렌더링, 아래 행은 최종 300dpi PNG이다. 여섯 패널을 직접 열어 한글 글리프, 줄바꿈, 상자 여백, SEND/BLOCK, 교정 있음/없음 분기, 겹침·잘림 없음 및 흰 배경을 확인했다. 검사 비교 이미지는 삽입용 그림이 아니다.
- 수정 범위는 `01.docs/figures/system/` 내부의 SVG·PNG·생성 스크립트·보고서·검사 비교 이미지뿐이다. 원고/HWPX 수정, COM 사용, 위임은 없었다.

세 도식의 원고 기준 수정과 검증을 완료했다. 남은 작업은 코디네이터의 원고/HWPX 삽입이며, 외부 구현과 연구 버전의 차이는 별도 미해결 사항으로 남긴다.
