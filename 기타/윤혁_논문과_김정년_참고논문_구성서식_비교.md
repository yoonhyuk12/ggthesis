## 3. 실제 목차 쪽수 불일치

다음은 2026-10-04 임시 복사본을 한글에서 PDF로 출력해 확인한 윤혁 논문의 값이다. ‘실제 쪽수’는 종이에 인쇄된 번호이며, PDF 순번과 다르다.

| 항목 | 목차에 적힌 쪽수 | 실제 인쇄 쪽수 | PDF 순번 |
| --- | ---: | ---: | ---: |
| 제1장 제2절 | 2 | 3 | 15 |
| 제5장 실증분석 결과 | 95 | 94 | 106 |
| 제6장 결론 | 120 | 119 | 131 |
| Abstract | 143 | 141 | 153 |

목차 첫 쪽은 김정년 `i`, 윤혁 `iv`였다. 서식을 수정하면 쪽수가 다시 달라질 수 있으므로 **서식 정리와 재조판을 마친 뒤 목차·표목차·그림목차를 최종 갱신**해야 한다.

## 4. 수정 우선순위와 유지할 구성

1. **누락·불일치부터 처리:** 논문개요와 Abstract를 완성하고, 앞부분 로마숫자의 시작 번호를 점검한다. 목차 쪽수 불일치는 최종 조판 후 해소한다.
2. **본문과 제목을 통일:** 본문 170%, 첫줄 처리, 목차 11pt·170%, 제목 번호 띄어쓰기·정렬·줄간격을 정리한다. 실제 공백과 정식 들여쓰기를 중복 적용하지 않는다.
3. **표·그림·출처를 통일:** 표 제목의 위치와 글꼴, 표 내부 줄간격과 머리행, 그림 제목 위치, 출처 9pt를 맞춘다. 표 내용에 따른 가독성은 별도로 고려한다.
4. **참고문헌을 정리:** 분류별 표시번호와 연도 위치를 일관되게 맞춘다. 기존 서지정보를 임의로 바꾸지 않는다.

윤혁 논문의 6장은 **서론 → 이론적 배경 → 시스템 개발 → 연구설계 → 실증분석 결과 → 결론**이다. 김정년의 연구방법·결과·결론 역할은 윤혁의 제4·5·6장에 대응하며, 제3장이 시스템 개발을 별도로 담당한다. 참고본이 5장이라는 이유만으로 합치거나 삭제할 필요는 없다.

## 5. 확인 범위와 제한

- 기존 HWPX XML 속성 비교와 한글 PDF 출력·대표 페이지 시각 확인 결과를 정리했다. 이번 MD 저장 과정에서는 원본 분석을 반복하지 않았다.
- 연구 내용의 타당성, 수치·인용·서지의 정확성은 검토하지 않았다. 초록은 작성 유무만 확인했다.
- 표·그림·출처의 세부 서식은 대표 표본 관찰이다. 모든 표와 그림을 전수 검증한 결과로 해석하지 않는다.
- 김정년 파일 역시 미입력 표시가 남은 참고본이다. 관찰된 서식 전체를 학교의 확정 제출 규정으로 단정하지 않는다.
- 당시 PDF는 김정년 130쪽, 윤혁 153쪽이었다. 분량 자체는 서식 오류가 아니다.
- **편집용지와 PDF 출력용지는 구분해야 한다.** 원본 XML의 용지 크기와 구역별 여백은 동일하지만, PDF MediaBox는 김정년 약 538×725pt, 윤혁 약 595×841pt(A4)로 달랐다. 출력용지 별도 설정의 영향일 가능성은 있으나 **원인은 미확정**이다. 이를 원본 편집용지의 차이라고 단정하지 않으며, 위 쪽수는 당시 출력 결과 기준이다.
- 원본 HWPX, MD 원고, 규칙 파일은 수정하지 않았다. 이 문서는 비교 기록이며 실제 서식 수정본은 아니다.
