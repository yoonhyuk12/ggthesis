# 시작하기 — 박사논문 작성 템플릿 초기 설정

이 폴더는 Claude Code로 박사학위논문을 작성하기 위한 템플릿이다. 논문 작성 스킬 모음(ARS, claude-research), 한글 HWPX 문서 도구(hwpx MCP), 박종용 교수님 논문작성요령이 미리 설치되어 있다. 아래 순서대로 설정하면 바로 논문 작업을 시작할 수 있다.

## 0. 준비물 (한 번만 설치)

| 프로그램 | 용도 | 받는 곳 |
|---|---|---|
| Claude Code | AI 논문 작업 도구 본체 | https://claude.com/claude-code |
| Python 3.10 이상 | 한글(hwpx) 문서 도구 실행용 | https://www.python.org/downloads/ — 설치 시 **"Add python.exe to PATH" 반드시 체크** |
| Git (선택) | 스킬 모음 업데이트용 | https://git-scm.com/ |

## 1. 폴더 복사

이 템플릿 폴더 전체를 내 PC의 원하는 위치로 복사한다. 경로는 자유이며, 한글 경로도 괜찮다. 폴더 이름은 자신의 이름 등으로 바꿔도 된다.

## 2. Claude Code 실행

복사한 폴더에서 터미널(PowerShell)을 열고 `claude`를 실행한다. 탐색기에서 폴더를 연 뒤 주소창에 `powershell`을 입력하고 Enter, 이어서 `claude`를 입력하면 된다.

## 3. 프롬프트 1 — 초기 설정

Claude Code에 아래를 그대로 붙여넣는다.

```
이 폴더는 박사논문 작성용 Claude Code 템플릿이야. 프로젝트 루트의 시작하기.md와 CLAUDE.md를 읽고 초기 설정을 진행해줘.

1. setup.ps1을 실행해서 스킬 정션을 만들고, hwpx MCP용 파이썬 가상환경을 생성하고, .mcp.json 경로를 이 PC 기준으로 갱신하고, 전역 CLAUDE.md(행동 지침)를 내 홈 폴더의 .claude에 설치해줘.
2. 끝나면 결과를 검증해줘: .claude/skills 정션이 113개인지, hwpx-mcp-simple/.venv/Scripts/hwpx-mcp-server.exe가 존재하는지, .mcp.json의 경로가 이 폴더를 가리키는지, 홈 폴더의 .claude/CLAUDE.md가 있는지.
3. 오류가 나면(예: Python 미설치) 원인을 설명하고 해결 방법을 단계별로 안내해줘.
4. 모두 정상이면 다음 할 일(Claude Code 재시작)을 알려줘.
```

설정이 끝나면 Claude Code를 완전히 종료했다가(`exit` 입력 또는 창 닫기) 같은 폴더에서 다시 실행한다. 재시작 시 hwpx MCP 서버 사용을 승인할지 묻는 창이 나오면 승인한다.

## 4. 프롬프트 2 — 내 논문 정보 설정

재시작한 Claude Code에 아래를 붙여넣는다.

```
내 박사논문 정보를 설정하자. CLAUDE.md와 "3. 기타" 폴더의 박종용 교수님 논문작성요령을 먼저 읽어줘.

1. 나에게 한 항목씩 질문해줘: 이름, 논문 제목(가제), 대학원·학과, 지도교수, 연구모형(독립·매개·종속 변수와 하위요소), 연구문제와 가설, 조사 방법(설문 대상, 표본 규모, 분석 도구), 목표 일정. 아직 정하지 못한 항목은 "미정"으로 두면 된다.
2. 답변을 정리해서 CLAUDE.md의 "내 박사학위논문" 섹션을 채우고, 안내 블록은 삭제해줘.
3. "2. 논문 작성" 폴더에 장별 뼈대 파일(00.목차.md ~ 07.참고문헌.md)을 만들어줘. 각 파일에 교수님 논문작성요령에 맞는 절 구성과 작성 가이드를 넣어줘.
4. 작성 순서(3장 → 2장 → 1장 → 4장 → 5장)에 따라 내가 무엇부터 준비하면 되는지 알려줘.
```

## 5. 프롬프트 3 — 레퍼런스 자료 등록 (자료가 준비되면)

참고할 논문·보고서 PDF를 `1. 레퍼런스 자료` 폴더에 넣은 뒤 아래를 붙여넣는다.

```
"1. 레퍼런스 자료" 폴더에 참고 자료 PDF를 넣었어. 전부 읽고 "00. 레퍼런스 논문 종합 요약.md"를 만들어줘. 자료별 서지정보·연구방법·핵심 수치, 내 논문에서 뒷받침하기 좋은 주장과 인용 위치(PDF 페이지 기준), 자료 간 공통 결론과 차이·연구 공백, 인용 시 주의사항(표본 편향, 자기보고, 수치 불일치 등)을 정리해줘.
```

## 6. 이후 사용법

설정이 끝나면 자연어로 지시하면 된다. 예를 들면 다음과 같다.

- "3장 연구방법 초안을 쓰자. 내 연구모형 기준으로 가설 표부터 만들어줘."
- "/ars-lit-review 근로자 참여가 안전성과에 미치는 영향" (문헌 리뷰)
- "/proofread 2. 논문 작성/03.연구방법.md" (교정)
- "이 hwpx 파일을 읽고 목차를 md로 정리해줘." (hwpx 파일은 프로젝트 폴더 안에 있어야 한다)

## 문제 해결

- **"Python을 찾지 못했습니다" 경고** — Python을 설치하지 않았거나 PATH 체크를 빠뜨린 경우다. Python을 설치한 뒤 프롬프트 1을 다시 실행하면 된다.
- **hwpx 도구가 안 보임** — `.mcp.json` 갱신 후 Claude Code를 재시작해야 반영된다. 재시작 시 MCP 서버 승인 여부를 물으면 승인한다.
- **스킬(/ars-... 등)이 안 보임** — `.claude/skills` 정션이 만들어졌는지 프롬프트 1의 검증 절차로 확인하고, Claude Code를 재시작한다.
- **플러그인 관련 경고** — `.claude/settings.json`이 참조하는 공식 플러그인(superpowers 등)이 내 PC에 없어서 나오는 경고는 무시해도 논문 작업에 지장이 없다.
- **전역 CLAUDE.md** — 템플릿의 `전역-CLAUDE.md`는 AI의 작업 습관(과잉 수정 방지, 테스트 후 완료 보고 등)을 잡아 주는 전역 행동 지침이다. setup.ps1이 홈 폴더의 `.claude\CLAUDE.md`로 설치하되, 이미 자신의 전역 CLAUDE.md를 쓰고 있으면 덮어쓰지 않고 건너뛴다. 그 경우 두 파일을 비교해 필요한 내용만 직접 반영하면 된다.
