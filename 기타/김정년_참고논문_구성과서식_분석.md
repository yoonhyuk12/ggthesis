# 김정년 참고논문 — 구성·서식 분석

- 분석 대상: `기타/건설현장 안전시설물 설치와 떨어짐 사고위험의 관계-논문전체(김정년) 261002.hwpx`
- 분석일: 2026-10-04
- 범위: 앞뒤 구성, 제목 체계, 글자·문단·쪽 설정, 표·그림, 인용·참고문헌의 **형식**. 연구 내용과 결과는 요약하지 않았다.
- 확인 방법: HWPX의 실제 문단·글자 속성을 확인하고, 원본의 임시 복사본을 한글에서 열어 PDF로 출력했다. 원본은 수정하지 않았다.

**핵심 특징은 작은 학위논문 판형, 한양신명조 본문 11pt·줄간격 170%, 장→절→항의 큰 제목 위계, 본문 중간의 표·그림과 아래 출처, 자료 유형별로 구분한 참고문헌이다.** 다만 이 파일에는 작성 지침과 미입력 표시가 남아 있다. 아래의 관찰값은 참고본의 현재 상태이며, 모두 학교의 확정 제출 규정이라는 뜻은 아니다.

## 1. 전체 구성과 배치 순서

### 실제 파일의 순서

| 구분 | 배치 순서 | 형식상의 특징 |
| --- | --- | --- |
| 표지류 | 겉표지 → 제출지 → 인준지 | 각 1쪽. 제목·소속·성명 등을 큰 여백과 중앙 정렬로 배치 |
| 앞부분 | 목차 → 표 목차 → 그림 목차 → 감사의 글 → 논문개요 | 본문 앞에 별도 구역으로 모음. 소문자 로마숫자로 쪽번호 표시 |
| 본문 | 제1장 서론 → 제2장 이론적 배경 → 제3장 연구방법 → 제4장 연구의 분석 결과 → 제5장 결론 | 장마다 새 쪽에서 시작. 장 안에 절, 절 안에 항 배치 |
| 뒷부분 | 참고문헌 → 부록 → Abstract | 각각 새 쪽 시작. 본문 아라비아 쪽번호를 이어 사용 |

국문초록 역할의 제목은 **「논문개요」**이고, 영문초록은 **부록 뒤의 맨 마지막**에 있다. 감사의 글도 뒤쪽이 아니라 목차류와 논문개요 사이에 있다.

### 실제 조판 분량 — 이 참고본에만 해당

한글에서 출력한 PDF는 총 **130쪽**이다. 다음은 PDF의 물리적 순번과 종이에 인쇄된 쪽수를 구분한 것이다.

| 부분 | PDF 순번 | 인쇄 쪽수 |
| --- | --- | --- |
| 겉표지·제출지·인준지 | 1–3 | 표시 없음 |
| 목차 | 4–6 | i–iii |
| 표 목차 | 7–8 | iv–v |
| 그림 목차 | 9 | vi |
| 감사의 글 | 10–11 | vii–viii |
| 논문개요 | 12–13 | ix–x |
| 본문 5개 장 | 14–105 | 1–92. 본문 첫 쪽의 숫자는 숨겨져 있음 |
| 참고문헌 | 106–116 | 93–103 |
| 부록 | 117–127 | 104–114 |
| Abstract | 128–130 | 115–117 |

130쪽은 **이 파일을 실제로 조판한 결과**이며 권장 논문 분량이 아니다. HWPX에 저장된 줄 위치·쪽 관련 캐시만으로 쪽수를 확정하지 않았다.

## 2. 재사용할 수 있는 목차 골격

이 참고본의 구조를 내용과 분리하면 다음과 같다. 대괄호는 재사용을 위한 빈자리이며 원문 제목이 아니다.

```text
겉표지 / 제출지 / 인준지
목차 / 표 목차 / 그림 목차
감사의 글
논문개요

제 1 장 서론
  제 1 절 연구의 배경 및 필요성
  제 2 절 연구의 목적
  제 3 절 연구의 범위 및 방법

제 2 장 이론적 배경
  제 1 절 연구의 이론적 근거
    제 1 항 [이론 1]
    제 2 항 [이론 2]
  제 2 절 [핵심 개념 1]
    제 1 항 개념 및 특성
    제 2 항 현황 또는 구성요인
    제 3 항 관련 선행연구
  제 3 절 [핵심 개념 2]
  제 4 절 [핵심 개념 3]
  제 5 절 선행연구의 종합 및 소결

제 3 장 연구방법
  제 1 절 연구모형
    제 1 항 [연구문제 1]
    제 2 항 [연구문제 2]
    제 3 항 [연구문제 3]
  제 2 절 변수의 조작적 정의와 측정도구의 구성
  제 3 절 설문조사
    제 1 항 설문조사의 개요
    제 2 항 설문지 구성
    제 3 항 예비조사 및 문항 검토
  제 4 절 자료수집과 분석방법

제 4 장 연구의 분석 결과
  제 1 절 조사대상자의 일반적 특성
  제 2 절 측정도구의 타당도 및 신뢰도 분석
  제 3 절 기술통계 및 상관관계 분석
  제 4 절 연구가설 검증
  제 5 절 연구결과 논의

제 5 장 결론
  [이 참고본은 별도 절 제목 없이 문단으로 전개]

참고문헌
부록
Abstract
```

구성상 특징은 **이론 설명과 선행연구를 묶은 뒤 소결을 두고, 연구방법과 분석 결과를 분리하며, 분석 결과 장 안에 논의까지 포함한다는 점**이다. 결론에는 번호가 붙은 절을 추가하지 않고 문단으로 이어 쓴다. 장 끝에는 다음 장으로 연결하는 문단을 둔다.

**적용 시:** 이 골격은 참고본의 5장 구성을 설명한다. 현재 집필 중인 논문을 5장으로 바꾸라는 의미가 아니다. 기존 장 수와 역할을 유지하면서 제목 위계와 배치 방식만 대응시켜 사용할 수 있다.

## 3. 편집 용지·여백·쪽번호

### 실제 설정값

용지는 전 구역에서 약 **가로 190 × 세로 256mm**인 세로형 사용자 판형이다. A4나 통상적인 B5 규격으로 임의 대체하지 말고 수치를 직접 확인해야 한다. 아래 값은 한글 내부 단위를 mm로 환산해 반올림했다.

| 설정 | 표지류 | 목차·감사글·논문개요 | 본문·참고문헌·부록·Abstract |
| --- | ---: | ---: | ---: |
| 위쪽 여백 | 30mm | 35mm | 35mm |
| 아래쪽 여백 | 25mm | 15mm | 15mm |
| 왼쪽 여백 | 30mm | 30mm | 25mm |
| 오른쪽 여백 | 30mm | 30mm | 25mm |
| 머리말 여백 | 0mm | 0mm | 0mm |
| 꼬리말 여백 | 0mm | 15mm | 15mm |
| 제본 여백 | 0mm | 0mm | 0mm |
| 편집 폭 | 약 130mm | 약 130mm | 약 140mm |

아래쪽 여백과 꼬리말 여백은 한글의 서로 다른 입력 항목이다. 둘을 합친 한 가지 값으로 입력하지 않는다.

- 구역은 **표지류 / 앞부분 / 본문 이후**의 3개로 나뉜다. 장마다 구역을 새로 만드는 구조는 아니다.
- 앞부분은 로마숫자, 본문부터는 아라비아숫자를 사용하며 각각 1부터 다시 시작한다.
- 쪽번호는 하단 중앙에 `- i -`, `- 6 -` 같은 형태로 표시한다.
- 제2장 이후 각 장, 참고문헌, 부록, Abstract는 명시적인 새 쪽 시작으로 처리한다.

**적용 시:** 용지 크기와 구역별 여백을 먼저 설정한 다음 글자와 표를 맞춘다. 본문만 맞추고 표지·목차까지 같은 여백으로 덮어쓰면 참고본과 달라진다.

## 4. 글자와 문단 서식

### 본문과 제목의 실제 값

아래 대표 서식의 한글·영문 글꼴은 모두 **한양신명조**로 지정되어 있다. 글꼴 목록에 저장된 다른 글꼴 이름으로 판단하지 않고 실제 글자에 연결된 속성을 확인했다. 영문초록도 이 파일에서는 같은 글꼴이다.

| 용도 | 크기 | 굵기 | 정렬 | 줄간격 | 장평 / 자간 |
| --- | ---: | --- | --- | ---: | --- |
| 일반 본문 | 11pt | 보통 | 양쪽 | 170% | 100% / 0% |
| 장 제목 `제 1 장 …` | 16pt | 굵게 | 왼쪽 | 170% | 100% / 0% |
| 절 제목 `제 1 절 …` | 15pt | 굵게 | 왼쪽 | 170% | 100% / 0% |
| 항 제목 `제 1 항 …` | 14pt | 굵게 | 왼쪽 | 170% | 100% / 0% |
| 항 아래 소제목 `1. …` | 11pt | 굵게 | 왼쪽 | 170% | 100% / 0% |
| 표·그림 제목 | 11pt | 보통 | 가운데 | 170% | 100% / 0% |
| 표·그림의 `자료:`·`주)` | 9pt | 보통 | 왼쪽 | 170% | 100% / 0% |
| 목차의 장·절·항 항목 | 11pt | 보통 | 양쪽 + 오른쪽 쪽수 탭 | 170% | 100% / 0% |
| 참고문헌 제목 | 16pt | 굵게 | 가운데 | 180% | 100% / 0% |
| 참고문헌 분류 제목 | 13pt | 굵게 | 양쪽 지정, 왼쪽에서 시작 | 180% | 100% / 0% |
| 참고문헌 개별 항목 | 11pt | 보통 | 양쪽 | 180% | 100% / −2% |
| 부록 제목 | 16pt | 굵게 | 가운데 | 170% | 100% / 0% |
| Abstract 제목 | 16pt | 굵게 | 가운데 | 180% | 100% / 0% |
| Abstract 본문 | 11pt | 보통 | 양쪽 | 170% | 100% / 0% |

**들여쓰기:** 일반 본문의 문단 속성은 첫줄 들여쓰기 **0**, 왼쪽·오른쪽 여백 **0**, 문단 앞·뒤 간격 **0**이다. 대신 문단 맨 앞에 **실제 공백 두 칸**을 넣어 첫줄을 들여 썼다. 따라서 ‘들여쓰기 2글자 설정’이라고 해석하면 실제 파일과 다르다.

**제목 사이 간격:** 제목 다음의 빈 문단과 실제 쪽 나누기로 공간을 만든다. 제목의 문단 앞·뒤 간격 값을 크게 준 방식이 아니다. 장·절·항 번호도 자동 개요 번호보다 직접 입력한 제목 문자열과 개별 서식에 의존한다.

**표·그림 제목:** 다음 문단과 함께 배치하는 설정이 켜져 있다. 제목만 쪽 아래에 남고 대상이 다음 쪽으로 넘어가는 것을 줄이기 위한 설정이다. 장·절·항 제목에는 같은 설정이 공통 적용되어 있지 않다.

### 표지류의 특징

겉표지와 제출지는 보이지 않는 표로 세로 위치를 맞췄다. 큰 제목은 중앙 정렬, **22pt·자간 −8%**, 부제는 **18pt·자간 −8%**이며 두 요소 모두 실제 속성상 굵게는 아니다. 학교명은 21pt, 전공명은 15pt, 성명은 17pt이다. 학교명·성명 등의 글자 사이 공간은 문자 자체의 공백도 사용한다.

인준지는 인준 문구, 심사위원 3인의 서명·날인 자리, 날짜, 학교명을 배치한다. 이 부분도 보이지 않는 표와 병합 셀을 사용한다. 본문 문단 설정을 그대로 적용할 대상이 아니다.

**적용 권장:** 본문·장·절·항·캡션·출처·참고문헌을 별도 스타일로 만들어 관리한다. 첫줄 공백과 빈 문단을 그대로 복제할지, 정식 들여쓰기·문단 간격으로 바꿀지는 일관되게 결정한다. 두 방식을 겹쳐 적용하지 않는다.

## 5. 목차·표·그림의 표현 방식

### 목차

- 장·절·항까지 목차에 포함하고, 절과 항은 공백으로 한 단계씩 안쪽에 배치한다.
- 장·절·항 항목은 모두 같은 11pt이며, 본문 제목처럼 크기를 달리하지 않는다.
- 제목과 오른쪽 쪽수 사이에 탭 리더를 사용한다. PDF에서는 점선형 연결선으로 보이며, 쪽수는 오른쪽 끝에 정렬한다.
- 표 목차와 그림 목차를 따로 만들며, 본문과 동일한 `<표 2-1>`, `<그림 2-1>` 번호를 사용한다.
- 현재 목차 항목은 문서에 직접 들어간 텍스트와 탭·쪽수로 구성되어 있다. 제목 수정만으로 쪽수가 항상 자동 갱신된다고 가정하면 안 된다.

### 표

본문의 번호 있는 표는 **32개**다. 제목 번호는 **장 번호-장 안의 일련번호**로 구성하고 장이 바뀌면 다시 시작한다. 표지·제목 배치용 표와 도식용 표는 이 수에 포함하지 않았다.

| 요소 | 실제 관찰 |
| --- | --- |
| 위치 | 표 제목 → 표 → `자료:` 또는 `주)` → 설명 문단 |
| 제목 | `<표 2-1> [표 제목]`, 표 위쪽 가운데, 11pt |
| 일반 표 글자 | 한양신명조 10pt, 장평 100%, 자간 0% |
| 표 안 줄간격 | 주로 130% |
| 정렬 | 머리행 가운데, 설명문 왼쪽, 숫자 오른쪽을 구분 |
| 너비 | 본문 표는 대체로 약 140mm, 첫 표는 약 138mm |
| 셀 여백 | 일반 본문 표 기준 좌우 약 1.8mm, 상하 약 0.5mm |
| 머리행 | 연회색 배경 `#D9D9D9`, 위쪽 선 0.4mm |
| 나머지 선 | 주로 검은 실선 0.12mm. 내부 세로 구분선도 사용하며 바깥 좌우선은 없는 형태 |
| 반복 머리행 | 일반 본문 표에 제목행 반복 설정 사용 |

열이 많은 일부 표는 **9pt·장평 79%**로 압축되어 있다. 해당 표의 강조 숫자에는 **9pt 굵게·장평 100%**도 섞여 있다. 이는 모든 표에 적용할 기본값이 아니라 밀도 높은 표의 예외다.

### 그림

그림은 **4개**이며 `<그림 장-번호>` 체계를 사용한다. 이 파일에서는 **그림 제목도 그림 위쪽**에 배치한다. 일반 관행만 보고 아래쪽 캡션이라고 옮기면 참고본과 달라진다.

그림 아래에는 `자료: 연구자 작성.` 또는 재구성 출처를 적고, 본문에서는 `<그림 1-1>`처럼 번호로 연결한다. 실제 그림 개체뿐 아니라 문자·화살표·표 셀을 조합한 도식도 포함되어 있다. 따라서 ‘그림 4개’와 HWPX의 이미지 개체 수는 같지 않다.

**적용 권장:** 번호·제목·대상·출처·본문 설명을 한 묶음으로 유지한다. 표의 가독성을 확보한 뒤 열폭을 조정하고, 밀도 높은 표의 79% 장평을 모든 표의 기본 설정으로 복제하지 않는다.

## 6. 인용·참고문헌·초록·부록

### 인용과 참고문헌

본문 인용은 **저자–연도 방식의 내주**를 사용한다. 형식 예시는 `저자(연도)`, `(저자, 연도; 저자, 연도)`이다. 실제 각주·미주 개체는 없다. 표와 그림의 출처는 별도의 `자료:` 문단으로 표시한다.

참고문헌은 다음 순서로 분류한다.

```text
가. 학위논문
나. 학술지
다. 보고서
라. 관련법
마. 기타
바. 국외 단행본
사. 국외 학술지
```

각 분류 안에서는 `[01]`, `[02]` 형식으로 번호를 다시 시작한다. **참고문헌에 대괄호 번호가 있다고 해서 본문도 숫자 인용 방식인 것은 아니다.** 참고문헌은 첫줄의 번호·저자 부분보다 다음 줄을 안쪽에 정렬하는 내어쓰기 모양이다.

문헌 유형별 기본 배열은 아래와 같다. 표기 패턴만 추출했으며 서지 내용의 정확성은 검토하지 않았다.

| 유형 | 배열 패턴 |
| --- | --- |
| 학위논문 | `[번호] 저자(연도), “제목”, 대학·대학원·학위 종류` |
| 학술지 | `[번호] 저자(연도), “제목”, 학술지명, 권(호), 쪽 범위` |
| 보고서 | `[번호] 저자 또는 기관(연도), “제목”, 발행기관, 보고서 식별정보` |
| 법령·기관자료 | `[번호] 법령명·자료명, 공포번호·연도·기관 등` |
| 국외 문헌 | `[번호] 영문 저자(연도), 제목, 출판지·출판사 또는 학술지 정보` |

내어쓰기의 정확한 한글 입력값은 원본의 호환용 속성 분기에서 서로 다르게 저장되어 있으므로 수치 하나로 확정하지 않았다. PDF에서 **후속 줄이 안으로 들어가는 모양**은 확인했다. 일부 영문 서명에는 Markdown의 `*…*` 기호가 문자로 남아 있어 실제 이탤릭체 지정과 구분해야 한다.

### 초록과 부록

- **논문개요:** 별도의 제목 뒤에 본문과 같은 11pt·170%의 여러 문단을 배치한다. 별도의 주제어 행은 확인되지 않는다.
- **Abstract:** 제목 → 학위유형 → 영문 논문제목·부제 → 성명 → 전공·대학원·대학교 → 영문 본문 순서다. 메타정보는 가운데, 본문은 양쪽 정렬이다. 별도 Keywords 행은 확인되지 않는다.
- **부록:** 설문 안내 → 소속·연락 정보 → 응답 안내 → 일반사항 → 문항군별 응답표 → 감사 문구 순서다. `A.`, `B.`, `문1)`처럼 본문 장·절과 다른 번호 체계를 쓴다. 문항과 척도를 병합 표에 배치하며 본문 표보다 복잡한 격자다.

## 7. 그대로 복제하면 안 되는 작성 중 상태

아래 항목은 의도된 최종 서식과 구분해야 한다.

| 관찰된 상태 | 해석 및 적용 시 처리 |
| --- | --- |
| 빨간색 `[작성지침]`, `[자리표시자]`, `[미작성]` 문단이 남음 | 편집 중 안내이며 제출본 본문 서식이 아님. 실제 빨간 안내문은 11pt 굵게 |
| 본문·표에 `[입력]` 등 빈자리 표시가 남음 | 완성본으로 보지 말고 내용 확정 뒤 별도로 정리 |
| 그림을 한글에서 다듬으라는 안내가 남음 | 문자·표로 만든 도식은 편집 중 상태일 수 있음 |
| 설문 표에 빈 병합칸·복잡한 세로선 등이 있음 | 표본 PDF에서도 정리가 필요한 모양을 확인함. 완성 표준으로 복제하지 않음 |
| 일부 표의 9pt·79% 장평 | 좁은 열을 위한 예외. 기본 표의 10pt·100%와 구별 |
| 표 쪽 나눔 속성에 `CELL`이 저장됨 | 이 파일에서 읽힌 설정일 뿐 권장안이 아님. 새로 만드는 표에는 현행 저장소의 표 배치·검증 규칙 적용 |
| 공백·빈 문단·직접 입력한 목차로 배치 | 보이는 결과는 참고하되 수정 후 자동 정렬·자동 갱신을 기대하지 않음 |
| 영문 문헌에 별표가 문자로 남음 | 최종 참고문헌에서 실제 서체와 구두점을 정리할 대상 |

현재 원고에 적용할 때 우선 가져올 요소는 **구역별 편집 용지, 11pt·170% 본문, 장16/절15/항14pt 위계, 표·그림의 번호와 출처 배치, 목차 체계**다. 장 수·통계 절 구성·참고문헌 분류는 원고의 설계 및 지도 지침과 맞춰 적용한다.

## 확인 범위와 근거

- HWPX 3개 구역의 직계 문단 **2 / 134 / 712개**를 읽고, 표 안의 중첩 문단까지 실제 속성을 추적했다.
- 글꼴 ID를 언어별 글꼴표와 대조했다. 한글 ID 6과 영문 ID 7이 모두 한양신명조를 가리킨다.
- 본문 11pt·170%, 주요 제목의 새 쪽 시작, 번호 있는 표 32개·그림 4개를 기계적으로 확인했다.
- 임시 복사본의 한글 열기와 PDF 저장이 성공했고, 실제 조판은 **130쪽**이었다. PDF 전체의 쪽별 텍스트를 확인했다.
