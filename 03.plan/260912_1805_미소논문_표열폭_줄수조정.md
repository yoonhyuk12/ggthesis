# 미소논문 표 열폭 및 잘림 조정

- 사용자 요청: 1613본 인쇄 113쪽의 동일 열폭 표를 줄수·줄간격에 맞춰 조정하고 다른 표도 가능한 범위에서 모두 개선한다.
- 적용 기준: 서론·점선목차 반영을 보존하기 위해 최신 `04. 미소논문/00. hwpx/260912_1802_미소논문_서론반영_점선목차.hwpx`의 사본을 사용한다.

- 작업폴더: `04. 미소논문/tools/hwpx_transfer/staging/table_fit_260912/`. 원본 해시 `source.json`, 모든 표·셀 덤프 `tables.json`, 문단 덤프 `base_paras.json`.
- Orca Run `run_a2fcccc3f885`: 폭 조정 도구와 실제 PDF 잘림 감사·검증 도구를 두 워커에게 분리 위임한다. HWPX 쓰기·COM은 메인이 순차 수행한다.
- 범위: 전체 본문 표 45개 검토. 글꼴·본문·수치·마커와 표 총폭은 보존하고 열별 줄수와 행별 최대높이를 줄이는 폭 배분을 적용한다. 고유 설문 상자·척도 병합 양식은 개선이 필요한 경우 외에는 보존한다.
- `cellSz` 높이는 최소값이라 단순 높이합 검증만으로 완료하지 않는다. 실제 한글 재조판 PDF에서 하단 잘림과 문항 누락을 확인한다. 폭 조정으로도 한 쪽을 넘으면 행 경계에서 분할하고 머리행을 반복한다.
- 표 조정에 따라 달라지는 일반·표·그림 목차 115항목의 쪽번호도 재갱신한다.
