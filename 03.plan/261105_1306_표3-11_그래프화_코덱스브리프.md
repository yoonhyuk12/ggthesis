## 그림 설계

- 형식: 가로 막대(또는 점) + 평균±SD 오차막대. 축 1∼5점, 3점('보통이다')에 점선 기준선과 라벨.
- 구성: C 문항 8개 → A1∼A4 묶음 4개 → C 전체 → D 문항 4개 → D 전체 순. C와 D 사이, 문항과 묶음 사이를 시각적으로 구분(간격·구획 라벨). 묶음·전체는 문항과 다른 채움(진한 회색 등)으로 구별.
- 각 막대 끝에 평균값 숫자 표기(소수 둘째 자리). SD는 범례나 그림 하단 한 줄로 "오차막대는 ±1 표준편차" 명시.
- 문항 라벨은 C-1처럼 번호만 쓰되, 묶음은 "A1 범용성"처럼 이름을 붙인다. 문항 문구를 넣으면 읽기 쉬우면 짧게 줄여 병기해도 되지만 원문 의미를 바꾸지 않는다(넣었으면 보고에 문구 목록을 적는다).
- 흑백 인쇄에서 구별되는 회색조. 글꼴 맑은 고딕(`C:/Windows/Fonts/malgun.ttf`, `malgunbd.ttf`), 한글 깨짐 없게.
- 크기: 한글 삽입 폭 150 mm 기준, 300 dpi PNG + 편집용 SVG(텍스트 유지).
- 그림 안에 제목·캡션을 넣지 않는다(캡션은 본문 MD에 둔다).
