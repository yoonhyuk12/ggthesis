## 판단과 범위

- 교수 지도 취지는 안전관리 실효성을 하나의 종속변수로 보고, 문항 내용 구분을 독립된 하위변수·하위척도로 취급하지 않는 것으로 이해한다.
- 현행 정의·문항·분석의 단일 원본은 `01.docs/04_연구설계및실증분석.md`와 `01.docs/부록1_설문지_양식.md`다. 이 계획은 별도 분석 설계 원본이 아니다.
- 사용자가 언급한 네 개와 달리 현행 MD는 다섯 내용 묶음이다. 개수 재분류가 아니라 하위요인 지위 제거가 작업 목적이다.
- 이미 수집한 B문항의 문구·번호·응답·전체점수 채점은 보존한다. 이론을 맞추려고 문항을 사후 변경하거나 새 문항을 만들지 않는다.
- 단일 종속점수와 엄밀한 단일차원성 입증은 구별한다. 요인분석·신뢰도만으로 타당성을 완전 입증했다고 쓰지 않는다.
- 하위요인별 검정은 본문에서 제외하는 안을 기본으로 한다. 기존 분석 출력과 과거 작업 기록은 삭제·재작성하지 않고 보존한다. 사후 보고범위 변경을 사전 계획이었던 것처럼 꾸미지 않는다.
- 원고 내용 작업만 대상으로 하며 HWPX·발표자료 반영은 이번 과제에 포함하지 않는다.

## 작업 운영

1. 위 순서대로 한 워커의 작업·검증·Advisor 검토를 마친 후 다음 과제를 시작한다. 같은 4장 파일을 병렬로 수정하지 않는다.
2. 각 작업 브리프에 정확한 파일/절과 쓰기 허용 범위, 지킬 수치·문항, 검증방법을 명시한다. git 쓰기, HWPX 도구, 범위 밖 파일 변경은 금지한다.
3. 작업 시작 전 해당 워커가 박종용 교수님 논문작성요령과 해당 규칙을 읽는다. 현행 원고를 다시 읽고 앞 과제의 변경을 이어받는다.
4. Advisor가 장 간 내용 파급을 판단한다. 워커가 증거 첨부(diff 요약, 검색 결과, 필요한 출력 대조) 보고 후 다음 과제 진행 여부를 정한다.
5. 가정 점검표 신설이나 CI·효과크기 설명의 일반 윤문은 단일변수 정리와 별개의 개선이다. 이번에는 필요한 개념 정합 수정만 하고 범위를 확대하지 않는다.
6. 제3장의 기술 성능 및 C/D 인식 결과는 B 실효성의 하위변수가 아니다. 관련 없는 분석을 함께 삭제하지 않는다.
