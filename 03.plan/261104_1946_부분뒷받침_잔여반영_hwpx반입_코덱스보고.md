## 시행 중 수정한 문제

- 최초 서지 삭제 스크립트는 lxml 직렬화 시 namespace 선언이 붙어 원문 바이트 찾기 assert에서 중단했다. 파일은 생성되지 않았으며, 원문 XML 문단 위치 기반 삭제로 수정했다.
- PDF 출력 도중 읽기를 시도해 잠금 오류가 났으나 출력 완료를 기다린 뒤 정상 검사했다.
- 최종 배치 보존 검사에서 표 높이 캐시 증가를 잡았다. 사용자 서식 손실이 아니라 내용 확장에 따른 재조판 값임을 셀 크기·전체 폭·PDF 배치로 확인했다.
