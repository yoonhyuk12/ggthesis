# 그림 1-1 표본 수치 갱신 결과

## 수정 범위

`01.docs/01_서론.md` 81행과 그림 1-1 SVG·PNG만 수정했다. 본 보고서 외 다른 파일은 쓰지 않았다. 기존 생성 스크립트와 같은 폴더의 다른 파일은 작업 전후 SHA256 일치를 확인했다.

## MD 변경 전후

변경 전:

```mermaid
  C --> D["60현장·60명 모집 목표: 현장당 1명·사후 설문 1회"]
```

변경 후:

```mermaid
  C --> D["도입 32개소·미도입 39개소, 응답 71명(모집 목표 60명): 현장당 1명·사후 설문 1회"]
```

바이트 단위 치환 후 역치환 결과가 수정 전 전체 파일과 일치한다. 변경 행은 81행 한 줄이며 CRLF 102개를 그대로 보존했고 단독 LF는 0개다.

## 생성 방법

기존 스크립트 `01.docs/figures/research/generate_research_figures.py`를 재사용했다. 파일을 수정하거나 전체 스크립트를 실행하지 않고 `runpy.run_path(..., run_name="figure_refresh")`로 로드한 뒤 `Figure.text`에 두 라벨의 메모리상 치환을 적용하고 `flow()`만 호출했다. `model()`은 실행하지 않았으며 `sys.dont_write_bytecode=True`로 캐시 쓰기도 방지했다. PowerShell에서 `$env:PYTHONIOENCODING='utf-8'` 설정 후 Python stdin 코드를 실행했다.

렌더러는 원래 스크립트의 Pillow ImageDraw이며 Malgun Gothic(malgun.ttf/malgunbd.ttf), 300 dpi, 기존 좌표·크기·색상을 그대로 사용했다. 실행되는 라벨 치환은 다음 두 건이다:

- 전: `도입 30개소·미도입 30개소, 사후 설문 1회`
- 후: `도입 32개소·미도입 39개소, 응답 71명(모집 목표 60명):`
- 전: `현장당 1명·총 60명 모집 목표 / 공변량·분석 절차 설정`
- 후: `현장당 1명·사후 설문 1회 / 공변량·분석 절차 설정`

장기 재생성 시에는 같은 치환을 다시 적용해야 한다. 생성 스크립트의 오래된 상수는 이번 허용 수정 범위 밖이므로 수정하지 않았다.

## 범위 밖 관찰

기존 그림 하단의 `jamovi 사용` 문구는 다른 노드·문구 변경 금지에 따라 보존했다. 그림 4-1과 생성 스크립트의 모집 목표 관련 기존 내용도 변경하지 않았다. Git 쓰기 명령 및 HWPX 도구·파일 접근은 수행하지 않았다.

## 후속: 생성 스크립트 현행화 및 그림 1-1·4-1 재생성

앞선 보고서의 범위 밖 관찰 중 생성 스크립트 상수 및 jamovi 문구를 후속 지시에 따라 갱신했다. 서론 MD는 수정하지 않았으며 작업 전후 바이트 일치를 확인했다.

### 스크립트 diff 요지 (3개 항목)

1. 그림 1-1 표본 라벨 두 줄을 도입 32개소·미도입 39개소, 응답 71명(모집 목표 60명) 및 현장당 1명·사후 설문 1회로 갱신했다. 직전 이미지의 콜론과 공변량·분석 절차 설정 문구도 그대로 유지했다.
2. 그림 1-1 하단 분석 도구를 jamovi에서 Python statsmodels로 바꿨다.
3. 그림 4-1 하단 총 60명 모집 목표를 응답 71명(도입 32개소·미도입 39개소)으로 바꿨다.

실제 스크립트 변경은 66·67·84·122행의 문자열 4줄이며 위 3개 항목에 해당한다. 좌표·글꼴·크기·배치·캔버스 및 나머지 코드는 그대로다.

### 실행 방법

PowerShell에서 `$env:PYTHONIOENCODING='utf-8'`을 설정하고 Python stdin으로 아래를 실행했다.

```python
import sys, runpy
sys.dont_write_bytecode = True
runpy.run_path('01.docs/figures/research/generate_research_figures.py', run_name='__main__')
```

스크립트 main의 flow()·model()을 모두 실행했으며 캐시 쓰기를 비활성화했다.
