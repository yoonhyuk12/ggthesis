# 참고문헌 팩트체크 W20 (2026-11-04)

## 요약

문헌 5건 / 서지: 일치 4·불일치 1·외부 확인 불가 0 / 입력 인용 줄 8건 전부 확인, 주장별 분리 11행: 뒷받침됨 9·부분 뒷받침 1·불일치 1·확인 불가 0 / 과거 확정 판정 번복 0건(추가 발견은 아래 기재).

- 서론 12행의 “전담 선임 의무가 적용되는 … 미만”은 법령의 **이상**과 적용 방향이 뒤집혀 읽힌다. 숫자는 일치하지만 문장 수정이 필요하다.
- 시행령 서지에 **대통령령 제36540호**가 빠졌다. 산업안전보건법의 6.1 시행판은 실재하는 인용판본이지만, 2026-11-04 현재 대조 기준은 같은 법률 제21374호의 **2026.8.1 시행판**이다.
- 4장 관리비 서술은 법 제72조와 관련 고시 영역이다. 목록의 제15·17조만으로는 해당 기준을 추적할 수 없다.

검증 범위: 지정 블록만 읽기 전용으로 확인하였다. 보유 PDF는 PyMuPDF로 표제와 해당 조문을 추출했고, 외부 자료는 공식 법령·OSHA 원문을 열었다. 웹자료에는 고정 인쇄/PDF 쪽수가 없으므로 “인쇄 p.해당 없음 / PDF 해당 없음”으로 표시하고 조·항 또는 Action item을 위치표지로 쓴다. 없는 쪽수를 만들지 않았다. 입력의 8건은 문헌별 인용 건수이며 3장 156행은 L01·L02·L03에 각각 속한다.

## 장 간 불일치

1. **01장 12행 ↔ 07 목록 375행:** 목록은 120억·150억 **이상**을 전담 의무 기준으로 정확히 적었으나 서론은 “의무가 적용되는 … 미만”으로 썼다. 연구 범위를 미만으로 정하는 것 자체가 문제는 아니며 법적 적용방향을 표현하는 수식 구조가 문제다.
2. **04장 86행 ↔ 07 목록 374행:** 관리비 기준을 활용했다고 쓰면서 목록은 제15·17조만 특정한다. 제72조·위임 고시로 추적 경로를 보완할 필요가 있다. 이는 내용 충돌보다 근거 조문 범위 누락이다.
3. OSHA의 2장 본문·표·부록2는 개념적 보완 근거라는 해석이 일관된다. 연도·수치 충돌은 없다. 다만 부록2는 “최초 문항 개발 시 사용한 척도의 출처가 아니라”라고 구분하므로, 2장 144행의 “문항을 구성하였다”가 실제 개발시점에 OSHA를 사용했다는 뜻이라면 과정 서술을 재확인할 필요가 있다. 공식 페이지로 개발 이력을 판정하지 않았다.

## 확인 못 한 것과 이유

- L01·L02·L04·T02는 보유 PDF가 없어 PDF 쪽 대조는 불가하지만 공식 HTML 원문 확인으로 내용은 판정할 수 있었다.
- 법령의 일반 URL은 기준일을 보장하지 않는다. 산업안전보건법 제15조 일반 링크는 **2027.4.28 시행, 법률 제22122호**로 연결되었다. 이를 현행판으로 오인하지 않고 `efYd=20260801&lsiSeq=283449`의 공식 전문을 별도로 열어 현재 시행판의 제15·17·72조를 대조하였다(직접 HTTP 200 확인).
- 6.1 시행판의 조문별 페이지는 표제를 읽을 수 있었지만 이번 열람에서는 본문이 비어 있었다. 따라서 6.1 판본의 조문 전문까지 직접 검증했다고 주장하지 않는다. 해당 판본의 실재·서지와 8.1 시행판의 실제 조문, 2025 보유 PDF는 구분하여 확인하였다.
- 관리비 관련 고시의 구체적 문항 매핑과 개발 이력, 김용선 선행연구 주장은 본 블록의 원문 범위 밖이다. 법령 확인 결과만으로 실제 설문개발 절차를 입증하지 않았다.
- 입력 5건 모두 prior_record_07은 빈 배열이다. 9월 종합·개별 서지 보고에서 이 5건의 개별 확정 판정은 검색되지 않았다. 따라서 과거 확정 판정 번복은 0건으로 집계하며, 새로 확인한 번호 누락·현행 시행판·문장 적용방향은 별도 발견으로 보고한다.
