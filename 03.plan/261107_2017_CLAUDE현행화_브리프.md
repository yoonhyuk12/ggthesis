# 현행 논문 전체 독해 후 CLAUDE.md 현행화

## 사용자 요청과 범위
사용자: 지금 논문 전체적으로 읽어보고, claude.md 업데이트 해주라.
현행 원고 전체를 읽은 뒤 CLAUDE.md만 실제 수정한다. 03.plan/README.md에는 이 브리프 및 보고서 링크만 끝에 추가 허용. 보고서는 03.plan/261107_2017_CLAUDE현행화_검토보고.md에 작성한다. 기존 원고·검토초안·HWPX·AGENTS.md·MEMORY·규칙·스킬·도구·참조인덱스는 수정하지 않는다. git 쓰기 금지. 사용자 기존 변경을 되돌리지 않는다.

## 먼저 읽을 기준
CLAUDE.md 전체, .claude/rules/lean-claude-md.md, 교수님 논문작성요령 전문(앞선 작업에서 전문 독해한 기준 재활용 가능). CLAUDE.md는 목차이며 연구내용 요약본을 만들지 않는 것이 핵심이다. 논문 수치·가설·문항·장절표를 복제하지 말고 실제 원고 절/항을 가리키는 포인터로 정리한다. 적용 규칙은 필요한 것만.

## 전체 독해 범위
01.docs/00_목차.md(국문/영문초록 포함), 01_서론.md, 02_이론적배경.md, 03_시스템개발.md, 04_연구설계및실증분석.md, 05_논의및결론.md, 07_참조번호목록.md, 부록1_설문지_양식.md, 부록2_설문항목_근거매핑.md, 감사의_글.md의 전문을 읽는다. 긴 출력은 100~160줄 단위 등으로 나눠 잘림 없이 읽을 것. 연구 사실은 반드시 이 원고 기준. 설문항목_작업이력.md와 08_자모비 결과 넣을부분.md, 09. 심사대비 정리.md는 성격/현행성 판단에 필요한 부분만 읽어 본문과 구별한다. 보고서에는 읽은 파일과 범위를 명시하라. 원문PDF/웹/HWPX 도구 작업 불필요.

## 이미 확인한 문제와 편집 방향
- CLAUDE.md는 제4장을 제7절까지로 소개하나 현행 제8절 분석결과 및 논의가 있음. 제5장은 절 없는 결론이고 현재 문단 수를 고정해 복제할 이유 없음. 원고 구성 세부 나열을 현행00목차 링크와 핵심 파일 역할 포인터로 단순화.
- 제목 전체, 표본수, 도구 버전, 항목개수 등 자주 낡는 원고 사실 복제는 가능한 원고 포인터로 대체. 개발+실효성 비교의 두 축을 잃지 않도록 읽을 원고 위치를 안내하되 새 연구모형 요약문 만들지 말 것. 중소규모 정의는 현행01서론 제1절에 있고 실제 조사 범위는 제3절/04장에 있으므로 찾을 위치를 명확하게.
- 현행 CLAUDE.md의 hwpx반입상태는 261106_0739 뒤를 미반입이라고 함. 00. hwpx 디렉토리 파일명과 03.plan/261106_1052_MD변경분_hwpx반입.md, 261106_0114_hwpx반입대기_체크리스트.md 등을 필요한 부분만 읽고 낡은 완료/미완료 단정 제거. 실제 MD-HWPX 내용대조를 하지 않았으므로 동기화완료를 새로 주장하지 말 것. 최신본은 매 작업시 YYMMDD_HHMM 접두사 재검색 원칙만 유지. 파이프라인 아래의 261028_0757이 현재 최신이라는 모순도 제거. 역사적 해시·파일명 나열은 기존 계획 링크로 대체 가능. 사용자의 직접 수정 보존, 복사본 부분치환, MD우선, 재조판/PDF검증 등 안전 규칙은 유지.
- 문헌 수 69/96 등 고정 집계와 모든자료가 인덱스에 있다는 단정은 신규 하위폴더 조사자료와 맞지 않을 수 있음. 확정 서지는07목록, 보유원문 분류는05참조자료, 미등재 신규자료는 조사보고서라는 포인터 구분. 도구상태/코드 자체 검증 없이 버전·테스트개수 새 확정 금지.
- 최신 세션 상태를 짧게 기록: 서론 제1절 재구성은 03.plan/261107_1955_서론제1절_재구성초안.md 및 261107_1946_서론제1절_재구성안.md에서 검토 중, 01.docs에 미반영. 전체대조상 부분보완 후 교체 권고만 있고 채택 완료 아님. 기존 실효성 비교 필요성·중소규모 정의를 보존해야 함. 사용자는 정부목표→CCTV활용→관제/오탐→중소규모 재해집중 및 인력비용→개발 필요성 흐름을 논의함. 새초안에는 후반 재해집중 문장이 아직 없으므로 완료로 기록 금지. 이 상태는 링크와 짧은 구분만, 원문 수치 재복제 금지.
- 원고밖 초안금지 원칙은 유지하되 사용자가 이번 세션에 명시적으로 03.plan에 초안을 쓰게 했으므로 '사용자가 별도 검토용 초안을 요청한 경우 지정계획서에 원고미반영 표시, 현행원고와 혼동 금지'로 좁은 예외를 명시 가능.
- 파일명을 문서에 무조건 고정하는 것보다 단일원본 포인터 우선. 기존 하네스 운영규칙·스킬·워커 모델 분담 등 사용자 정책을 멋대로 바꾸지 말 것. 외부 도구 최신성검증은 이번 범위 밖.

## 검증 및 보고
변경 전 CLAUDE 내용을 작업 메모리에서 보존해 이번 턴 변경만 diff로 검토한다(HEAD와 비교하면 기존 사용자 변경이 섞임). 전문 독해 근거를 기반으로 링크 대상 존재/실제 절 위치, 낡은 현재최신/미반입 단정 제거, 안전규칙 보존, 원고수치 중복 축소를 한 번 점검. 원고파일 hash 전후 동일 확인은 가능하며 과도한 테스트 불필요. 보고서에 수정항목/근거 원고 위치/미해결 불일치/독해범위/검증 증거와 줄수 변화를 기록. 원고 내부 모순은 이번에 고치지 말고 필요한 것만 보고. worker_done으로 결과와 보고서경로, 핵심diff와 검증을 반환. 후속 사용자 확인을 기다리며 작업을 멈추지 말고 요청된 CLAUDE 업데이트까지 완료하라.
