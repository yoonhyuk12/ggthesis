# 서론 제1절 재구성 근거 조사와 구성안
- 사용자 승인 범위: 기존 문헌·웹 조사, 원문 다운로드, 표/그림 확보, 현행 분량의 구성안. 현행 원고 및 HWPX 미수정.
- 순서: 정부 감축목표·건설업 비중 → CCTV 보급 및 효과성 인식 → 녹화/사후확인 한계 → 오경보 → 비용 → 기존 CCTV·PC 기반 YOLO-LLM 필요성.
- W1: 보급·효과성·원문 도표·현행 분량. W2: 사후활용·오경보·경보 중단. W3: 정부목표·재해 지표·비용.
- 팀장: 결과의 직접성/분모/일반화/현행 시스템 정합성을 검토하고 부족한 항목은 재지시한다. 결과 취합 후 문단별 분량과 출처가 붙은 구성안을 이 계획 영역에 작성한다. 본문 초안은 원고 외부에 만들지 않는다.
- 확인하지 못한 주장은 확정하지 않는다. 기존 07 참고문헌목록은 변경하지 않는다.
