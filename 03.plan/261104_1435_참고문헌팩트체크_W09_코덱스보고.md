검증 방법: 보유 PDF 3건을 PyMuPDF로 읽었다. 조도빈 표제·제출·인준면(PDF 2~4쪽), 국문 요약(PDF 5쪽), 결과 논의(PDF 40쪽)는 추출 누락이 있어 렌더링 이미지로 직접 확인했다. 나머지는 원문 텍스트와 쪽 표기를 대조했다. 외부 요청은 3초 이상 간격으로 수행했으며 웹 도구 실패는 일반 HTTP 요청으로 보완했다. 입력 JSON에서 memo=false인 수정이력성 줄 두 개도 빠뜨리지 않고 서지 주장으로 판정했다.

## 장 간 불일치

없음. 담당 인용에서 조도빈 저자·2026년은 제2·3장과 부록2가 일치한다. KISA와 한소은은 입력상 각 한 줄이다. 수정이력성 문구 두 줄이 입력에서 memo=false로 분류된 것은 집계상 주의점이며 연도 불일치가 아니다.

## 확인 못 한 것과 이유

- 고가 장비 구매 여력 부족과 관리비 준수율 사이의 직접적인 인과 근거는 확인하지 못했다. 원문은 저조한 집행과 복합적인 제도·운영 문제를 다루며 구매능력 실증과 구별된다. 해당 복합 주장은 부분 뒷받침으로 판정했다.
- 조도빈의 추출 텍스트에는 본문 누락이 많아 검색 결과만으로 특정 내용의 부재를 확정하지 않았다. 위 표의 핵심 근거는 실제 렌더링 면을 읽고 전사했다.
- 두 학위논문의 별도 ‘학년도’ 표기는 표제·제출·인준면에서 확인되지 않는다. 명시된 연월과 외부 발행·학위연도만 보고했다. DOI는 현행 목록에 없으며 이번 대조에서 확정하지 않았다.
- 조도빈 외부 레코드의 학과명이 과거 기록과 달라진 이유·변경 시점은 확인할 수 없다. 현재 열람한 필드와 과거 기록을 구별했다.

## 완료 확인

입력 W09의 K18·K19·K20을 서지표에 모두 포함했다. memo=false 위치 5개를 모두 인용표에 포함했고 복합 주장 두 줄을 각각 나눠 7행으로 판정했다. 원고·PDF·입력·README·도구·git 이력은 수정하지 않았다. 저장소 산출물은 본 보고서 한 개이며 렌더링 이미지 임시는 지정 TEMP 디렉토리만 사용했다.
