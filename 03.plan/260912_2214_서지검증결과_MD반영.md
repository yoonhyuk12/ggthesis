## 공통 결정

- 06·18은 이창남(2025)의 같은 문헌. 06을 대표 인용번호로 사용하고 18은 중복 파일 기록으로 남긴다. 원문 파일명·번호 재부여·삭제는 하지 않는다.
- 19는 영문 표기 Mi(2025), 경북대 박사학위논문으로 통일. 22 김용선(2022), 28 조도빈(2026), 32 류정·박인선(2025), 45 노희상·박종용·정상윤(2026), 30의 VLM 학위논문은 한소은(2026).

- 36의 기관저자는 국토교통부·국토안전관리원(2024). 다른 한국산업안전보건공단 문헌까지 일괄 치환하지 않는다.
- 기사 내주는 김정아(2021), 손형주(2024). 제목·발행일·기자명·URL은 검증 보고서 사용.
- 이론 원전 6건은 검증된 서지를 07목록에 기록하되 PDF 파일 일련번호를 새로 부여하지 않는다. Tiwari·Herstatt와 라벨 데이터 Kim은 미확정 마커 유지·명료화. 임의 후보로 대체하지 않는다.
- 서지 치환과 직접 관련된 오해만 최소 교정: Mi의 .980은 PPE 탐지, 화재 논문 .3은 동적 임계값, 한소은의 가중 정확도와 FAR는 직접 우열 비교 금지. 비용은 검증된 개별 단가와 연구자 가정을 구분하고 4,540만원을 확정 TCO 또는 검증된 95% 절감으로 단정하지 않는다. 기존 숫자를 임의로 재산정하지 않고 미확정 범위를 표시한다.
- 연구 설계·가설·문항·실험 결과·장절 구조는 보존한다. 논문 내용을 대폭 재작성하거나 새 연구를 추가하지 않는다. HWPX, 원문 PDF, 02.reference, .claude, MEMORY, git 쓰기는 금지한다.
