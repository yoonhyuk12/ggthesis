## 단계 (순서대로, 각 단계의 명령과 출력을 보고서에 그대로 붙인다)

1. 내려받기·검증
   - `https://github.com/edwardkim/rhwp/releases/download/v0.8.6/rhwp-v0.8.6-windows-x86_64.zip`
   - `https://github.com/edwardkim/rhwp/releases/download/v0.8.6/SHA256SUMS.txt`
   - SHA256 대조(PowerShell `Get-FileHash` 또는 Python `hashlib`) → 일치/불일치 기록. 불일치면 **중단하고 보고.**
   - 압축 해제 후 `rhwp.exe --version`(또는 `rhwp.exe capabilities`)로 버전 확인.
2. 논문 파일 복사: `"C:/Users/User/Documents/2026 개발관련/03. 경기대 논문/00. hwpx/260911_1101_경기공학_건축안전_윤혁_논문작성_작성본.hwpx"` → `thesis.hwpx`. 원본은 이후 절대 건드리지 않는다.
3. CLI 실측 — 각 명령을 PowerShell `Measure-Command { … }` 또는 Python `time.perf_counter()`로 감싸 **ms 단위**로 잰다. 플래그는 `rhwp.exe <명령> --help`로 먼저 확인한다.
   - `rhwp.exe capabilities` (출력은 `capabilities.json`으로 저장)
   - `rhwp.exe info thesis.hwpx`
   - `rhwp.exe export-text thesis.hwpx …` (출력 파일 크기·줄 수 기록)
   - `rhwp.exe verify thesis.hwpx`
   - `rhwp.exe layout-anomaly thesis.hwpx`
   - `rhwp.exe dump-pages thesis.hwpx -p 0`
   - `rhwp.exe export-pdf thesis.hwpx -o thesis_rhwp.pdf` (PDF 쪽수 기록 — Python으로 `/Type /Page` 개수 세기 등)
4. MCP 세션 실측 — Python 스크립트로 `rhwp.exe mcp-serve`를 `subprocess.Popen(stdin/stdout=PIPE)`로 띄우고 stdio JSON-RPC(줄 단위 JSON)로 다음을 순서대로 보내며 **호출별 벽시계 시간(ms)**을 잰다. 응답 원문은 `mcp_log.jsonl`에 저장한다.
   1. `initialize` (protocolVersion "2024-11-05") → `notifications/initialized`
   2. `tools/list` → 도구 개수
   3. `tools/call hwp_open {"path": "<thesis.hwpx 절대경로>"}` → `docId`
   4. `tools/call hwp_doc_info {"docId": …}`
   5. `tools/call hwp_doc_search {"docId": …, "query": "산업안전보건법", "maxMatches": 5}`
   6. `tools/call hwp_doc_text {"docId": …, "page": 10, "maxChars": 2000}`
   7. `tools/call hwp_close {"docId": …}`
   인자 이름이 다르면 `tools/list`의 inputSchema를 보고 맞춘다. 어느 호출이든 **5분 넘게 응답이 없으면 프로세스를 죽이고 그 사실을 기록**한다.
5. 정리: 띄운 rhwp 프로세스가 남아 있지 않은지 확인.
