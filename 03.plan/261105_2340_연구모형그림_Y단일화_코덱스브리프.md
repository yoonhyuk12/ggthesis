# <그림 4-1> 연구 모형 — 종속변수 Y 상자에서 y1~y5 제거 (Codex 워커 브리프, 2026-11-05 23:40)

## 할 일
지도교수 지도에 따라 종속변수(Y)는 '안전관리 실효성' **하나**다. 연구 모형 그림의 종속변수 상자 안에 적힌 `y1. 조기인지`·`y2. 대응 신속성`·`y3. 원격 파악`·`y4. 순찰부담 경감`·`y5. 위험 통제력` 다섯 줄을 지우고, 상자에는 제목 `종속변수(Y)`와 본문 `안전관리 실효성`만 남긴다. 독립변수(X) 상자, 통제변수(C) 상자, 화살표 두 개(X→Y, C→X–Y 선)는 **그대로** 보존한다.

## 파일(저장소 루트 기준 상대경로)
- 생성 소스: `01.docs/figures/research/generate_research_figures.py` — `model()` 함수(현재 L92~L116)만 고친다. `flow()`·`means_ci()`는 건드리지 않는다.
- 정본 산출물: `01.docs/figures/research/figure_4-1_research_model.svg`, `figure_4-1_research_model.png` (둘 다 재생성·덮어쓰기 대상). 다른 그림 파일(`figure_1-1_*`, `figure_4-2_*`)은 재생성하지 않는다.

## 절차
1. 작업 전에 현재 `figure_4-1_research_model.png`를 열어 보고(이미지 뷰어 또는 PIL로 확인) 현재 배치(X 상자 좌측, Y 상자 우측 높이 470, C 상자 아래, 화살표 위치)를 파악한다. 현재 SHA256을 기록한다.
2. `model()`에서 `for i,t in enumerate(['y1. 조기인지', …])` 루프를 삭제한다. Y 상자는 다섯 줄이 사라지면 비어 보이므로 **높이를 X 상자와 같은 270으로 줄이고 X 상자와 같은 y좌표(250)에 맞춰** 배치한다(`headed_box(1040,250,420,270,'종속변수(Y)')`). `안전관리 실효성` 글자는 상자 본문 가운데(세로 중앙 근처, 예: y≈400)에 두고 글자 크기는 X 상자 본문과 같은 34를 쓴다. X→Y 화살표(`f.line([(560,385),(1040,385)],arrow=True)`)와 C→선 화살표는 그대로 두되, Y 상자 이동 후 화살표가 상자 머리띠(제목 구분선 y=330)나 상자 밖을 지나지 않는지 확인한다. 캔버스 전체 높이(780)는 유지한다.
3. **`model()`만 실행**한다. `__main__`은 `flow(); model(); means_ci()`를 전부 돌리므로 그대로 실행하면 무관한 그림이 재생성된다. 다음처럼 호출한다:
   ```
   cd 01.docs/figures/research && python -c "import generate_research_figures as g; g.model()"
   ```
   (파일이 `Figure` 클래스에서 svg·png를 함께 저장하는지 코드를 먼저 읽고 확인한다. PIL 등 의존성이 없으면 설치하지 말고 보고한다.)
4. 재생성된 PNG를 열어 육안 확인: y1~y5가 없고, 상자 3개·화살표 2개·글자 겹침 없음.
5. svg 파일 안에 `y1`·`조기인지` 문자열이 없는지 `grep`으로 확인한다.
