# 지정 HWPX 발표자료 반영

- 근거: `00. hwpx/261108_1359_경기공학_건축안전_윤혁_논문.hwpx`.
- 기준 발표: `06. 발표/261106_1209_윤혁_석사학위논문_심의발표.pptx`. 원본을 보존하고 KST 작업시각 접두사의 새 PPTX·PDF를 같은 폴더에 저장한다.
- 지정 논문의 변경 내용을 기존 슬라이드·노트·표와 대조해 타깃 반영한다. 추가 지시에 따라 17번 슬라이드의 지시 전달 소요시간·과정지표 A-9 내용과 관련 발표노트를 제거한다.
- 구현·검증: update_slides 워커, 쓰기 범위는 `06. 발표/**`. 원고와 HWPX는 수정하지 않는다. 제공 문단 덤프는 `06. 발표/작업자료_261108/base_paras.json`.
- 완료 기준: PowerPoint 개방·PDF 출력, 수치·표현 대조, 전 슬라이드 렌더와 넘침 검사, 변경 슬라이드 시각 검토, 기존 원본 해시 불변. 검증 증거와 변경 목록은 작업자료 폴더 JSON에 기록한다.

## 사용자 범위 확대 — 발표 전체 스토리 재구성

- 추가 지시: 전체 HWPX 내용을 보고 설득력 있고 이해하기 쉽게, 스토리텔링이 되도록 재구성.
- 구성 원칙: CCTV의 관제 한계 → 시스템 개발 해법 → 기술적으로 작동하는지 → 도입 현장의 실효성 차이 → 의의와 결론의 범위. 목차 나열보다 질문과 답으로 구성한다.
- A-9 지시 전달 소요시간은 재구성 발표에서 제외. 기술 검출시간과 구별한다.
- 주요 분석은 단일 종속변수 실효성과 주가설에 집중. 횡단비교 결과를 인과효과로 과장하지 않는다.
- 본발표 약 18~21장, 필요한 부록만 추가하는 방향으로 워커에 재지시. 최종 재구성본만 PowerPoint·PDF·시각 검증한다.

## 사용자 교정 — 논문 장순서 유지

- 사용자는 WHY/HOW/WHAT을 발표 전체의 대분류로 쓰는 것이 아니라, 논문 목차 순서대로 구성하고 각 장 안에서 필요성·핵심내용·방법을 자연스럽게 설명하도록 교정하였다.
- 지정 HWPX 실제 목차를 따른다: 서론 → 이론적 배경 → YOLO-LLM 안전관제 시스템 개발 → 연구설계 및 실증분석 → 결론. 초기 저장소 인덱스의 장명보다 사용자 지정본 실제 장명을 우선한다.
- 제작 워커 update_slides, 장별 논리 검토 story_review. 이론적 배경 보완, 기술평가·운용실태는 3장, 비교 설계·실증결과·논의는 4장으로 정렬. WHY/HOW/WHAT 전면 표기는 제거한다.
- 새 버전 PPTX/PDF 출력 및 검사 후 보고. 기존 파일 보존, A-9 삭제 유지.
