# 제4장 표 앞 설명 정리와 HWPX 반영

- 사용자 승인: 제4장의 표 후행 설명을 정리하라는 요청. 직전 답변의 MD 정리 후 HWPX 반영을 실행한다.
- 기준 HWPX는 작업 시 접두사 최신본 `00. hwpx/261104_0817_경기공학_건축안전_윤혁_논문.hwpx`.
- MD: 제4장 잔여 민감도·강건성 설명을 표 앞에 배치하고 표 지시로 시작하는 본문을 조립기 오인 없이 고친다. 표 수치·인용·결론 보존.
- HWPX: 현행 제4장과 그림·목차 항목을 반입. 사용자 직접 수정분을 대조하고 기존 표 병합·폭·서식을 가능한 범위에서 보존. 다른 장 본문은 건드리지 않는다.
- 워커1 MD 수정·검증, 워커2 반입 코드 준비·읽기 전용 검증. HWPX 쓰기 및 COM은 메인만 순차 실행.
- 완료 조건: 한글 Open/SaveAs/Reopen/PDF 성공, 전 표 배치·내용 보존, 목차 실제 인쇄 쪽수 대응, 기준본 SHA256 불변.

## 진행

- MD 표 4-13 뒤 민감도·강건성 설명을 앞에 이동, 표 4-12 해설의 캡션 오인 방지. 표 15개·수치·인용 보존 검증 완료.
- 사용자 추가 요청에 따라 `CLAUDE.md`, `.claude/rules/defense-feedback.md`, `.claude/rules/hwpx-table-layout.md` 업데이트. 모든 장의 표 설명·해석·주를 표 앞에 배치하고 실제 HWPX/PDF의 순서와 반영·미반입 범위를 확인하도록 명시.
- 최신 MD는 기존 HWPX 17표와 구조가 달라 13표 재구성, 2표 기존 구조 보존. 다른 장 본문 XML 불변.
- 1차 한글 출력에서 전 표 셀 끝 1,777건 누락 0, 꼬리말 침범 0. 육안 확인에서 목차 본문 오인 3항목 및 표 4-4 머리행 고아 문제를 발견해 정식 제목 추출·해당 캡션 새 쪽 처리.
- 2차 출력에서 표 4-4 캡션·첫 데이터행 동일 쪽, 이어지는 쪽 머리행 반복·마지막행 정상 확인. 제4장 정식 제목 20개와 표 15개 앞 설명 순서 원고 일치.
