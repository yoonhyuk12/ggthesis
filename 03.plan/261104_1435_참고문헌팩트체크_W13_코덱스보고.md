## 장 간 불일치

두 문헌의 입력 대상은 모두 제2장이며 장 간 저자·연도·수치 불일치는 없음. 다만 동일 장 안에서 F09는 97·114행에서는 “관계”, 189행에서는 “향상 효과 확인”으로 주장 강도가 달라지고, 178행은 수용 의도와 실제 성과의 차이를 실증한 것처럼 읽힌다. 이는 서로 모순됨을 확정한 것이 아니라, 원문 미보유 상태에서 확인 범위를 넘어서는 표현의 차이다.

## 확인 못 한 것과 이유

- F09 원전 전문은 미보유다. Crossref는 서지 확인만 가능하고 OpenAlex의 abstract_inverted_index는 null이었다. 출판사 직접 접속은 HTTP 403(3초 이상 간격으로 1회 재시도도 동일)이므로 전체 초록·방법·결과를 열람하지 못했다. 제목 정확검색으로 출판사 검색 결과의 초록 1문장만 확인했다.
- ref 83·84는 각각 별개 저자·연도의 논문임을 PDF 첫 쪽에서 확인했으며 F09의 근거로 사용하지 않았다.
- F06은 PyMuPDF로 JSTOR 서지표지(PDF 1쪽), 본문 첫 쪽(인쇄 p.319 / PDF 2쪽), 정의 문단(인쇄 p.320 / PDF 3쪽)을 직접 추출하여 대조했다. 원고 33·97행에 개별 인용 쪽수 표시는 없으나 07 목록의 기존 쪽수 기록을 함께 재확인했다.
- 33행의 기술특성 네 가지와 TAM 연결, 97행의 안전관리 실효성 다섯 하위요인 구성은 원고가 명시한 연구자 구성으로 읽었다. 해당 분류가 원전의 검증 결과라는 의미로 확대해서는 안 된다.
- 기존 서지 판정을 뒤집은 건은 0건이다. Davis의 배타적 표현 문제는 자료분류에 이미 경고되어 있고, F09의 전문 대조 미완료 역시 과거 기록과 같다. 이번 작업은 이를 실제 인용 줄에 대응시켰다.
- 조회는 2026-11-04 수행했으며, 직접 HTTP 요청 사이에는 3초 이상 간격을 두었다. 저장소 쓰기는 이 보고서 하나에 한정했고 원고·목록·README·PDF는 수정하지 않았다.
