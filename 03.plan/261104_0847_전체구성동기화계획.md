# MD·HWPX 전체 구성 동기화

- 사용자 요청: MD와 한글의 구성을 같게 유지한다. 수록 제외된 상세 분석·jamovi 원출력 부록 삭제는 확인된 사용자 승인에 따른다.
- 단일 원본: `01.docs/` 현행 MD. HWPX는 작업 시 `00. hwpx/`의 접두사 최신본을 확인하고 복사하여 수정한다. 원본은 덮어쓰지 않는다.
- 대조에서 확인한 범위: 제1장 흐름도, 제2장 옛 예산 제약성 절·항, 제5장 불필요한 절 제목, 초록·감사의 글·참고문헌, 설문 양식의 공통·전용부 구성, 표 4-3 참고 변수 행, 옛 상세 분석 및 jamovi 부록.
- 구현 담당은 현재 HWPX와 MD를 대조해 타깃 반영 코드를 준비한다. 사용자 직접 추가·수정분은 보존·역동기화하며, 확정 삭제된 옛 수록물을 무조건 복원하지 않는다.
- 메인만 HWPX 쓰기·한글 COM 재저장·PDF 출력을 수행한다. 문단·표 변경 캐시를 제거하고 기존 사용자 서식을 가능한 범위에서 보존한다.
- 최종 검증: 장절항·표·그림·부록의 번호·제목·순서·수록 일치, 이미지 일치, 목차 실제 인쇄 쪽수, 전 표 내용·배치, 빨간 마커, 원본 SHA256 불변.
- 지침 반영: `CLAUDE.md`는 짧은 포인터, `.claude/rules/hwpx-output-verification.md`는 구성 일치 완료 기준, `MEMORY.md`는 사용자 교정 기록을 추가했다.
