## 검증 결과 — 1회 수행

- 제1절은 4차 초안과 문자열 대조하여 승인된 연결 문장 1개 외에 차이가 없음을 확인했다.
- 제2절부터 제3절 끝까지는 표 1-2의 지정 셀 치환 외에 문자열이 동일하다. 표·그림·가설·표본·방법은 추가로 변경하지 않았다.
- 표 목차와 본문의 표 1-1 제목이 일치한다. 표 수치는 승인본 대조에 포함된다.
- 신규 관리번호 110~112는 각각 한 행이며 국내문헌 가나다순과 고용노동부 연도순을 확인했다. 113은 미등록·미인용이다. 맹인영 등의 출판 서지 47–63쪽과 공개 저자원고 표 8의 PDF 14쪽을 구분했다.
- 이준호 인용은 바뀐 서론에 남지 않아 ref39에서 제1장만 제외했다. 류정·박인선은 제1장 추가 인용을 반영했다.
- 시작 시 지정 수정 파일의 바이트 스냅샷을 임시 디렉토리에 보관하고 그 상태와 비교했다. 기존 미커밋 변경이나 git 기준과 혼동하지 않았다. 줄바꿈 형식을 보존했으며 git 쓰기는 수행하지 않았다.
- 보호 파일 1,120개(다른 원고·기존 초안·참고 자료·HWPX)의 경로별 SHA256은 전후 동일하다. 이 중 HWPX는 19개이며 신규 생성·삭제·수정 작업을 하지 않았다. 경로와 파일 해시로 구성한 검증 목록의 SHA256은 `f149763fa95748ead814e4fd90f0b1c26295b6bfe906d7766dfee49369aa518c`이다. 앱 코드는 접근·수정하지 않았다.
- 출처 존재·쪽수 검증과 교수님 작성요령 및 전체 원고 10개 전문 독해는 앞선 작업의 증거를 승계했다. 원문 재다운로드·웹조사·분석 재실행은 하지 않았다.

## 미반영·후속 확인

**HWPX에는 이번 내용을 반입하지 않았다.** 제29항에 제1절·표 1-1·표 목차·참고문헌 반입을 대기 상태로 기록했으며 기존 대기를 완료 처리하지 않았다.

최종 검토에서 제2장 제3절의 현장 작동성 정의 뒤에 있던 “(제1장 제1절)” 참조를 삭제하였다. 새 제1절에는 해당 용어의 명시적 정의가 없어 성립하지 않는 상호참조만 정리한 것으로, 정의 문장과 나머지 제2장 내용은 보존하였다. 해당 문장 1곳만 치환되었음을 바이트 비교로 확인하였다. 위 보호 파일 불변 검증은 이 최종 수정 직전 워커 작업 범위의 증거이며, 최종 변경 파일에는 `01.docs/02_이론적배경.md`가 추가된다.

제2장 내용 보완이나 초록·결론 재작성, 다른 표의 형식 정리는 수행하지 않았다. 이번에 추가한 세 문헌의 인용·표 목차 기계적 정합은 완료했다.
