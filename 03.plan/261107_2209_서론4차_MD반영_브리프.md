# 서론 4차 초안 MD 반영 브리프

사용자 승인: “응 md에 반영 해줘”. 검토된 4차 초안을 실제 MD에 반영한다. 원고 전체 독해와 출처 검증은 기존 작업 증거를 승계하고 반복하지 않는다. 저장소 지침과 교수님 논문작성요령을 준수한다.

## 구현 범위
- `03.plan/261107_2143_서론제1절_재구성4차초안.md`의 제1절 본문만 `01.docs/01_서론.md` 제1절로 반영한다. 검토 메모는 넣지 않는다. 마지막 문단의 연구 공백 문장 뒤에 승인된 연결 문장 “관련 선행연구는 제2장에서 고찰하였다.”를 추가한다.
- 제2절 연구목적과 제3절 범위·방법은 유지한다. 단 표 1-2의 제1장 방법 `재해 통계 검토`는 정책·재해 통계 및 CCTV·관제 선행연구 검토를 포괄하도록 최소 수정한다. 상단 작성 상태와 하단 메모 중 현행 제1절·표 1-1을 잘못 설명하는 부분을 정리한다. 과거 기록은 이력으로 구분한다.
- `01.docs/00_목차.md` 표 1-1 제목을 새 표 제목과 일치시킨다.
- `01.docs/07_참조번호목록.md`: 신규 인용 110,111,112를 서지와 대응 목록에 등록한다. 국내문헌 가나다순 유지. 113은 인용하지 않으므로 추가하지 않는다. 류정·박인선 ref32의 인용 장에 제1장 추가, ref39 이준호는 서론 다른 곳에 남는지 검색하여 인용 장 표시만 정합화. 과거 목록 수치 등 무관한 전면 정리는 하지 않는다.
- `CLAUDE.md` 세션 연속성 항목의 “미반영·채택 미완료”만 실제 MD 반영 완료 및 HWPX 대기 상태로 갱신하고 이번 보고서를 연결한다. 원고 사실 요약을 새로 만들지 않는다.
- `03.plan/261106_0114_hwpx반입대기_체크리스트.md`에 이번 제1절·표 목차·참고문헌 변경의 반입 대기를 추가한다. 기존 대기를 완료 처리하지 않는다.
- 현재 시각 Asia/Seoul 접두사로 `03.plan/`에 반영 보고서를 작성하고 README에 본 브리프와 보고서 링크를 추가한다.

## 제한·완료 증거
현재 사용자의 다른 미커밋 변경이 많으므로 시작 시 지정 파일 스냅샷을 잡아 자신의 변경만 비교한다. HWPX·다른 장·기존 초안·참고 PDF·앱 코드 수정 및 git 쓰기 금지. 출처 재다운로드 불필요. 제1절 승인본 일치(연결문장만 추가), 표 목차 일치, 3건 서지 등록 및 인용 정합, 제2·3절 본문 보존(표1-2만 예외), HWPX 불변을 한 번 검증하고 증거를 보고한다. 보고서에 수정 파일·핵심 diff·검증 결과·미반영 HWPX를 명시한다. 작업 완료 후 worker_done으로 보고.
