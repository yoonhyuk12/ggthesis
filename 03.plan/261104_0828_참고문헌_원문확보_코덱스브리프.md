## 저장 규칙

- 파일명: `02.reference/NN. 제목.pdf`. NN은 **71부터** 확보한 순서대로 부여한다(현재 70번까지 있음). 제목은 영문 원제의 앞부분(60자 이내)이면 충분하다.
- 받은 판본이 출판본이 아니면(프리프린트·저자 원고·OCR 스캔) 파일명 끝에 `(preprint)`·`(author manuscript)`처럼 표시하고 보고서 판본 비고란에 적는다.
- 저장 후 검증: `python -I` 로 pypdf(6.19 설치됨) 또는 pymupdf를 써서 **쪽수와 첫 쪽 텍스트**를 추출하고 저자·제목·연도가 위 서지와 일치하는지 대조한다. 콘솔 출력은 `PYTHONIOENCODING=utf-8`을 앞에 붙인다(cp949 UnicodeEncodeError 방지).
- SHA256을 기록한다(`Get-FileHash` 또는 `sha256sum`).
- 공개 도메인·OA가 아닌 단행본(B2·B3)은 파일을 저장하지 않는다.

## 탐색 도구 (웹 검색 도구가 없어도 되는 API)

- OpenAlex: `https://api.openalex.org/works/https://doi.org/<DOI>` → `best_oa_location.pdf_url`, `open_access.oa_url`
- Semantic Scholar: `https://api.semanticscholar.org/graph/v1/paper/DOI:<DOI>?fields=title,year,openAccessPdf`
- Crossref: `https://api.crossref.org/works/<DOI>` → `link[]` 중 `content-type: application/pdf`
- Unpaywall은 이메일 식별자를 요구하므로 쓰지 않는다. 개인 이메일을 어떤 요청에도 넣지 않는다.
- 내려받기는 `curl -L -A "Mozilla/5.0"` 또는 PowerShell `Invoke-WebRequest`.
