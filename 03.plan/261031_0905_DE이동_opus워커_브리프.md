> 시스템 개발의 효과와 관련된 도입 현장 전용부 D(시스템 특성 인식)·E(경보 피로도 완화 인식)의 설문 결과는 앞선 제3장 제4절 제5항에서 서술하였으며, 가설 검정에는 투입하지 않았다.

### 2-3. 제3절 제2항 두 문장 삭제

## 6. 표 번호 당김 — `04_연구설계및실증분석.md`와 `00_목차.md` 두 파일만

먼저 `grep -n "표 4-13" 01.docs/04_연구설계및실증분석.md 01.docs/00_목차.md`가 0건임을 확인한다(2-8·5에서 지웠으므로). 그 다음 아래 스크립트처럼 **14부터 27까지 오름차순**으로 `표 4-N` → `표 4-(N-1)` 치환한다. 뒤에 숫자가 이어지지 않는 경우만 바꾼다.

```python
import re, io
for p in ["01.docs/04_연구설계및실증분석.md", "01.docs/00_목차.md"]:
    raw = io.open(p, "rb").read()
    nl = "\r\n" if b"\r\n" in raw else "\n"
    s = raw.decode("utf-8")
    for n in range(14, 28):
        s = re.sub(r"표 4-%d(?!\d)" % n, "표 4-%d" % (n - 1), s)
    io.open(p, "wb").write(s.encode("utf-8"))
```

5장·1장·2장·3장은 4장 표를 <표 4-6>만 참조하므로 건드리지 않는다.
