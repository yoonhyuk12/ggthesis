# 참고문헌 팩트체크 W05 (2026-11-04)

## 요약

문헌 2건 / 서지: 일치 2·불일치 0·외부 확인 불가 0 / 입력 인용 줄 15건, 주장별 분할 18행: 뒷받침 14·부분 3·불일치 1·확인 불가 0 / 과거 서지 확정 기록과 달라진 점 0건.

- 제3장 104행은 박종학이 권장한 임계값 0.4∼0.5를 기존 연구의 일반적 운영 관행으로 확대하고, 그 값 때문에 미탐이 증가했다고 귀속한다. 원문은 이 범위를 정밀도·재현율 균형의 권장 범위로 제시한다.
- 박종학의 F1=0.91은 초록에 실제로 있으나 본문 p.51은 최대 F1=0.92(confidence 0.444)라고 한다. 인용 오류와 원문 내부 불일치를 구분해야 한다.
- 류정·박인선의 13개 현장·재해율 비교는 확인되나, 원문 Table 8의 일반 현장 근로자 수·재해자 수로 계산하면 제시 재해율 0.461%가 재현되지 않는다. 현 원고는 그 수치를 직접 인용하지 않으며, 사고예방의 가능성·간접 근거라는 한정을 유지할 필요가 있다.

검토 방법: 입력 JSON의 W05 두 문헌과 모든 인용 줄의 앞뒤 문맥, 표 제목·열 머리를 읽고 PyMuPDF로 PDF를 추출하였다. 외부 조회는 KCI와 디지털집현전을 사용했으며 요청 간 3초 이상 간격을 두었다. `memo=false`인 제2장 207·209행은 실제로는 206행의 ‘집필 메모 — 본문 아님’ 아래에 있다. 입력 누락 방지를 위해 표에는 포함하되 해당 문헌의 저자·연도만 판정하고 논문 주장으로 세지 않았다. 다른 문헌에 귀속된 같은 줄의 주장은 W05 판정 범위에서 제외했다.

## 장 간 불일치

저자·연도 및 반복 수치의 장 간 불일치는 없음. 제2장 47·76행과 제3장 46행은 동일한 박종학 초록의 성능 수치를 일관되게 사용한다. 다만 제3장 104행에서 같은 연구를 임계값의 문제점 근거로 해석한 부분은 원문 권장 범위와 맞지 않는다. K09는 제2·4·5장 모두 사고예방 가능성 또는 간접 근거로 사용한다.

### 원문 자체의 수치·설계 주의사항

1. K09 Table 8(인쇄 p.132 / PDF 8쪽): 일반 현장 근로자 5,706,224명, 사망자 171명, 부상자 2,485명, 재해율 0.461%를 제시한다. 제시 숫자로 계산한 `(171+2485)/5706224×100`은 **0.046545666626476634%**로 0.461%와 다르다. 본문 현장 수는 150,059개소인데 같은 표는 150,159개소이다. 123개 지원 현장 재해율 0.357%와 13개 연구 현장 0%를 혼동해서도 안 된다. 외부 통계의 정확한 분모·산식을 다시 확인하지 않고 원문 값을 확정 통계로 재인용하면 위험하다. 현재 W05 인용 줄은 이 0.461%를 직접 전사하지 않아 인용 수치 불일치 건수로 세지 않았다.
2. K10 초록(인쇄 p.x / PDF 14쪽, 영문 인쇄 p.104 / PDF 119쪽)의 F1=0.91과 본문(인쇄 p.51 / PDF 66쪽)의 “YOLOv8n의F1 Score는confidence 0.444 지점에서0.92로최대치를기록하였다.”가 다르다. 서로 다른 운용점일 가능성을 원문이 충분히 설명하지 않으므로 0.91을 임의로 0.92로 고치지 말고 ‘초록 보고값’으로 출처를 명시하거나 그래프·평가 조건을 추가 확인할 필요가 있다.
3. K10 초록은 YOLOv8n을 ‘가장 우수’로 서술하지만 Table 4-7(인쇄 p.45 / PDF 60쪽) 10epoch mAP50은 YOLOv5n 0.91698, v8n 0.90587, v11n 0.91434이다. 현 원고는 ‘가장 우수’까지 옮기지 않아 수치 귀속은 유지 가능하다. 실제 현장 실시간 성능과 이미지 데이터셋 평가의 적용 가능성도 구분해야 한다.

## 확인 못 한 것과 이유

- K10의 정확한 학위수여 일자는 표지·제출면·인준면과 조회한 공식 레코드에 없다. 2024는 학년도, 2025-06은 제출·인준월, 2025-08은 외부 레코드 날짜로 구분하였다. 인용연도 2025는 확인된다.
- K09의 일반 현장 재해율 산식·분모 오류를 해결할 외부 원통계 재산출은 이번 두 문헌 인용 대조 범위를 넘는다. 보유 PDF 표의 불일치만 확인했으며 수정 수치를 확정하지 않았다.
- K10 초록 F1=0.91과 본문 최대 F1=0.92의 평가 조건 차이는 확인하지 못했다. 원고가 초록을 정확히 옮겼다는 판정과 원문 지표의 재현 가능성은 별개다.
- 입력 JSON의 memo 분류 오류 2줄(제2장 207·209행)을 보고했으며 입력 파일은 수정하지 않았다. 15줄 전부 표에 포함했고 복수 주장 3줄을 나누어 18행으로 작성했다.
