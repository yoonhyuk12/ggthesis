## 사용자 사실 확인 질문

아래는 문헌만으로 답할 수 없는 실제 연구·운용 기록이다. 이미 원고에 미실행으로 명시된 연구는 실행한 것으로 바꾸지 않았다.

1. **설문 날짜와 예비조사:** 10월 12~13일 응답도 10월 14일 확정본과 동일 문항인가? 중간 수정 또는 재응답이 있었는가? 예비조사 참여자 수·시기·검토 방식과 최종 73명 포함 여부는 무엇인가? 구글폼 변경 기록에는 10월 12일 편집이 있지만 이 사실만으로 최종본 사용 여부를 확정할 수 없다.
2. **도입 분류·3개월:** 34개 도입 현장별 설치일, 정상운용 기간, 가동 중단, 미충족 제외 건수의 기록이 있는가? 3개월 기준은 언제 정했는가? 응답자의 최초 선택과 도입 명부가 달랐을 때 실제 어떤 대조·정정 절차를 적용했는가? 현재 본문과 부록은 자기보고 최초 선택 기준으로 읽히므로 명부가 분류를 대체했다고 임의 확정하지 않았다.
3. **이미지 누락:** 원본 1,095건 중 이미지가 연결되지 않은 217건의 원인은 캡처 실패·내보내기 누락·삭제 중 무엇인가? 별도 원영상이나 보관본이 있는가? 제외 건수와 파일상 사유는 확인했으므로 다시 산정할 필요는 없다.
4. **FAR 노출시간:** 196.8시간의 시작·종료·중단 제외 기준과 서버시간/카메라별 노출시간 중 어떤 분모인지 확인할 기록이 있는가? 원본 시각 범위는 약 197.309시간, 다른 파일 범위는 약 196.718시간으로 해당 값을 직접 재현하지 못했다.
5. **접근 경고:** 실제 사용한 거리·지속시간 기준과 사건별 영상·지속시간 자료는 무엇인가?
6. **운영점:** 허용할 위험 누락 수준·최소 재현율을 정한 담당자와 기준·운영 기록이 있는가? 문헌의 임의 수치로 운영 결정을 대신할 수 없다.
7. **성능 실측:** 45/95밀리초 측정 당시 CPU·GPU·RAM·모델·해상도·동시 채널·반복 수·타임스탬프가 있는가? 종단 간 지연 및 SEND/BLOCK, RAG 유무, 정상/장애 경로별 측정 기록은 무엇인가? 기술분석서의 지원 아키텍처만으로 측정 조건을 확정하지 않았다.
8. **비용:** PC 견적일·사양·부가세, 월 API 모델·호출량·단가·추가 호출, 교정 인건비는 무엇인가? 비교 제품의 채널·중복 구성·라이선스 기간과 양측 포함 항목은 동일한가?
9. **독립 평정:** 개발자 외 독립 평가자의 실제 라벨 검토 기록이 별도로 있는가? 없다면 현행 미실행·한계 서술을 유지한다.

윤영석 학위수여연도는 개인 연구 사실 질문과 별개의 서지 접근 문제다. 공식 도서관 링크나 학위수여 정보가 확보되면 제출연도와 구분하여 확정할 수 있다. EN 정본과 통제변수 문헌 역시 외부 근거 확보 과제로 남기며 사용자 경험만으로 확정하지 않는다.
