## 파일명 규칙

```
YYMMDD_HHMM_플랜명.md
```

- 날짜와 시각은 **작성 시점의 Asia/Seoul 현지시각**을 쓴다.
- 시각을 알 수 없는 과거 문서는 `0000`으로 둔다. 실제 작성 시각이 아니라 미상이라는 뜻이다.
- `README.md`는 이 색인 파일이므로 규칙에서 제외한다.

## 사용 흐름

1. 계획 문서는 착수 전에 작성하고 사용자 승인을 받는다 (`.claude/rules/plan-first.md`).
2. 서브에이전트에 위임할 때는 브리프를 이 폴더에 남긴다. 다음 세션이 위임 범위와 금지사항을 다시 만들지 않아도 되게 한다.
3. 완료된 작업은 본 README의 상태 열에 ✅로 표시한다.
