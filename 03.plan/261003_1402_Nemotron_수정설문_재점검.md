1. `report.html`: 한국어 단일 파일. 앞부분에 이번에 새로 점검한 범위, 핵심 발견, 기존 점검에서 이어지는 사항을 구분한다. 스크롤하며 읽을 수 있는 간결한 표로 6프로필×3문항=18건의 가상 문항 해석/응답 가능 여부/필요 정보/근거를 보여준다. 인물별 해석은 직무와 주어진 정보에만 근거하고 성별·나이·성격으로 성향을 단정하지 않는다. 허위 현장 경력·비용·Likert 점수를 채우지 않는다. 발화는 실제 인터뷰 인용이 아니라 LLM이 작성한 가상 해석임을 명시한다.
2. `review.json` 및 엑셀 열기 가능한 UTF-8 BOM `review.csv`: 위 18건과 원본 UUID/문항/상태/근거. 현재 A-3·A-4·A-6의 문구와 안내·선택지를 정확히 보존한다. 필요한 경우 source_age와 hypothetical_test_age를 명확히 분리한다.

4. `manifest.json`: 입력 SHA256, 출처·라이선스·이전 점검 링크, 실행 시각, 실행 주체(단일 Codex 워커), 재사용/신규 점검 구분, 알려진 모델 정보만 기록(temperature/seed 미공개시 null), LLM 점검/대표성 없음/통계 추정 없음 명시. NVIDIA 모델을 실행했다고 쓰지 않는다.
5. `validation.json`: 의미 있는 정합 검증을 한 번 실시하고 증거를 남긴다. 필요하면 짧은 재현용 build/validate Python 스크립트도 같은 폴더에 둔다.

### 판단 기준
