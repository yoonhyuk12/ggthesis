# 방어적 서술 점검 — 초록·제1·2·5장

- 요청: 그림 1-1의 인과효과 면책 문구 삭제와 함께 원고 전체의 선제 방어적 표현 조사.
- 범위: `01.docs/00_목차.md`의 국문·영문초록, `01_서론.md`, `02_이론적배경.md`, `05_논의및결론.md`의 본문. 집필 메모·목차 안내는 제외.
- 상태: 조사만 수행. 원고 수정 없음.
- 집계: 수정 판단이 필요한 **15개 문장군**. 동일 문단 또는 같은 논지를 반복하는 인접 문단·표 셀을 묶은 검토 단위이며 부정어 출현 횟수가 아니다.
- 분류: A 삭제 가능한 중복·선제 방어 3개 / B 수행 내용 중심 재서술 8개 / C 실제 방법·한계 유지 및 위치·분량 정리 4개.

제2장에 가장 많은 반복이 있다. 선행연구마다 “직접 검증하지 않았다”, “동일 척도가 아니다”를 덧붙여, 문헌을 연구 근거로 연결하기보다 근거 부족을 해명하는 인상을 준다. 문헌과 본 연구의 차이를 한 번 정의하고 각 문단에서는 실제로 참고한 개념을 설명하는 편이 낫다.

## 삭제 대상으로 보지 않은 표현

- 초록·제5장의 “유의하지 않았다”, “유의한 차이가 나타나지 않았다”: 실제 분석 결과.
- 실제 위험 44건 중 5건 차단: 안전 성능의 핵심 결과.
- 제1장 재해 통계 분모의 차이: 수치 비교의 정확성에 필요.
- 제2장 선행연구 지표·분모·비교 모델 구분: 인용 결과를 왜곡하지 않는 범위에서 간결화해야 한다.

## 편집 원칙

각 문단에서 미수행 항목을 열거하기보다 수행한 대상·방법·결과를 정확히 서술한다. 실제 한계는 적절한 위치에 한 번 정리한다. 수행하지 않은 검증을 수행한 것처럼 바꾸거나 실제 손실·비유의 결과를 감추지 않는다.
