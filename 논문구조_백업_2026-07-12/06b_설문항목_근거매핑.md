###### 06b. 설문 문항 근거 매핑

> 본 문서는 `06_설문항목.md`의 리커트 44문항(B-1~B-4, C, D, E)에 대해 `referernce/` 디렉토리 PDF의 측정 근거 단락을 페이지·요약으로 매핑한 자료이다.
> 페이지 표기는 PDF 본문 페이지 번호 기준(국문초록은 i, ii…, 본문은 1쪽부터)이며, 본문 위치를 확정하기 어려운 경우 "p.X 추정 (장·절명)"으로 표기하였다.
> 원문 직접 인용은 지양하고 한국어 1~2줄 요약으로 통일.
> **활용:** 「3장 4절 측정도구 구성표(<표 3-X>)」 작성, 심사위원 질의응답 근거 자료, 인용 페이지 추적용.

- 본 표는 「3장 4절 측정도구 구성표(<표 3-X>)」 작성 시 동일 인용 가능.

- 페이지 번호는 PDF 본문 페이지 기준이며 PDF 뷰어 페이지와 다를 수 있으므로 인용 시 재확인 권장.
- "p.X 추정"으로 표기된 항목은 본문 위치를 좁히지 못한 항목 — 본문 인용 시 직접 확인 필요.
