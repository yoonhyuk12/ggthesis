## 적용 계약

- 모든 section은 `Contents/section2.xml`이며 `table_idx`는 base_tables에 기록된 구역 내 인덱스다. 중첩 표도 포함되어 있으며 전체 JSON 배열의 전역 위치로 재해석하지 않는다.
- `cell_replace.old`는 base_paras의 실제 문단 문자열과 정확히 일치한다. 표 교체 인덱스와 셀 치환 인덱스는 중복하지 않는다.
- `remove_table_indices`는 첫 대표 표를 제외한 나머지 기존 물리표다. `all_old_table_indices`는 교체에 관여하는 기존 물리표 전체다. 이를 단순 삭제 후 첫 자리로 몰아넣는 방식으로 적용하지 말고 panels의 개별 배치 정보를 따른다.
- 각 패널의 `md_block_idx`, `after_new_md_block_idx`, `after_new_md_text`는 new_blocks 및 B의 assembly_order와 교차 배치할 때 쓰는 위치 참조다. 설명문 본문은 B 소유이며 이 문자열을 별도로 다시 출력하지 않는다.
- 기존 물리표가 있는 패널은 `table_idx`·`old_anchor_idx` 위치에 넣는다. 새 패널은 아래 경계 안에서 B의 해당 새 설명문 바로 뒤에 넣는다.
- `preserve_total_width`는 기존 대표 표 전체 폭이다. width_weights는 실제 글꼴을 측정하지 않은 제안이며 메인이 기존 전체 폭을 보존해 정수 열폭으로 확정해야 한다. 긴 식별·설명열을 수치열보다 넓게 제안했다.

## 직접 수정분과 내용 처리

기존 HWPX의 결과 빈칸 492개를 표별 실제 문단 인덱스와 함께 user_edits에 기록했다. 코디네이터의 질의 답변에 따라 기존 및 신설 통계 결과칸 모두 빈칸 양식을 유지한다. 이는 MD 수치의 수정이 아니라 기존 결과 양식 보존 예외다. 5장 표 뒤 결과 대기 본문이 있는 경우 그 MD 블록 인덱스를 기록했고, 없는 경우 짧은 빨간 DATA PENDING 주석을 panel.note로 제안한다. 실질적인 확정 필요·CITE_TODO는 이 빈칸 규칙의 삭제 대상이 아니다.

비결과 셀의 실제 수치와 행·열 이름은 새 MD 그대로 반영한다. 표3-6의 0.950·+0.717·0.979·+0.929와 표3-7의 TP·FP·TN·FN 추가는 MD 문자열만 반영했으며 원자료를 재계산하지 않았다. 표3-6 제목은 idx606, 표본 설명은 idx607의 기존 두 문단 형태를 유지한다. 표3-7 및 5장 병합 제목은 각 교체 그룹 caption에 들어 있다. 표 밖 캡션은 B 소유다.

표3-4 혼동행렬 셀의 대시 대신 문단 분리한 편집, 표4-3의 D블록 확정 마커를 이미 지운 편집, 표5-1의 발주청·공사금액 라벨 축약은 보존한다. 부록1의 B~E 문항 격자는 MD 내용 변화가 없으며 도입·미도입의 실제 복수 물리표와 12열 병합 구조를 보존한다. 별도 인계된 설문 안내 idx2101·2102·2105·2448·2451은 셀 치환에 포함했다.

## 검증 증거와 남은 작업

`C_build.py` 실행 결과는 `C_validation.json`에 저장했다. 실제 old 문자열 전수 일치, 셀 문단 존재, 중복 치환 없음, 교체 표와 셀 치환의 충돌 없음, 15패널의 모든 행·열 수 일치, 표번호 형식, 새 MD 표 전체 coverage, 새 MD 셀과 제안 패널의 일치(승인된 빈칸 예외만 적용)를 assert로 확인했다. old_blocks의 일부 표가 한 행씩 table 블록으로 분리되어 있어 연속 블록을 결합하고 Markdown 구분행만 제외한 뒤 비교했다.

원본 HWPX·COM·MCP/rhwp·원고 MD·원자료·Git은 쓰지 않았고 원본 HWPX도 열지 않았다. 생성 파일은 지정 스크래치의 tables_C.json, report_C.md, C_tables.py, C_build.py, C_validation.json뿐이다. 실제 HWPX 반영, B 본문과 패널 교차 조립, 글꼴 측정과 열폭 확정, 한글 재조판·PDF 배치 검증은 메인 담당으로 남는다.
