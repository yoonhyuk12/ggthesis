### 목차 리더점·탭 구조 (s1 p7 원본 XML)

```xml
<hp:p id="2147483648" paraPrIDRef="25" styleIDRef="0" pageBreak="0" columnBreak="0" merged="0">
  <hp:run charPrIDRef="116">
    <hp:t>제 1 장  서  론<hp:tab width="27252" leader="3" type="2" />1</hp:t>
  </hp:run>
  ...
</hp:p>
```

- 리더는 `hp:t` **안의 인라인 `<hp:tab width=… leader="3" type="2"/>`**로 구현되고 바로 뒤에 쪽번호 텍스트가 온다. type=2(오른쪽 탭), leader=3(파선 리더).
- paraPr25의 tabPr 3: tabItem pos=39684 RIGHT leader=DASH(HwpUnitChar 케이스; default 케이스는 pos=79368). 표·그림목차용 paraPr52의 tabPr 4: pos=36852 RIGHT DASH, autoTabRight=1.
- 조립기는 항목 텍스트 + 인라인 탭 + 쪽번호 문자열 구조를 그대로 복제하면 된다(width는 한글이 재계산).

- 표는 **문단의 run 안에 treatAsChar=1(글자처럼 취급)로 인라인 배치**된다. p223의 run 구성: `[tbl, t]` — 표 뒤에 빈 텍스트가 따른다.
- `<hp:caption>` 요소는 쓰지 않는다. 캡션은 **표 첫 행(r0)을 colSpan=4로 병합**하고 borderFill 13(아래만 실선)을 줘서 만든다. 캡션 아래 실선이 표 상단 굵은선 역할.

### 그리드·셀 구조

- 열폭 [7380, 3135, 9644, 18983], 합 = 39142 = 표 폭. **모든 행의 cellSz.width 합이 표 폭과 정확히 일치**한다(rowSpan 중인 셀이 있는 행은 그 셀 폭을 제외한 합: r3~r5는 31762 = 39142 − 7380).
- 병합: r0 캡션 행 colSpan=4·rowSpan=1. r2 "독립변수(X)" 셀은 rowSpan=4(colAddr=0, rowAddr=2). cellAddr은 (colAddr, rowAddr) 0-기준.
- cellSz.height는 참고값이다(합 31182 ≠ sz.height 27699 — 한글이 열 때 재계산). **width는 반드시 그리드 합치, height는 근사여도 무방.**
- 셀별 cellMargin은 전 셀 left=510 right=510 top=141 bottom=141(inMargin과 동일).
- 셀 내부 문단: 일반 셀 paraPr=75(가운데·160%)+charPr=7(10pt), 캡션 행 paraPr=11+charPr=58, 변수코드 헤더 paraPr=76, 개념 셀 charPr=89/92.

## 7. 빈 줄·쪽 나눔 관행

- **쪽 나눔은 `hp:p`의 `pageBreak="1"` 속성**으로 한다. paraPr의 breakSetting.pageBreakBefore는 어디에도 켜져 있지 않다.
  - 실측 위치: s0 p1(속표지), s1 p82·p85·p110(전면부 블록 시작), s2 p11·p16(절), p45·p61·p74(항), p214·p272(장), p300(참고문헌), p317(부록), 부록 설문 파트 구분(p323, p326, p328, p333, p336, p339).
  - 단, 제1·2·5장 제목엔 pageBreak가 없다(직전 내용이 쪽 끝에 오는 우연 배치에 의존). 조립기는 **장 제목마다 pageBreak="1"을 명시**하는 편이 안전하다.
- **빈 줄 리듬**: 장 제목 → 빈 문단 1개 → 절 제목 → 빈 문단 1개 → (항 제목 → 빈 문단 1개 →) 본문. 장 끝에도 빈 문단 1개. 빈 문단은 본문과 같은 paraPr51 + charPr61(또는 41·67 등 다음 제목의 charPr)로 되어 있다.
- 열 나눔(columnBreak)은 모두 0. 섹션 나눔은 파일 단위(section0/1/2)로만 존재.

## 8. 조립 시 주의점 정리

1. **스타일 불일치가 원본에 이미 존재한다.** 장 제목 5곳의 (style, paraPr, charPr)가 4가지 조합으로 갈라져 있고, 3장 제목 paraPr66은 줄간격 70%로 명백한 사용자 실수다. 조립기는 style_map.json의 정본 조합(h1: 1/57/63, h2: 0/51/67, h3: 0/51/41, body: 0/51/61)으로 통일 생성하는 것을 권장.
2. **목차 장 항목의 charPr 116은 빨강**이다. 최종본 목차를 생성할 땐 charPr 13(흑)으로 바꿔야 한다.
3. **표 폭 그리드 검증 필수**: 행별 cellSz.width 합 = tbl sz.width. 높이는 근사 허용.
4. **표 좌우 개방형 테두리**: 가장자리 셀 borderFill 45/46, 내부 6, 캡션 행 13.
5. **본문 들여쓰기는 전각공백**: paraPr intent가 0이므로 문단 첫머리에 "  "(전각 2칸)를 텍스트로 넣는 관행을 따라야 모양이 같다.
