- 기준 파일: `toc2_saved.hwpx`(zipfile+lxml로 읽기만 함). SHA256은 `back_layout_plan.json`의 `source_sha256`에 있다.
- 생성기: `back_layout_plan_gen.py`. 실행: `PYTHONIOENCODING=utf-8 python back_layout_plan_gen.py`. 결과는 **`validation.ok = true`, problems 0건**이다.

- 범위는 QA_back의 높음·중간 항목뿐이다. <표 5-1>(26)은 현재 `[4043, 9299, 4300×6]`을 유지하고, 43·50의 폭 38402도 그대로 둔다. 낮음 항목 18·19·20·21·41은 제외했다. header.xml은 바꾸지 않는다(`header_changes: []`).

**실행 방법**
- `hp:tbl/hp:sz@width`를 `total_width`로 바꾼다. 전폭 표는 39142를 그대로 두고, 44·51만 37102로 줄인다.
- 각 셀의 `hp:cellSz@width`는 `cells[].new_width`로 바꾼다. 이 값은 `sum(widths[col:col+colSpan])`이다.
- 높이·병합·주소는 바꾸지 않는다.

**36·39의 셀 여백**
- 표 안의 모든 셀에 `hp:tc@hasMargin="1"`, `hp:cellMargin@left="283"`, `@right="283"`을 설정한다. top·bottom 값은 지금 값을 유지한다(`keep_top_bottom`).
- 표 전체 기본 여백인 `hp:inMargin`은 바꾸지 않는다.
- 이렇게 하면 수치 열의 안쪽 폭이 3034가 된다. 실측으로는 3023 이상이면 `실험전`이 한 줄에 들어간다.

**중첩 표 44·51**
- 가용 폭 = 부모 폭 38402 − 부모 셀 좌우 여백 510×2 − 안쪽 표 바깥 여백 140×2 = 37102다(`nested.available`).
- 바꾸는 곳은 `hp:tbl/hp:sz@width`와 `hp:tc/hp:cellSz@width` 두 곳이다. 부모 표 43·50은 건드리지 않는다.

**사전·사후 검증** (`tables[].precheck`)
- `old_widths`는 현재 값과 정확히 같은지 생성기에서 대조했다. 이 값이 다르면 그 항목은 실행하지 않는다.
- `text_sha256`(표 텍스트)과 `runs_sha256`(run별 charPrIDRef+텍스트 순서)은 수정 후에도 같아야 한다. 한글 재저장 후에는 charPr ID가 바뀔 수 있으므로, 그때는 텍스트 해시와 `marker_count_실험전`으로 판정한다.
- 병합 격자는 모든 대상 표에서 점유가 정확히 1이다. 범위 초과도 없고, 이전 셀 폭은 이전 열폭 합과 일치한다.

**줄 배치 캐시 제거**
- `tables[].linesegarray_clear_paragraph_idx`(해당 표의 셀 문단)와 `anchor_paragraph_idx` 문단의 `linesegarray`를 제거한다.

- **paraPr를 복제할 필요가 없다.** 55·56은 id와 lineSpacing 값을 빼면 52(도입 표지 본문 서식)와 XML이 같다. 57과 54의 관계도 같다. 정렬·여백·단어 나눔·borderFill이 모두 일치한다. 따라서 기존 ID를 재사용하는 것만으로 줄간격이 190/180%로 줄어들고, 다른 서식은 바뀌지 않는다.
- 문단은 위치로 대응시켰다. 표 42와 49의 1행은 문단 수가 9개로 같고, 같은 위치 문단끼리 텍스트가 모두 일치한다. 42 쪽 대응 문단 번호는 `counterpart_in_table42_idx`에 있다.
- 사전 확인: `precheck.old_text`, `precheck.runs`(charPrIDRef+텍스트), `styleIDRef=0`이 현재 값과 같아야 한다. 텍스트와 run은 바꾸지 않고 `paraPrIDRef`만 바꾼다.
- 캐시 제거 대상: 2514~2522 문단과 표지 앵커 문단(`paragraph_styles_linesegarray_clear_idx`).
- 표지 0행(제목 3줄, paraPr 33·41·34)과 표 42는 바꾸지 않는다.
