# QA_front — reflowed.pdf 물리 1~75쪽 시각 QA (읽기 전용)

- 대상: `reflowed.pdf`(150쪽) 물리 1~75쪽. 쪽 번호는 모두 **PDF 물리 쪽**이며, 괄호 안은 인쇄 쪽수다.
- 방법: `visual/p*.png`(744×1052)는 판독용으로 작아서 같은 PDF를 130dpi로 다시 렌더링해(스크래치) 표 페이지를 1쪽씩 확인했다. 경계가 애매한 곳은 300dpi 크롭과 PyMuPDF 좌표(괘선 y·글자 bbox)로 판정했다. 1~75쪽 콘택트 시트 3장으로 먼저 분류했다.
- 재현: `QA_front_measure.py`(꼬리말 근접·앞쪽 여백 대비 표 높이), `QA_front_crops.py`(증거 크롭 `QA_front_*.png` 12장 생성). HWPX·MD·COM·원본 PDF는 건드리지 않았다. HWPX MCP는 쓰지 않았고, section0·1 표 식별만 `reflowed.hwpx`를 zipfile로 읽기 전용 확인했다.

### C. 전 표 공통(낮음)

- **C1 셀 상하 안쪽 여백이 사실상 0이다.** 다줄 셀의 첫 줄 상단이 윗 괘선과 같은 y다(예: 51쪽 `ONVIF` 166.3pt, 괘선 166.4pt). 줄 간격이 좁은 셀은 글자가 괘선에 닿는다. 잘림은 아니다. 여백을 일괄로 늘리면 쪽 이동이 연쇄되므로 B항 열폭 조정을 먼저 하고, 필요할 때만 표별로 적용할 것을 권한다.
- **C2 표 직후 문단이 하단 괘선에 붙는다.** 표 2-2(25쪽) 뒤 `4. 전달:`, 2-6(39쪽) 뒤 `주:`, 2-7(41쪽) 뒤 본문, 3-1(48쪽)·3-4(65쪽) 뒤 본문이 해당한다. 반면 <표 3-7>(68쪽)은 제목과 표 사이 간격이 약 20pt로 다른 표보다 넓어 일관성이 없다.

## 4. 추출 이상과 실제 결함의 구분

- 검증 JSON `missing_marker_multiplicity`의 `[확정 필요: …]` 3건(expected 1 / actual 0)은 **쪽 경계에서 마커가 둘로 나뉘고 사이에 꼬리말 `- n -`이 끼어든 추출 이상**이다. 실제 PDF에는 3건 모두 있고 빨간색도 쪽을 넘어 이어진다.
  - `최소운용기간…포함기준]`: 15쪽 끝 `[확`(R)에서 16쪽 첫 줄 `…현장포함기준]`(R)으로 이어진다.
  - `비교 구성의 중복…포함 범위]`: 71쪽 끝 `[확`(R)에서 72쪽 `복여부·채널…`(R)로 이어진다.
  - `전문가 수…CVR 채택 기준]`: 85쪽 끝에서 86쪽 `에 따른 CVR 채택기준]`(R)으로 이어진다. 85~86쪽은 범위 밖이지만 같은 원인이라 함께 확인했다.
  - 기대 문자열의 가운뎃점은 `ㆍ`(U+318D)이고 PDF 추출은 `·`로 나온다. 정규화 차이도 오탐에 영향을 줄 수 있다.
- `실험전` 588/566(22 부족): 1~75쪽의 `실험전` 출현은 0이다. 차이는 모두 76쪽 이후(제5장 결과표)이므로 이 QA 범위 밖이다.
- 그 밖에 텍스트 추출 순서가 셀 순서와 다르게 섞이는 것은 추출 특성일 뿐이다. 이미지 기준 셀 잘림은 1~75쪽에 없다.

## 5. 범위 밖 관찰(참고만, 조치 불요 판단은 메인)

- 12쪽 `논문 개요`는 제목만 있고 본문이 비어 있다. 11쪽 `감사의 글`은 빨간 템플릿 문장 1줄뿐이다(마커 접두사가 아닌 빨강).
- 61쪽 `운영 안정성과…`, 66쪽 `조건부 필터 성능은…`, 71쪽 `현재 제시한 값은…` 문단은 다른 문단과 달리 첫 줄 들여쓰기가 없다.
