## 사용한 방법

1. **hwpx 재추출** — `qa/dump_hwpx.py`. `zipfile`로 열어 `Contents/section*.xml`을 `ElementTree`로 파싱하고, `hp:p`를 문서 순서대로 순회하여 문단 텍스트(`hp:run` 직속, 중첩 `hp:tbl`·`hp:ctrl` 제외)와 표를 뽑았다. 표는 `hp:cellSpan`의 `colSpan`/`rowSpan`을 반영해 격자로 펼쳐 행렬화했다. 결과: 문단 638, 표 62, 중첩표 0.
2. **MD 재파싱** — `qa/parse_md.py`. 헤딩(`#`~`####`), 문단, 표(구분행 제외), 그리고 제외 대상(blockquote·코드펜스·수평선·단독 HTML 태그·"본문 아님"/"내부 관리용" h2 섹션 전체)을 독립적으로 분류했다.
3. **선형 전수 대조** — `qa/compare.py`. 양쪽을 (제목/문단/표셀) 선형열로 펼치고, 마크다운 인라인 마크업 제거·공백 정규화 후 `difflib.SequenceMatcher`로 **순서를 포함해** 대조했다. 삽입·삭제·치환 블록이 하나도 없으면 누락뿐 아니라 **hwpx 측 추가 텍스트도 없음**이 동시에 증명된다.
4. **항목별 검사** — `qa/checks.py`, `qa/checks2.py`. 제목 1:1, 표 구조, 제외 규칙, 미확정 표시, 구판 오염, 내주 표기를 개별 검사했다.

**제1~3장 범위 확정:** `section2.xml`의 첫 문단(`제1장 서론`)부터 `제4장 연구설계` 문단 직전까지. `section1.xml`은 전면부(목차), `section0.xml`은 표지로 본 감사 범위 밖이다.

산출 파일: `dump_hwpx.py`, `parse_md.py`, `compare.py`, `checks.py`, `checks2.py`, `hwpx_dump.json`, `md_0{1,2,3}_*.json`, `diff_ch1-3.json`(빈 배열), `checks_out.md`, `checks2_out.md`.

재현 명령(작업 디렉토리 `tools/hwpx_transfer/qa/`).

```
python dump_hwpx.py "../../../논문구조/260725_경기공학_건축안전_윤혁_논문작성_작성본.hwpx" hwpx_dump.json
python parse_md.py ../../../논문구조/01_서론.md md_01_서론.json      # 02·03도 동일
```
