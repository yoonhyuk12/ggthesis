# G3 — 본문 인용 ↔ 참고문헌 목록 대조 (읽기 전용)

공통 규칙: `_COMMON_워커공통규칙.md` 를 먼저 읽는다. **보고서 1개만** 만든다. 원고를 고치지 않는다. 서지를 검색·추정해 채우지 않는다.

## 대상
- 본문: `04. 미소논문/01.docs/01.서론.md` ~ `06.결론.md`, `07.부록.md`, `07-2. 설문근거.md`, `00.목차.md`(국문초록 절)
- 목록: `04. 미소논문/01.docs/08.참고문헌.md` (`[01]`~ 번호 항목. `## 마. 추가 확보 필요 문헌 (CiteTodo — 잔여)` 절은 "미확보"로 따로 취급)

## 할 일
1. 본문의 내주 인용을 전부 추출: `(저자, 연도)`, `(저자 외, 연도)`, `저자(연도)`, `(저자 & 저자, 연도)`, `(저자 et al., 연도)`, 연도 뒤 `a/b`, 세미콜론으로 이어진 다중 인용, `[CITE_TODO: …]`. 파일·행 번호·원문 포함. 같은 (저자, 연도)는 한 항목으로 묶고 출현 횟수를 센다.
2. 각 인용을 `08.참고문헌.md`의 항목과 대조(저자 성·연도 일치): **매칭됨 / 목록에 없음 / CiteTodo 절에만 있음(미확보) / 연도만 다름(예: 2025 vs 2026) / 저자 표기만 다름(예: "안전보건공단" vs "한국산업안전보건공단")** 으로 분류.
3. 역방향: 목록에는 있으나 본문 어디에서도 인용되지 않은 항목 목록(번호·저자·연도).
4. `[CITE_TODO: …]` 전수 목록(파일·행·요약).
5. 인용 표기 형식 이탈: 교수님 요령은 내주 `(이름, 연도; 이름, 연도)` 국내→국외 순. 순서가 뒤집힌 다중 인용, `et al.`과 `외` 혼용, 쉼표 누락 등을 표본으로 20건 이내.
