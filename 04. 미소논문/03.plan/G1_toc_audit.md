# G1 — 목차·표/그림 목차 정합 감사 (읽기 전용)

공통 규칙: `_COMMON_워커공통규칙.md` 를 먼저 읽는다. 이 작업은 **보고서 1개만** 만든다. 원고를 고치지 않는다.

## 대상
`04. 미소논문/01.docs/` 의 `00.목차.md`(목차·표 목차·그림 목차 절)와 본문 `01.서론.md`~`06.결론.md`, `07.부록.md`, `07-2. 설문근거.md`.

## 할 일
1. `00.목차.md`의 장·절·항 목록 vs 본문 파일의 `#`/`##`/`###` 헤딩을 1:1 대조. 제목 문구 차이(예: 목차 "제 1 항 작성 성과 지표(시간·도출 건수·품질)" vs 본문 "제 1 항 작성 성과 지표"), 누락, 순서 불일치를 표로.
2. `00.목차.md` 표 목차(`<표 N-M>`) vs 본문에 실제로 있는 표 캡션(`<표 N-M>`로 시작하는 행, 백틱·굵게 포함) 대조: 목차에만 있음 / 본문에만 있음 / 번호 중복·건너뜀 / 캡션 문구 차이.
3. 그림 목차(`<그림 N-M>`) vs 본문 그림 캡션 vs `![…](그림/….png)` 이미지 참조 vs `01.docs/그림/` 실제 파일 대조. 캡션은 있는데 이미지 줄이 없는 그림, 이미지 줄은 있는데 캡션이 없는 그림, 파일이 없는 참조를 표로.
4. 본문 안의 상호참조(`<표 5-3>`, `제3장 제2절`, `(<그림 3-1>)` 등)가 실제 존재하는 표·그림·절을 가리키는지 확인해 깨진 참조 목록.
5. 각 장 말미에 다음 장으로 잇는 연결 문장이 있는지(있음/없음) 장별로 표시.
