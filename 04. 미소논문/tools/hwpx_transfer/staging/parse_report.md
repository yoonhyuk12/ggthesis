# MD → blocks 변환 리포트 (미소논문 W1)

`PYTHONIOENCODING=utf-8 python "04. 미소논문/tools/hwpx_transfer/md_to_blocks.py"` 실행 산출물이다. `04. 미소논문/01.docs/`의 원고 MD 9개(본문 6장 + 부록 2 + 00.목차의 국문초록 절)를 verbatim 블록 JSON으로 변환하고, 모든 비어있지 않은 원본 행이 블록 텍스트 또는 excluded에 존재하는지 자기검증한 결과를 담는다. 원고 MD는 읽기만 하며 한 글자도 수정하지 않는다.

처리 방침: (a) `00.목차.md`는 국문초록 절만 `front.blocks.json`으로 내고 표지·목 차·표 목차·그림 목차 절은 `front_matter`로 excluded(조립기가 본문에서 목차를 생성한다). (b) `08.참고문헌.md`는 파싱하지 않는다(W2가 references.json으로 담당). (c) `![alt](그림/x.png)` 행은 신규 `figure_image` 블록으로 낸다. (d) 백틱·굵게로 감싼 `<표 …>`·`<그림 …>` 캡션은 마커만 벗겨 `table_caption`·`figure_caption`으로 인식한다. (e) 인용구(`> …`)는 **하나도 제외하지 않고** 전부 `{"type":"p","runs":[…],"guide":true}` 문단으로 낸다 — `[작성 가이드]` 집필 지침까지 포함한다(조립기가 guide 문단을 빨간 글자로 찍어 지도교수가 집필 방향 서술을 한눈에 보게 하는 규칙). (f) `## 4. 잔여 과제`·`## 5. 구 설계 보존 자료 …`(부록2)는 하위 절을 포함해 통째로 excluded. (g) 여러 줄 HTML 주석 블록도 제외한다.

## 5. 인용구(`> …`) 처리 — guide 문단

인용구는 **하나도 제외하지 않는다.** `[작성 가이드]` 집필 지침까지 모두 `{"type":"p","runs":[…],"guide":true}` 문단으로 낸다. 조립기는 guide 문단 전체를 빨간 글자로 찍는다(지도교수가 집필 방향 서술을 한눈에 보게 하는 규칙). 인용구가 아닌 일반 문단에는 `guide` 키를 붙이지 않는다(기본 false). 여러 줄 인용구는 기존 행→문단 규칙을 그대로 따라 한 행이 한 문단이며(글머리 항목이 뭉치지 않는다), 인용구 안의 빈 줄(`>`)만 `blockquote_blank`로 제외한다.

## 8. 조립기(W4) 인계 사항

- **새 블록 타입 `figure_image`** — `{"type":"figure_image","path":"그림/….png","alt":"…"}`. 경로는 `01.docs/` 기준 상대경로다. 조립기가 PNG를 hwpx BinData에 넣고 그림 개체로 삽입한 뒤, 바로 뒤 `figure_caption` 블록을 캡션으로 쓴다.
- **`<br>` → 셀 내 줄바꿈 변환 대상 0개 행** (해당 없음)
- **`&emsp;` → 전각 공백 변환 대상 0개 행** (해당 없음)
- **국문초록** — `front.blocks.json`은 `# 국문초록` h1과 그 아래 문단만 담는다. 표지·목 차·표 목차·그림 목차는 excluded(`front_matter`)이므로 조립기가 양식의 표지와 자동 생성 목차를 쓴다.
- **참고문헌** — `08.참고문헌.md`는 파싱하지 않았다. W2의 `references.json`을 쓴다.
- **guide 문단 119개** — `p` 블록에 `"guide": true`가 붙은 문단은 인용구(`> …`)에서 온 집필 지침·방향 서술이다. 조립기가 이 문단은 **전체를 빨간 글자로** 찍는다(대괄호 마커와 달리 문단 단위 판정이다). 일반 문단에는 키가 없다.
- **빨간 마커** — `[DATA PENDING`, `[확정 필요`, `[CITE_TODO`, `[CiteTodo`, `[분석 후 작성`, `[실험 후 작성`, `[그림 삽입 예정`, `[UNVERIFIED` 등 대괄호 표시는 본문의 일부로 verbatim 보존했다. 색은 조립기가 입힌다.
- **표 구분행**(`|:---:|…`)은 표 구조로 소비했고 excluded에는 넣지 않았다(내용 문자 없음 검증 통과).
