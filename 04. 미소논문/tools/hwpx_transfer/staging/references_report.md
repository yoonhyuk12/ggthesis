## 2. 산식 — 원고 총 항목 = 채택 + 제외 + 중복

원고의 번호 서지 항목(`[01]`~`[60]`) 총 **60**건.

```
원고 총 항목 60 = 채택 60 + 제외 0 + 중복 0
```

- 채택 60 = 가. 학위논문 11 + 나. 학술지 31 + 다. 보고서 8 + 라. 관련법 3 + 마. 기타 7
- 제외(번호 항목 중) 0건 — 번호 서지 항목은 전량 채택했다. 본문 제외 대상은 번호가 없는 `## 마. 추가 확보 필요 문헌 (CiteTodo — 잔여)` 절의 불릿 **23건**이며, 이는 서지 번호 총계와 별개다.
- 중복 0건 — 없음(공백 정규화·말미 마침표 제거 후 문자열 동일 항목 없음)

제외 절을 포함한 확장 산식:

```
원고 서지 항목 60 + CiteTodo 불릿 23 = 원고 총 항목 83
  = categories 수록 60 + flagged cite_todo 23 + 중복 0
  = 83
```

## 5. 결정 사항

- 원고의 `## 가.`~`## 라.` 절(확보 시점별 묶음)은 분류에 쓰지 않고, 각 항목의 `###` 소제목으로 양식 5분류에 재배치했다. 매핑: 학위논문→가 / 학술지·학회지→나 / 보고서·정부공공기관 간행물→다 / 관련법·고시→라 / 기타·단행본·단행본 장·Preprint·웹자료→마.
- 서지 문자열은 손대지 않았다. 유일한 변형은 마크다운 기울임 별표 제거(**28건**)다. `G*Power`처럼 단어 내부의 별표는 강조가 아니므로 보존했다(정규식 좌측 lookbehind로 배제).
- `[45] 서용하(2013)`의 `[UNVERIFIED — 학과·페이지수 미확인…]`은 원고 본문 표기이므로 서지에 남겼다. hwpx 조립 시 빨간색 마커 규칙(`[UNVERIFIED` 접두사)이 그대로 적용된다.
- `[14]`는 법적 근거 괄호(`— [54] 참조` 포함)까지 원고 그대로 옮겼다.
- 번호(`no`)는 분류별 1부터 재시작한다. 조립기가 `[%02d]` 형식으로 출력한다.

## 6. 미해결 사항

- 분류 애매 9건(`category_uncertain`)은 지도교수 양식 대조 후 최종 확정이 필요하다.
- 원고 상단 [정리 규칙]의 "본문 실인용 문헌과 상호 대조"는 본 작업 범위 밖이다(G3 과제). 특히 원고 주석이 예고한 `[26]~[38]·[41]·[43]`(SEM·요인구조 전용 인용)의 실인용 재판정은 이 파일에서 수행하지 않았다 — 전량 수록 상태다.
- `라. 관련법` 3건은 저자가 없어 법령명 가나다순으로 정렬했다. 양식이 법률→고시 위계 순을 요구하면 재정렬이 필요하다.
