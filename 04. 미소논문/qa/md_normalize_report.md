`00.목차.md`의 `# 목 차` 블록(표/그림 목차·국문초록 항목 제외)과 본문 `#`/`##`/`###` 헤딩을 **문서 순서대로 짝지어** 대조했다. 부록·참고문헌의 하위 헤딩은 목차 미수록이라는 G1 합의에 따라 제외한다.

```
목차 항목 75 · 본문 헤딩 75 · 불일치 0
exit=0
```

검사 스크립트(재현용, 저장소 `04. 미소논문/`에서 실행):

```python
# -*- coding: utf-8 -*-
"""00.목차.md 목차 트리 vs 본문 헤딩 1:1 대조 (순서 포함)."""
import io, os, re, sys
D = "01.docs"
BODY = ["01.서론.md","02.이론적배경.md","03.시스템개발.md","04.연구설계.md",
        "05.실증분석결과.md","06.결론.md","08.참고문헌.md","07.부록.md","07-2. 설문근거.md"]

toc_src = io.open(os.path.join(D,"00.목차.md"), encoding="utf-8").read()
m = re.search(r"^# 목 차\n(.*?)^---$", toc_src, re.S | re.M)
toc = []
for ln in m.group(1).split("\n"):
    if not ln.strip().startswith("- "): continue
    depth = (len(ln) - len(ln.lstrip(" "))) // 2   # 0=장, 1=절, 2=항
    t = ln.strip()[2:].strip()
    if t in ("표 목차","그림 목차","국문초록"): continue
    toc.append((depth, t))

body = []
for fn in BODY:
    for ln in io.open(os.path.join(D,fn), encoding="utf-8"):
        mm = re.match(r"^(#{1,3}) (.+?)\s*$", ln)
        if not mm: continue
        lvl = len(mm.group(1)) - 1
        if fn in ("07.부록.md","07-2. 설문근거.md","08.참고문헌.md") and lvl > 0:
            continue   # 부록·참고문헌 하위 헤딩은 목차 미수록
        body.append((lvl, mm.group(2), fn))

bad = 0
for i in range(max(len(toc), len(body))):
    a = toc[i] if i < len(toc) else None
    b = body[i] if i < len(body) else None
    if a is None:
        print("!! %3d 본문에만: [%d] %s (%s)" % (i, b[0], b[1], b[2])); bad += 1
    elif b is None:
        print("!! %3d 목차에만: [%d] %s" % (i, a[0], a[1])); bad += 1
    elif a[0] != b[0] or a[1] != b[1]:
        print("!! %3d 불일치\n     목차: [%d] %s\n     본문: [%d] %s (%s)"
              % (i, a[0], a[1], b[0], b[1], b[2])); bad += 1

print("목차 항목 %d · 본문 헤딩 %d · 불일치 %d" % (len(toc), len(body), bad))
sys.exit(1 if bad else 0)
```

## 7. 남는 문제 (이 작업 범위 밖 — 코디네이터 판단 필요)

1. **`00.목차.md:30` 표지 날짜가 `2026년 [확정 필요: O]월 *[확정 필요]*`** 로 마커가 두 번 붙는 모양이 되었다. 브리프 치환표(`[O]` → `[확정 필요: O]`)를 그대로 따른 결과다. 표지에서 어색하면 `2026년 [확정 필요: 학위수여 월] *[확정 필요]*` 처럼 한쪽으로 합치는 편이 낫다.

3. **`05.실증분석결과.md` 파일명이 장 제목(`제5장 실험 결과`)과 다르다** — G1이 이미 지적. 헤딩 불일치는 아니므로 6-5 검사는 통과한다.
